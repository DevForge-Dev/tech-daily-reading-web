Opus 5 が新デフォルト・自律起動廃止・サブエージェント可視化 — 8/6の制御性強化

Opus 5 が1Mコンテキストで新デフォルトOpusに（同価格）。/verify・/code-review・/deep-research は自律起動を廃止し手動のみへ。サブエージェントは stream-json で可視化＋セッション上限200、基盤は MCP 2026-07-28 に対応。

📅 2026年8月6日 ⏱ 約3分 🔗 出典 4 件

Claude Code はこの週、"勝手に走らせない"方向へ舵を切った。エージェントが重い調査やレビューを自律的に起動してトークンを溶かす挙動を抑え、ユーザーの意図に沿った制御性を前面に出す変更が中心だ。可観測性の底上げもあわせて入り、"委任先で何が起きているか"を掴みやすくなっている。

何が新しいか。まず Opus 5 が新しいデフォルトOpusに採用され、1Mトークンのコンテキストに対応しつつ価格は Opus 4.8 と同額に据え置かれた。長大なコードベースや設計文書を分割せず一度に読ませても採算が合う。次に /verify・/code-review・/deep-research の自律起動が廃止され、明示的に呼んだときだけ実行されるようになった。さらにサブエージェントのテキストや思考を stream-json へ流す --forward-subagent-text（環境変数 CLAUDE_CODE_FORWARD_SUBAGENT_TEXT）と、暴走的な委任ループを防ぐセッション毎の生成上限（既定200）が加わった。基盤側では MCP 2026-07-28 仕様に対応し、コアのステートレス化・OAuth/OIDC 強化・拡張のバージョニング・埋め込みUIが入った。

# サブエージェントの途中経過を stream-json に流して観測
export CLAUDE_CODE_FORWARD_SUBAGENT_TEXT=1
# 暴走的な委任を上限で止める（既定200）
export CLAUDE_CODE_MAX_SUBAGENTS_PER_SESSION=50

使いどころ・自分が試すなら。1Mコンテキストの Opus 5 なら、モノレポ横断のリファクタや長い設計文書のレビューを分割せず投げられる。CI やログ基盤を持つなら --forward-subagent-text で委任先の途中経過を観測でき、失敗の切り分けが速くなる。まずは重いタスクを1本、サブエージェント上限を小さめ（例: 50）に絞って回し、stream-json をログに落として挙動を眺めるところから始めたい。

落とし穴。自律起動の廃止で、これまで"勝手に"走っていた検証やレビューは手動で呼ばないと動かない。CLAUDE.md やフックに「PR前に /code-review を回す」等を明記し、習慣を仕組み化しておかないと抜ける。ベストプラクティス各記事も CLAUDE.md は概ね200行以内・文脈を絞る・完了はテストで定義、を共通して勧めている。

ひとことまとめ。速さ（Opus 5 の 1M）と制御性（自律廃止・委任上限）と可観測性（stream-json）の三点セット。委任は「上限＋可視化フラグ」を必ずペアで使うのが今の型だ。
