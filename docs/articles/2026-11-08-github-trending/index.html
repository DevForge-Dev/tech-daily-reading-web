Th0rgal/satmux（Python・⭐約356）

解決したい課題：機内や GEO 衛星の Wi-Fi は RTT が極端に高くパケットロスも多いため、素の TCP では遅く詰まりやすい。提供する機能：暖機済み BBR による TCP 多重化＋1-RTT の Ground-TLS＋zlib 圧縮で、この高遅延環境を高速化するプロキシ。依存ゼロ・MIT。created 2026-11-07＝公開約1日で実測約356★/forks18（日平均約356★/日）と当日モメンタム筆頭で、AI 飽和のなか希少な純・非AIネットワーク最適化という新鮮さが拡散の理由。

voyager-so/vork（Rust・⭐約856）

解決したい課題：画像/動画の生成モデルは溢れているが、エージェントが GUI なしに 3D/VFX を“描画”する基盤は乏しい。提供する機能：Metal／レイトレーシングで動くヘッドレスな 3D/VFX レンダリング・エンジン（リサーチプレビュー）。生成モデルではなく「エージェントが叩く描画エンジン」という設計が差別化点。公開約3日で実測約856★/forks55（日平均約285★/日・率約33%）。ライセンス未設定（NOASSERTION）のため製品組み込み時は要確認。

yappologistic/CUI（C・⭐約283）

解決したい課題：Electron/WebView 前提の UI 開発が重く、ネイティブ・依存ゼロを求める層の不満。提供する機能：C 言語向けのネイティブ UI コンポーネント約150種で、スプリング・モーションと完全なキーボード操作に対応し Win/mac/Linux で依存ゼロに動く。公開約3日で実測約283★/forks10（日平均約94★/日・率約33%・fork率4%＝star-farm 懸念なし）。昨日の rune（Rust）とは別言語・別レイヤーの同系トレンドで、希少な C 言語枠。
