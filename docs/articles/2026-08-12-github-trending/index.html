msitarzewski/agency-agents（—・⭐—、Trendshift日次3位・言及1.2k）

解決したい課題：サブエージェント／スキル運用が広がる一方で、目的ごとに「どんな人格・手順・成果物を持つエージェントを用意するか」を毎回ゼロから設計するのは重い。提供する機能：フロントエンドの魔術師から Reddit コミュニティの忍者まで、個性・プロセス・deliverables を備えた専門エージェントを丸ごと束ねた「AIエージェンシー」一式。チームとして一気に呼び出せる。本日 Trendshift 日次3位・言及1.2k とトップクラスの露出で、「エージェントをチーム編成で使う」潮流に乗って急拡散した。

karanb192/itr-wala（—・⭐—、Trendshift日次20位・New 2026・#Fintech・言及408）

解決したい課題：インドの所得税申告（ITR）は税制選択や計算が煩雑で、LLM任せだと数字の正しさが担保できない。提供する機能：ターミナルから ITR を完結させ、両税制対応・AY2026-27 の決定論的な税計算エンジンを備える（Claude Code / Codex / Gemini から使える）。エージェント一色の上位で「確定申告を端末から」という生活密着のドメイン特化が刺さり、新規リポながら日次入り。信頼性を LLM に委ねない設計が話題化の芯だ。

HKUDS/DeepTutor（Python・⭐—、Trendshift日次15位・言及505＋OSSInsight当日）

解決したい課題：画一的な教材は個々の学習者の理解度・履歴に最適化されない。提供する機能：生涯にわたるパーソナライズド個別指導を掲げ、学習者ごとに継続的に最適化する AI チューターシステム。教育×RAG の文脈で、研究色の強い HKUDS 発という完成度への期待もあり、Trendshift＋OSSInsight の二重シグナルで急上昇した。

まとめ・自分が試すなら：開発運用に効くのは agency-agents で、自分のサブエージェント編成の雛形として構成（人格/手順/成果物の3点セット）を読むだけでも学びがある。itr-wala は「LLM＋決定論エンジン」という信頼性設計のパターンとして、DeepTutor は継続最適化のRAG設計として参考になる。まず agency-agents の構成を1つ写経してみたい。
