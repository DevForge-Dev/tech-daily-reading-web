10/6の話題リポジトリ — ローカル記憶の新ハーネス・Ghidraをエージェント化・OSINTをグラフで

エージェント記憶一色の中、“大型の新ハーネス/逆解析/調査”と方向の違う3本。

📅 2026年10月6日 ⏱ 約3分 🔗 出典 3 件

この日もトレンドは「エージェント・記憶・スキル経済」一色。その中から既出クラスタを避け、方向性の異なる3本を選んだ——ローカル記憶を持つ大型の新ハーネスopenhuman、バイナリ解析をエージェント化する定番GhidraMCP、OSINT調査をグラフで組むflowsint。共通するのは「エージェントや可視化を“現場の具体作業”に接続する」視点だ。

tinyhumansai/openhuman（Rust・⭐約41k）

解決したい課題：既存のエージェント記憶・ハーネス（mem0 / claude-mem / openrig 等）はクラウド前提だったり、永続記憶と多エージェント統括が分断されていたりする。開発者は「手元に残る永続記憶」と「耐久的なワークフロー上での複数エージェント統括」を一体で欲しい。提供する機能：ローカルファーストのエージェント・ハーネス。Memory Tree＋Obsidianボルト連携で永続記憶を持ち、耐久グラフ・ワークフロー上でマルチエージェントを統括、100+ OAuth／5000+ MCPサーバと接続する。Rust製で、日中スナップショットで約39.7k→41.4k（＝+約1.7k）と短時間で急伸し、本日のモメンタム筆頭になった（ライセンスはGPL-3.0なので製品組み込みは要注意）。

LaurieWired/GhidraMCP（Java・⭐約10.4k）

解決したい課題：リバースエンジニアリング（RE）の中核ツールGhidraは強力だが、LLMエージェントから直接操作する標準的な口が無く、解析の自動化がしづらい。提供する機能：Ghidraの逆コンパイル、メソッド/データのリネーム、関数・クラス・インポート/エクスポート列挙などの中核機能をMCPツールとして公開し、Claude等のエージェントにバイナリ解析を自律実行させる。本日+約129（率約1.2%/日）とクリーンに伸び、“エージェント×バイナリ解析”という希少ジャンルで存在感を示した（Apache-2.0、防御/解析用途）。

reconurge/flowsint（TypeScript・⭐約9.2k）

解決したい課題：サイバー調査（OSINT）では人物・ドメイン・インシデント間の関係が複雑で、表やメモだけでは全体像を追えない。提供する機能：エンティティ間の関係をグラフで描く、視覚的で拡張可能な調査ワークベンチ。ノード／グラフで関係性を可視化し、カスタムの調査フローを組み立てられるモダンなWebプラットフォーム。本日+約104（率約1.1%/日）で伸び、ハーネス一色のトレンドに“非ハーネスの視覚ツール”として多様性を加えた。

自分が試すなら。手元で一番効きそうなのはGhidraMCP——既にClaude中心の運用なので、怪しいバイナリや自作ネイティブの挙動確認をエージェント経由で回せる（解析は自己資産・許可範囲で）。openhumanはローカル記憶の作りが面白いが、GPL-3.0のため“試用・学習”に留め、製品には混ぜない。flowsintは調査系の仕事が来たとき用にブックマーク。まとめ：派手な記憶ハーネスより、GhidraMCPのように「既存の強ツールにエージェントの口を付ける」系が自分の実務には刺さる。
