Dart 3.13 の dot shorthands と Riverpod 3 のオフライン永続化 — Flutter 3.47 時代の書き味と堅牢性

型が推論できる文脈で先頭ドット省略が可能に。Riverpod 3 は自動リトライ＋オフライン永続化で async を堅牢化。Flutter 3.47 安定版と Impeller 既定を土台に整理する。

📅 2026年9月10日 ⏱ 約3分 🔗 出典 3 件

今日の Flutter は「書き味」と「堅牢性」の両輪が動いた。言語側は Dart 3.13 の dot shorthands と primary constructors が正式化し、状態管理側は Riverpod 3 が自動リトライとオフライン永続化で async を強くする。土台は安定版 Flutter 3.47.x／Dart 3.13.x（3.47.0 は 2026-08-12）だ。

Dart 3.13：dot shorthands と primary constructors

dot shorthandsは、型が推論できる文脈（switch・変数代入・引数）で enum 値・static メンバ・constructor を先頭ドットで省略できる機能。冗長な型名の反復が消える。primary constructorsもクラスヘッダで constructor と instance 変数を 1 行宣言でき boilerplate を大幅削減。利用は language version を ^3.13.0 に。

// before
onPressed: () => setAlign(Alignment.center);
// after（型が推論できる文脈で先頭ドット）
onPressed: () => setAlign(.center);

状態管理：Riverpod 3 の堅牢化

新規の既定は Riverpod 3.0（現行 3.3.x）。unified Ref、失敗 provider の自動リトライ（指数バックオフ）、実験的なオフライン永続化（stale-while-revalidate）、書き込みの中間状態を扱う Mutations API で async データを堅牢にする。再描画は ref.watch(provider.select(...)) で最小スライスに絞る。監査証跡が要る規制業界や複雑並行は Bloc 9.0 の event-driven audit trail が向く。

アニメーションとパフォーマンス

アニメは Material 3 Expressive の spring-driven motion が前進（material_3_expressive で opt-in）。性能では FFI の UI thread merging（Flutter 3.41〜）で native Swift/Kotlin を同期呼び出しでき低レベル統合が高速化。ただしバグのある native 呼び出しは UI スレッドを直接ブロックしうるので、重い処理は Isolate.run()/compute() で背景 isolate へ逃がす。フレーム予算は 60fps=16ms／90fps=11ms／120fps=8.3ms。const と Selector/select で不要な rebuild を削り、Impeller が全 shader を AOT precompile して first-run jank をゼロにする。

実務・注意・まとめ

まず language version を上げて dot shorthands を試し、次に Riverpod の select と自動リトライで壊れにくい非同期にする。注意点は、dot shorthands は型が推論できる文脈限定である点と、FFI 同期呼び出しのUI ブロックリスク。書き味の改善と堅牢化は別レイヤーの話なので、両方を同じ PR に混ぜず段階的に入れるのが安全だ。
