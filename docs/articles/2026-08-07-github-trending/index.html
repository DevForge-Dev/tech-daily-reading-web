PrimeIntellect-ai/prime-agent（Trendshift 日次1位・New 2026）

解決したい課題。多くのコーディングエージェントは固定された能力で、使い込んでも賢くならず、ブラウザを閉じれば止まる。提供する機能。Prime Intellect 製の自己改善型 RLM（強化学習）エージェントで、コーディングのワークフローから長時間の自律タスクまでをこなす。「使うほど自己改善する」「常駐して走り続ける」という切り口が、本日 Trendshift 日次1位・New 2026 の突出したモメンタムを生んだ。常駐エージェント志向の高まりの中核にある。

cloudflare/cloudflare-os（Trendshift 日次2位・New 2026）

解決したい課題。汎用チャットは会社のシステムや文脈を知らず、社内文書やアプリを"その組織のやり方"で作るのは難しい。提供する機能。Cloudflare Workers 上に構築された公式のエージェント・ワークスペース（OS）で、会社のコンテキストやシステムを取り込み、文書作成・アプリ構築・エージェント実行を行う。エッジ実行基盤の上に「会社の文脈で動くエージェントOS」を載せた発想が支持され、先行の @cloudflare/computer に続くエージェントスタック整備として話題化した。

Binaryify/open-kimi-ppt-skill（Trendshift 日次7位・New 2026）

解決したい課題。AI生成のスライドは体裁が固定で、生成後に手直しできない・画像として吐かれて再編集不能、という不便があった。提供する機能。AI エージェントに編集可能な PPTD+PPTX を生成させ、手直し用のローカル・ブラウザエディタまで同梱する非公式の Kimi Slides スキル。当日増加率が上位群で最高クラスで、エージェント一色の Trending の中で文書・プレゼン生成というジャンル多様性も担う。

自分が試すなら。実務に最短で効くのは open-kimi-ppt-skill。手元の要点メモから編集可能な PPTX を吐かせ、ブラウザエディタでの手直し体験と崩れ具合を既存フローと比べたい。基盤として面白いのは cloudflare-os——既に Workers を使うなら、社内文脈を与えたエージェントで小さな社内ツールを1つ作ってみる価値がある。prime-agent は「自己改善×常駐」の思想を確かめる観察対象として追っておきたい。
