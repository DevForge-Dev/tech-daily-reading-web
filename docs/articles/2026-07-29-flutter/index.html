Dart 3.12 で定型を削り、Impeller で 120fps を出す

primary constructors など3機能でボイラープレートを圧縮。Impeller は既定でラスタライズ約50%短縮・Skia比17%省電力。状態管理は Riverpod 3.3 と Bloc 9.0 の二枚看板。

📅 2026年7月29日 ⏱ 約3分 🔗 出典 4 件

今日の Flutter は「書く量を減らす」と「速く描く」が同時に前進した。Dart 3.12 は定型コード削減の3機能が軸だ。primary constructors（experimental・primary-constructors フラグ）は5行の Point クラスを1行に圧縮、private named parameters は先頭 _ から公開名を自動決定、dot shorthands（3.10 で登場し3.12で成熟）で列挙や定数の記述が短くなる。安定版は Flutter 3.44.0 / Dart 3.12、次の機能リリースは2026年8月だ。

描画は Impeller が iOS＋モダンAndroid（API 29+）の既定になり、もはや experimental ではない。AOT でシェーダーを事前コンパイルして初回ジャンクをゼロにし、複雑シーンでフレームラスタライズ時間を約50%短縮。ランタイムのシェーダーコンパイル排除と CPU-GPU 同期削減で、Skia 比約17%低いバッテリー消費も報告されている。

計測は必ず profile モードで、DevTools の Performance タブでタイムラインを取る。基本は不要な rebuild の撲滅だ。const 徹底で const widget の再ビルドを完全スキップし、build を分割して最小スライスだけ watch、RepaintBoundary を戦略配置する。saveLayer を誘発する nested Opacity・複雑な clip・重なる影は避ける。

状態管理は2026も三強（Riverpod 3.0 / Bloc 9.0 / GetX〈退潮〉）で、新規は Riverpod 3.3.1 ＋ code generation が既定線。unified Ref・自動リトライ・context-free read で compile-time safety を保つ。監査証跡が要る規制業界（fintech/healthcare）や複雑な並行ワークフローは Bloc 9.0——mapEventToState を廃した on<Event> 構文で、全 state 変更が特定 event に対応する。上に feature 単位の Clean Architecture ＋ go_router を敷く。

自分が試すなら、まず private named parameters と dot shorthands だけ実務投入する。primary constructors は experimental preview で構文が変わり得るので本番は様子見。アニメーションは UI モーションの約80%（hover・state 遷移・レイアウト変化）を implicit（AnimatedSize/AnimatedScale）で、複雑な choreography や physics だけ explicit に。まとめ：定型は Dart 3.12 に任せ、浮いた労力を rebuild 削減と Impeller 活用に回すのが今の正解。
