Claude Code v2.1.330 が latest に昇格 — 組み込みチャート mod「easel」でCLIが図を描き、MCPメトリクスにも自動で添える

今日の最大の動きはバージョン。npm latest が v2.1.329→v2.1.330 へ（JST 11/21 04:16 公開、stable=v2.1.323）。目玉は組み込みチャート mod「easel」——依頼に応じて図を描き、/mcp のメトリクス結果の下にも自動でチャートを添える。あわせて Enterprise Admin Console 管理組織へのサインインに対応し、コンパクト後のフリーズや WebFetch の空応答、worktree 誤削除など多数を修正した。

📅 2026年11月21日 ⏱ 約4分 🔗 出典 3 件

Claude Code の版は今日も素直に一段進んだ。npm view @anthropic-ai/claude-code dist-tags を一次確認すると latest=v2.1.330（npm 公開 2026-11-20 19:16 UTC＝JST 11/21 04:16）で、昨日の v2.1.329 から1つ前進。stable は v2.1.323 に据え置かれている。GitHub の一次 CHANGELOG によれば、このバージョンのユーザー向けの目玉は明確に1つ——組み込みチャート mod「easel」の追加だ。CLI がターミナルの中で図を描けるようになり、しかも /mcp のメトリクス結果の下にも自動でチャートを添える。

何が新しいか：easel は“別インストール”ではなく組み込み mod

誤解されやすいが、easel は外部プラグインではなく Claude Code に同梱される組み込み mod だ。対象は Pro・Max、そして利用可能な環境では Team・Enterprise の macOS・Linux。自動でチャートを添える挙動が不要なら /config で止められる。関連して v2.1.330 では、許可/拒否リストが easel を除外している環境で起動のたびに出ていた「MCP server blocked by enterprise policy: easel」警告の抑制や、Claude が Code Mode から組み込みチャートツールを呼ぶと失敗する不具合の修正も入り、チャート周りが一通り整えられた。もう一つの新機能は Anthropic の Enterprise Admin Console で管理する組織へのサインイン対応で、claude auth login の後に組織の設定とそのクラウドプロバイダ/ゲートウェイを適用する。短いサインインリンクが壊れる場合に完全なリンクを出す CLAUDE_CODE_FULL_SIGN_IN_LINK=1、セルフホストランナーの作業開始フォルダを指定する --start-dir / SELF_HOSTED_RUNNER_START_DIR も追加された。

見逃せない修正：無人運用に直撃する worktree 誤削除

機能より重要かもしれないのが修正群だ。とりわけ ExitWorktree（および終了ダイアログ）が、別セッションが作業中の worktree を削除してしまう不具合の修正は、/batch や claude --worktree で worktree を並列に使う無人運用にとって地雷の除去にあたる。ほかに、非常に長い会話のコンパクト直後に数分フリーズする問題、WebFetch が一部ページで数分フリーズ・空応答を返す問題、複数プロセスの同時保存でユーザー設定が失われる問題、Code Mode の多数の不具合が直った。

実務での使いどころ・自分が試すなら

worktree 並列運用をしているなら、この版への更新は優先度が高い——誤削除修正だけでも上げる価値がある。easel は、ログや CSV を手元で素早く可視化したいときに /config の設定を一度確認し、自動添付が邪魔なら切る、という付き合い方で十分だ。周辺の技術記事も厚い日で、DevelopersIO は v2.1.326 の破壊的変更（auto モードで $HOME 始まりのワイルドカード allow が無視され安全チェックに回る／サンドボックスが一部の機微な home フォルダへ既定で書かなくなる）を before/after で解説し、Vibehackers は hooks（command/HTTP/prompt/agent の4種、command は終了コード2でブロック）と subagents を体系化している。

ひとこと

事例面では Money Forward の全社展開（エンジニアの80%が採用・API 実装を2日→5時間、社内ツール Sherlock/Lumos を内製）も公開された。派手な新機能より“無人で安全に回す”方向の地ならしが続く中、v2.1.330 は worktree 周りの実害を消しつつ、CLI に図を描く小さな楽しさ（easel）を足した版だ。
