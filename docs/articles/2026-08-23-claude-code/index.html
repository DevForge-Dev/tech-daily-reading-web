Claude Code

v2.1.239でコスト表示が正確に — データ所在地1.1倍プレミアムとself-hosted runner

派手な新機能より運用の地盤づくり。/cost や --max-budget-usd がデータ所在地の1.1倍課金を反映し、自社インフラで動かす self-hosted runner が企業運用の要になってきた。

📅 2026年8月23日 ⏱ 約3分 🔗 出典 5 件

今日のClaude Codeは「精度」と「企業運用」の日だった。8/21の v2.1.239 はコスト表示の正確化が中心で、週次の公式What's New（Week32）では自社インフラで動かす self-hosted runner が主役。あわせて、企業導入の数字が一段跳ねたニュースも出そろった。

何が新しいか

v2.1.239 では、/cost・ステータスライン・--max-budget-usd のコスト見積もりに、データ所在地（US限定推論）ワークスペースの1.1倍プレミアムが反映されるようになった。これまで見積もりと請求がズレていた構成で、事前予算と実額が噛み合う。加えてPythonプロジェクトを anthropic 0.x→1.x へ移す /claude-api アップグレードコマンド、Alpine/musl ビルドでの画像貼り付け・クリップボード・音声キャプチャのネイティブ対応、name@synced によるクラウドセッションのプラグイン管理改善が入った。

self-hosted runner という転換

Week32の目玉は Team/Enterprise 向けの自己ホスト実行環境 claude self-hosted-runner。自社のマシンやコンテナを、Web/モバイル/デスクトップの各セッションの実行基盤に差し替えられる。コードや機密情報をAnthropic側に置かずに回せるため、規制業界や社外持ち出し不可のリポジトリでも本番導入しやすい。あわせて、セッション同士が @メンションで直接やり取りするクロスセッションメッセージング（同一Mac内はローカル完結）、ZIP over HTTPS でのプラグイン導入、サンドボックス権限の強化が入った。

実務での使いどころ

自分が試すなら、まず /cost の新表示で普段のワークフローの実コストを測り直す。常駐エージェントのトークン予算はガバナンス込みで設計したい——市場側の数字がそれを裏づける。企業AI採用でClaudeが法人顧客30万社超・年100万ドル超の大口1,000社超に達しOpenAIを逆転、Claude Code単体の年換算売上は25億ドルでWAUは年初から倍増。国内でもみずほFGが約3万人で業務活用、楽天は新機能導入を80%短縮と報じられた。伸びる一方でトークン支出は効くので、self-hosted runner＋予算上限で「性能とコストの両取り」を狙うのが今の定石だ。

注意点

1.1倍が乗るのはデータ所在地WSのみで、通常WSは対象外——自分の構成がどちらかを取り違えないこと。self-hosted runner は運用責任（更新・監視・セキュリティ）が自社に移る。/claude-api 移行は破壊的変更を含むので、まずブランチを切って回す。

ひとこと

「使えるか」から「安く・安全に・大規模に回せるか」へ。コスト精度と自社ホストは、まさにその段階に入った合図だ。
