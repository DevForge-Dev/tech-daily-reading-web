Flutter 3.47系の到達点と120fps時代の設計 — Impeller既定・Riverpod 3.3.1・フレーム予算

stable 3.47.4/Dart 3.13.3を軸に、アニメの時間設計(micro 50–200/component 200–400/Hero 300–600ms)、状態管理はRiverpod 3.3.1既定・監査はBloc 9.0、性能は60/90/120fpsのフレーム予算で考える。

📅 2026年9月17日 ⏱ 約4分 🔗 出典 5 件

今日の主役は Flutter 3.47.4 / Dart 3.13.3 の stable パッチ追従だ。2026-09-11 に patch が出て現行安定は 3.47 系を継続。この系の到達点は、material_ui / cupertino_ui 1.0 の standalone 化、Impeller が全デスクトップで既定、Widget Previews stable、Dart 3.13 の primary constructors と dot shorthands。beta は 3.48.0-0.5.pre（Dart 3.14）で、Web は WebAssembly（WasmGC）を既定コンパイルターゲットへ前進中。次の安定機能リリースは年 4 回サイクルの 2026 年 11 月見込みで、Impeller の Android 一本化と WasmGC 既定化が布石になっている。

アニメーションは timing とカーブの設計から

UI モーションの約 8 割は implicit で賄うのが基本線。時間設計の目安は、micro-interaction が 50–200ms（implicit / controller 不要）、component 遷移が 200–400ms（explicit / AnimationController＋dispose 必須）、Hero が 300–600ms。標準カーブは easeInOut / fastOutSlowIn。多段の振付は flutter_animate の .then() / delay: で宣言的に組み、デザイナー主導の複雑シーケンスは Rive / Lottie にオフロードする。jank の典型は「描画変換のつもりが layout pass を誘発」で、動きは Transform、フェードは Opacity に閉じるのが鉄則（width/height の setState は layout を走らせる）。

状態管理は Riverpod 3.3.1 を既定に

選定は benchmark でなく team expertise・データフローの形・欲しい保証で決める。新規の既定は Riverpod 3.3.1＋@riverpod codegen——compile-time safety・BuildContext 非依存の reads・first-class async を最小 boilerplate で得られ、テストは provider override でツリー非起動、平均 30–40% 少ない行数で書ける。再描画最適化は ref.watch(provider.select(...))。一方 監査/規制業界（fintech・healthcare）は Bloc 9.0——events/states/logic を厳格分離し、各 state 変化が特定 event に対応づいて audit trail を生む。blocTest で正確な state 列を検証でき、永続化は hydrated_bloc。

パフォーマンスはフレーム予算で考える

Impeller は iOS＋モダン Android（API 29+）の既定で、全 shader を build 時に precompile して shader compilation jank を排除。Skia 比で平均フレームレンダリング時間が約 22% 改善、budget Android で frame time variance 約 60% 減という報告もあり、高リフレッシュで安定 120fps を狙える。フレーム予算は 60fps=16ms / 90fps=11ms / 120fps=8.3ms。最も多い性能問題は不要な rebuild で、プロパティ不変なら const で完全スキップ、大きな build() を分割、select / BlocSelector で最小スライス購読、アニメ領域を RepaintBoundary で隔離、重い計算は Isolate.run() / compute() で背景 isolate へ。計測は必ず profile モードで DevTools Performance タブを使う。

ひとことまとめ

3.47 系は「Impeller 既定・standalone UI パッケージ・Dart 3.13 の軽量構文」で土台が固まった段階。自分が試すなら、新規は Riverpod 3.3.1＋codegen で組み、アニメは時間設計の 3 段を守って implicit 中心にし、DevTools の profile 計測で rebuild と raster spike を潰す——この 3 点を型にするのが 120fps 時代の実務解だ。
