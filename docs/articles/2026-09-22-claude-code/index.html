カスタマイズ5手段の輪郭が揃った日 — CLAUDE.md/コマンド/Skills/Subagents/Modsの使い分けとAGENTS.mdフォールバック

CLI新版は無く（最新v2.1.278）、軸は「カスタマイズ手段の使い分け」。CLAUDE.md・スラッシュコマンド・Skills・Subagentsの役割整理に、TypeScript関数フックModsの一般公開とAGENTS.mdフォールバック定着が重なった。自分の設定を棚卸しするのに丁度いい一日。

📅 2026年9月22日 ⏱ 約3分 🔗 出典 5 件

背景から。ここ数週のClaude Codeは派手なAPI追加より運用の足回りを固める流れで、この日もCLI新版は無い（最新は9/19のv2.1.278）。代わりに各所の記事が揃って扱ったのが「カスタマイズ手段の使い分け」だ。CLAUDE.md・スラッシュコマンド・Skills・Subagentsをどう役割分担させるか——設定が増えてきた今こそ棚卸しに向くテーマで、そこにMods（関数フック）の一般公開とAGENTS.mdフォールバックの定着が重なった。

何が新しいか

公式軸は週次まとめ。AGENTS.md対応が既定挙動として定着し、CLAUDE.mdがあればそれを優先、無ければAGENTS.mdへフォールバックする（claude-md-or-agents-md、/configで優先順位変更可）。2.1.268で入れたdenyルール変更は2.1.273で差し戻し、2.1.275で起きたゲートウェイ経由の全リクエスト400回帰は2.1.276で緊急修正された。さらにMods——プラグイン挙動をTypeScript関数で書く仕組み——が sec-default / diff / telemetry の3種で一般公開（要 CLAUDE_CODE_ENABLE_FUNCTION_HOOKS=1）。9/16のClaude Slides（/slidesでデッキ生成・PPT/PDF出力）も定着した。

仕組みと実務での勘所

4層の境界はこう捉えると迷わない。CLAUDE.mdは常時ロードの規約だが、長いセッションでは優先度が下がる（コンテキストドリフト）ので「絶対守らせたい規約」だけに絞る。スラッシュコマンドは引数を取れる手動マクロで自動永続はしない。Skillはプロンプトが説明（description）に一致すると自動起動する「モデル起動」型で、待機中は1件約100トークンしか食わないため50個入れても軽い。Subagentは別コンテキスト・別ツール権限・別モデルの隔離インスタンスで、調査結果の要約だけをメインに返す。実戦の定石は、何でも屋を1体でなく3〜7体の専門特化（explorer/reviewer/test/doc）を用意し、各々に単一の仕事と最小権限を与えること。並列は3〜5体まで（超えると要約統合コストが利得を上回る）、SubagentStopフックでテスト通過や秘密情報除去を返却前に強制する。

落とし穴

最大の不意打ちはSubagentのモデル継承。2026年既定ではリードのモデルを継承するため、triageまでOpusで走って意図せず高額課金になりやすい——triageはHaiku等に明示固定してコストを制御する。SkillはSKILL.mdを500行未満に保ち、エッジケースやスクリプトは参照サブディレクトリへ逃がして必要時のみ読ませる。外部システム接続はMCP、隔離・並列はSubagent、反復手順はSkill、という住み分けを崩さないこと。

ひとことまとめ

新版は無くとも「手段の輪郭」が揃った日。まず自分のCLAUDE.mdを規約だけに削り、Subagentのモデルを明示指定するところから手を付けたい。
