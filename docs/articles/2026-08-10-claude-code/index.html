セルフホスト実行環境がベータ — Claude Codeのセッションを自社ネットワーク内で回す（Focus view / maskモードも）

8/6発表のセルフホスト実行環境がパブリックベータに。どこから起動してもセッションは組織のネットワーク内で動き、リポジトリ・シークレット・生成物が境界内に留まる。Team/Enterprise向け・既定オフ、ランナーはFixed/On-demandの2モード。v2.1.221のFocus viewとサンドボックス資格情報maskモード、v2.1.224〜226の地固めも実運用を後押しする。

📅 2026年8月10日 ⏱ 約3分 🔗 出典 4 件

コーディングエージェントの「実行場所」そのものを顧客側へ動かす更新だ。Anthropic は 8/6、Claude Code のクラウドセッションを自社ネットワーク内のサーバーで実行する「セルフホスト実行環境」をパブリックベータで提供開始した。Web・モバイル・デスクトップ・ターミナル・スケジュール実行のどこから起動しても、セッションは組織の内側で社内サービスやツールチェーン、セキュリティ制御の隣で走る。規制の厳しい企業ほど効いてくる話だ。

何が新しいか — データ境界の内側でエージェントを回す

従来はセッションが Anthropic 側インフラで動き、リポジトリのチェックアウトやシークレットが境界の外に出る前提だった。セルフホストではリポジトリ・ビルド成果物・シークレット・セッションが生成/変更したファイルが、組織の用意したマシン上に留まる。対象は Team / Enterprise プランで既定は無効。ランナーは常時一定数を保つ Fixed と、キュー状況で起動/停止する On-demand の2モードを選べ、セッション数に応じてスケールできる。

UX と安全性の地固め（v2.1.221〜226）

大型機能を日常運用に乗せる改善も続く。v2.1.221 でチャットメニューに Focus view が追加され、ツール実行アクティビティをターンごとの折りたたみサマリーの背後に隠して会話の流れを追いやすくした（Ctrl+Alt+F で切替）。同時に Linux/WSL 向けにサンドボックス資格情報の mode:"mask" が入り、シークレットを露出させずにサンドボックス実行へ渡せる。v2.1.224〜226 はサブエージェントのテキストストリーミングと背景エージェントの信頼性改善を軸に、権限・アップロード・セッション・Chrome・Windows にまたがる広範なバグ修正と、端末描画性能・メモリ・プロンプトキャッシュの底上げを含む。

実務での使いどころ・注意点

使いこなすチームは「良いプロンプト」より良いハーネスを組む、というのが実務ガイドの一貫した主張だ。締まった CLAUDE.md、実効的な権限ポリシー、Skills のライブラリ、絶対厳守を強制する数個の Hooks、委譲境界としてのサブエージェント——強制は Hooks/権限、知識は Skills、委譲はサブエージェント、と役割を分けると重複が減る。日本企業の事例では導入3〜6週で月30〜80時間の工数削減が目安とされ、freee は Max 定額と Enterprise 従量を併用しコスト最適化とガバナンスを両立させている。注意点は、セルフホストがベータ・既定オフ・Team/Enterprise 限定で、日次で小刻みにパッチが出るため CI/スクリプト連携では固定バージョン運用が無難なこと。

ひとことまとめ：派手な新機能というより、強力なエージェントを「境界内で・安全に・長時間」回すための地固めの回。並列・自動運用ほど恩恵が大きい。
