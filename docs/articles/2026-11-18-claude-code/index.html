Claude Code

Claude Code v2.1.327 は next 先行配布・文書化最新は v2.1.326 — 自動実行を締める「auto モード allow 厳格化」と「サンドボックス書込先制限」

今日の版は二段で捉える。npm next=v2.1.327（JST 11/18 05:33）が先行配布される一方、GitHub の CHANGELOG 先頭は依然 v2.1.326 でリリースノート未掲載。文書化された最新の v2.1.326 では、auto モードの allow ルール厳格化とサンドボックス既定書込先の制限という、無人実行を安全側へ締める2つが効く。

📅 2026年11月18日 ⏱ 約4分 🔗 出典 2 件

Claude Code の版は今日、素直に『最新版はこれ』とは言えない。npm view @anthropic-ai/claude-code dist-tags を叩くと next=v2.1.327（npm 公開 2026-11-17T20:33Z＝JST 11/18 05:33）・latest=v2.1.326・stable=v2.1.311 だが、一次ソースの GitHub main の CHANGELOG.md 先頭は依然 v2.1.326で、v2.1.327 のリリースノートは本稿時点で未掲載だ。これは Claude Code が安定版（latest）より先に next タグで先行ビルドを配る運用のため——配布物としては v2.1.327 が存在するが、文書化された最新機能は latest=v2.1.326 までという状態になる。把握の仕方は『今日の新規版=v2.1.327（next 先行・中身は未公開）』『文書化済みの最新=v2.1.326』の二段で持つのが正確だ。

何が重要か：v2.1.326 は無人実行を安全側に締め直す

DevelopersIO（classmethod）の v2.1.326 挙動検証によれば、367 項目の大半は修正だが、権限チェックとサンドボックス周りに主要な挙動変更が2つある。(1) auto モードの allow ルール厳格化——プログラム名を含まないワイルドカードや $HOME から始まるワイルドカードの shell allow ルール（記事の例は Bash($HOME/scripts/*)）は無視され、サーバ側の安全性チェックに回される。完全一致（exact-match）ルールは従来どおり許可される。(2) サンドボックスの既定書込先制限——macOS/Linux/WSL でサンドボックス実行時に一部の機微な home 配下フォルダへ既定で書けなくなり、ユーザー/管理設定の sandbox.filesystem.allowWrite で明示許可する。あわせて .credentials.json 等サインイン系ファイルへの書込拒否、Bash grep のファイル取りこぼし修正、並列 MCP 結果の取り違え修正、Bedrock/Vertex/Foundry の compaction 修正、そして昨日の目玉 Code Mode×エージェントチーム併用（既定 in-process のチームメイトも Code Mode で動作）が挙がる。

実務での使いどころ・自分が試すなら

無人スケジュール運用の身には、この2点は直撃する。auto モードで雑に Bash($HOME/...*） のようなワイルドカード allow を置いていたジョブは、v2.1.326 以降は静かに安全性チェックへ回され、無人だと止まる可能性がある。対策は、許可したいコマンドを完全一致ルールで列挙し直すこと（代替のワイルドカード構文は記事に示されていない＝完全一致へ寄せるのが安全）。サンドボックス側は、ビルド生成物を home 配下の機微フォルダへ書くジョブがあれば sandbox.filesystem.allowWrite に対象を明示する。まずは1ジョブで /status と allow 設定を点検し、無視されている allow ルールが無いかを確認してから横展開したい。

注意点

v2.1.327 の具体的変更点はノート未公開で、next の先行ビルドは破壊的変更があり得るため本番パイプラインへの即投入は避け、latest=v2.1.326 を基準にするのが堅い。版の追跡は npm view @anthropic-ai/claude-code dist-tags（版番号）＋ GitHub 一次 CHANGELOG（ノートの有無）の2系統で。DevelopersIO は英語の二次検証で、設定キー名・既定挙動は版・環境で変わりうる点も踏まえておく。

ひとこと

機能追加の派手さはない日だが、『無人・自動実行をどれだけ安全側に倒すか』という Claude Code の一貫した方向が v2.1.326 でまた一歩進んだ。allow ルールは“雑なワイルドカード”から“完全一致の列挙”へ——定期タスクを回す人ほど、この棚卸しの価値が大きい。
