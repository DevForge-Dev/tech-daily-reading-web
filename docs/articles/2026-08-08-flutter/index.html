Flutter 2026「Finishing the Job」— Impeller完遂・Web WasmGC既定化・Riverpod 3.0既定

安定版はFlutter 3.44/Dart 3.12、次の機能リリースは2026年8月。2026ロードマップはAndroid Impeller移行完遂・WebのWasmGC既定化・GenUI・Full-Stack Dartが柱。flutter build web --wasmでロード最大40%短縮/JS比2-3x。状態管理は新規=Riverpod 3.0、監査/大規模=Bloc 9.0。

📅 2026年8月8日 ⏱ 約3分 🔗 出典 3 件

今日のFlutterは、単発の新機能ではなく2026年の年間ロードマップ「Finishing the Job」が主役。安定版は Flutter 3.44 / Dart 3.12（3.44.0 は 2026-05-18・I/O 公開）で、次の機能リリースは 2026年8月（年4回：2/5/8/11月）。8月版の前に 3.44 系で足場を固める好機だ。

ロードマップ5本の柱

①Android の Impeller 移行完遂（Android 10+ で legacy Skia backend 撤去）②Web の WebAssembly 既定化③GenUI / agentic app architecture（AI駆動の動的UI）④Full-Stack Dart（Cloud Functions を Dart で）⑤ AI前提の開発体験。3.44 では Impeller が Android API 29+（Vulkan）で既定となり Skia 撤去、iOS/macOS は Swift Package Manager が既定（CocoaPods 段階的廃止）、Agentic Hot Reload（Dart MCP server 経由）と GenUI が production へ昇格した。Dart 3.12 は private named parameters・dot shorthands 成熟・primary constructors（experimental）。

状態管理は「新規＝Riverpod 3.0、監査＝Bloc 9.0」

エコシステムは Riverpod 3.0（compile-time safety・最小ボイラープレート）・Bloc 9.0（enterprise event tracing）・GetX（退潮）。Riverpod 3.0 は多くの新規の既定で、①初期化失敗時の指数バックオフ自動リトライ②opt-inのオフライン永続化③Mutations（@mutation・experimental で Idle/Pending/Success/Error を UI へ公開）④画面外widgetの listener 自動pause を備える。Bloc 9.0 は on<Event> ハンドラで event→state を直列化し監査証跡を生む＝規制業界向け。現行は Riverpod 3.3.x / bloc 9.2.x。両者は ProviderScope と MultiBlocProvider で共存可。

自分が試すなら / 注意点

まず既存Web案件を flutter build web --wasm で計測し、dart:html/package:js を dart:js_interop に置換して WasmGC 経路に載せる。パフォーマンスのボトルネックは raster より widget build・layout に移っているので、const 徹底・大きな build() 分割・select で局所再描画を軸に。フレーム予算は 60fps=16ms / 90fps=11ms / 120fps=8.3ms、計測は必ず profile モードで。primary constructors は構文が変わり得るので本番は保留。

ひとことまとめ：Impellerを完遂し、WebをWasmへ、状態管理はRiverpod 3.0を既定に。2026年の「土台」が確定した。
