Claude Code

v2.1.331 公開 — 実験機能「Code Mode」が Bedrock・Vertex・Foundry でも使えるように。VS Code に「Fix with Claude Code」、MCP 30分ハング／rewind のファイル削除も修正

JST 11/24 早朝に v2.1.331 が登場。目玉は Code Mode の対応バックエンド拡大で、これまで Anthropic 直結だけだった省トークン実行が主要クラウド経由でも動く。あわせて 11/20 の組み込みチャート mod「easel」も整理する。

📅 2026年11月24日 ⏱ 約4分 🔗 出典 4 件

日本時間 11/24 の早朝（UTC 11/23 18:36）に npm の latest/next が v2.1.331 へ更新された（stable は v2.1.325 のまま）。追加14・改善17・変更9・修正約95という中規模リリースだが、話題性でいちばん大きいのは実験機能 Code Mode の対応バックエンド拡大だ。これまで Anthropic 直結のサブスク／Console 接続でしか使えなかったものが、Amazon Bedrock・Google Cloud(Vertex)・Microsoft Foundry 経由でも利用できるようになった。企業で Bedrock/Vertex にモデル接続を寄せている環境でも、ようやく Code Mode を試せる。

Code Mode とは何かをおさらいすると、従来 Claude Code は「ツールを1回呼ぶ→出力を Claude が読む→次の手を決める」を繰り返すため、巨大な検索結果や中間出力がすべて Claude のコンテキストを一度通過していた。Code Mode では Claude が複数ツールを連結した JavaScript を1本書いて実行し、ツール呼び出しの結果はスクリプト内で直接次へ渡る。結果として、大きな出力を絞り込んでから必要分だけ読む・同じ変更を多数ファイルへ一括適用・独立コマンドを並列実行、といった処理でトークンを節約できる。

仕組みと制約。有効化は起動シェルで CLAUDE_CODE_EXPERIMENTAL_CODE_MODE=1 を設定して新規セッションを開始（既定オフ）。ネイティブ v2.1.323 以降・ターミナル対話セッションのみ（VS Code 拡張パネルやデスクトップ版は不可）で、待機は10分、--permission-mode auto 等でのバックグラウンド実行は最大2時間。実行した JavaScript は Ctrl+O で Code 行を展開すると中身を確認できる。HIPAA 設定やゼロデータ保持の組織は対象外。11/20 の gihyo 解説時点ではバックエンドが Anthropic 直結に限られていたが、今日の v2.1.331 でその壁が下がった形だ。

同じリリースには実務で効く修正も入った。ローカル／WebSocket サーバーの不正応答で MCP ツール呼び出しが最大30分ハングする問題、復元に失敗した後の rewind がファイルを削除する問題を解消。VS Code 拡張にはエラー・警告・失敗テスト向けの「Fix with Claude Code」クイックフィックス（問題をチャット欄に投入）が追加され、claude doctor には API 接続性チェックの節も増えた。挙動変更として、managed 設定の extraKnownMarketplaces のプラグインマーケットプレースは『2026-11-30 以降の版』で既定自動更新になる予定。

11/20 の v2.1.330 で入った組み込みチャート mod「easel」（内部名 cc-plugin-easel）も振り返っておく。依頼するとチャートを描き、MCP の時系列メトリクス結果（Prometheus の range query など）の下にも自動でグラフを表示する。/plugin の Installed に Built-in として現れ、自動チャートは /config でオフ可。Pro/Max と提供範囲の Team/Enterprise、macOS・Linux 限定（WSL 不可）。DevelopersIO の実機検証では棒グラフは描けたが円グラフは不可で HTML 円グラフを代替生成したと報告されている。「チャートツールが見つからない」時は /exit→claude 再起動で再試行するとよい。

自分が試すなら：まず Code Mode を1セッションだけ有効化し、「大量の grep 結果を絞って必要ファイルだけ読む」系タスクで従来モードとトークン消費を比べる。Bedrock/Vertex に寄せている場合はそのバックエンドで動くか確認。落とし穴は、Code Mode がターミナル対話限定なので CI やデスクトップ運用には入れられない点と、30分ハング修正の恩恵を受けるには実際に v2.1.331 へ上げる必要がある点。ひとことまとめ：版番号は小刻みでも、Code Mode の“クラウド解禁”は企業導入の実用ラインをまたいだ一手。
