MoonshotAI/Kimi-K3（Python・Trendshift日次1位）

解決したい課題：最前線級の知能が一部の閉じたモデルに偏り、誰もが土台として使える大型オープンモデルが不足している状況。提供する機能：「Open Frontier Intelligence」を掲げる Kimi 系の新モデル本体で、NLP・コンピュータビジョン・エージェント用途に横断で使える基盤を公開する。エージェント／スキル一色のTrendingの中で、久々の大型オープンモデルとして他を引き離し日次1位まで急伸した。

bradautomates/claude-video（Python・Trendshift日次3位＋OSSInsight当日）

解決したい課題：テキストと画像が中心の Claude は、そのままでは動画コンテンツを理解できない。提供する機能：/watch で動画をダウンロードし、フレーム抽出と文字起こしまで自動化して一式を Claude に渡す。映像入力を橋渡しするという実用的な着眼が支持され、複数ソースで明確な急上昇を示した。

mshumer/Claude-of-Duty（JavaScript / Three.js・Trendshift日次12位）

解決したい課題：本格的なゲーム制作は、3D・物理・アセット・入力処理と参入障壁が高い。提供する機能：単一プロンプトから Call of Duty 品質の Three.js 製 FPS を丸ごと生成する。ブラウザ完結の WebGL 実装で、「プロンプト1発でゲーム」というデモ性が拡散を呼んでいる。

自分が試すなら：実務に一番効くのは claude-video——日々の調査やレビューに映像ソースを取り込める。Kimi-K3 はオープン基盤としてウォッチ、Claude-of-Duty は生成AIの到達点を測るベンチマークとして眺めるのがちょうどよい。
