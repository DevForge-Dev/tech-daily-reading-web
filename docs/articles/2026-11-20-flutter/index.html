Flutter 3.50.1 hotfix が「中身の組み立て」へ前進 — changelog PR がマージ、ただし tracker は全未チェックで未出荷。あわせて Material Motion の既製トランジション package も整理

3.50.1 は changelog PR #196936 が候補ブランチへ merged し cherry-pick 11本が出そろったが、release-tracker #196743 は依然 OPEN で全項目未チェック＝まだ出荷前。stable は 3.50.0／Dart 3.14.0 据え置き。画面遷移の意匠を既製化する公式 animations 3.0.0 もあわせて押さえる。

📅 2026年11月20日 ⏱ 約4分 🔗 出典 3 件

Flutter の次の hotfix 3.50.1 が、昨日の「tracker が立っただけ」段階から一歩進み、今日は中身（changelog）が初めて組み上がったのが news だ。現況は stable 3.50.0 / Dart 3.14.0（11/11）、beta 3.51.0-0.1.pre / Dart 3.15.0 で据え置き、3.50.1 行は stable 表にまだ無い＝未出荷。「出そうで出ていない」この数日の状態を、リリース工程のどこにいるかで読むと分かりやすい。

何が動いたか — changelog は merged、出荷チェックは全部空

GitHub の flutter/flutter #196936「[3.50] Changelog for 3.50.1」が 11/19 に auto-submit[bot] で候補ブランチ flutter-3.50-candidate.0 へ MERGED（reviewer approve 済）。本文は 3.50.1 に入る cherry-pick を列挙し、計11エントリ——例として「flutter_tools: library plugin に app 専用ビルド型を複製しない（#196756）」「[Linux] glBlitFramebuffer 無し合成時のレイヤ位置修正（#196418）」「DevFS.create の VM ファイルシステムエラー処理（#196895）」「[FGP] split-APK の versionCode オフセット（#196923）」など、ツール／Linux 描画／Android ビルドの回帰修正が主だ。一方で肝心の release-tracker #196743 は依然 OPEN、チェックリスト（CP マージ→Dart 版更新→engine hash pin→changelog→postsubmit 検証→MPA で push→SDK Archive 確認→告知）は全項目 未チェック。Dart 版更新も無く、3.50.1 は Dart 3.14.0 据え置きの見込みだ。

あわせて：画面遷移の意匠は公式 animations で既製化できる

リリース待ちの間に効くのが、公式 animations 3.0.0（publisher flutter.dev・BSD-3）。Material 3 の Material Motion 4種（Container transform / Shared axis / Fade through / Fade）を既製 widget 化したもので、3.0.0 は依存に 3.50 で入った新 material_ui ^1.0.0 を取るのが新しい。中核は2つ——タップで画面を埋めるように成長する OpenContainer（closedBuilder/openBuilder を渡す）と、child の ValueKey 変化で差し替える PageTransitionSwitcher。後者の transitionBuilder に SharedAxisTransition（horizontal/vertical/scaled の3軸）を返せば、オンボーディングやステップ遷移が「軸に沿って入れ替わる」動きになる。11/13 に見た flutter_animate が「任意 widget へエフェクトを連鎖」なのに対し、こちらはページ/コンテナ遷移の“型”担当、と住み分けると整理しやすい。

ひとこと

3.50.1 は「出荷直前だがまだ」。慌てて上げず 3.50.0 を pin したまま、#196743 の MPA push / SDK Archive のチェックを待つのが正解。待ち時間は、遷移の意匠を OpenContainer と PageTransitionSwitcher で標準化しておくと、アップグレード後の見栄え調整が楽になる。配色も ColorScheme.fromSeed（seed 1色＋contrastLevel）で宣言的に整えておきたい。
