tobi/disktree（Rust / GPUI・⭐約1.3k）

解決したい課題：ディスクを何が占有しているのかが分からず、不要ファイルを見つけて削除する作業が面倒だという、誰もが持つ低レイヤーの不満。提供する機能：ディスク使用量をツリーマップで可視化し、大きい項目をその場で削除できるネイティブ GUI。Zed 由来の GPU レンダラ GPUI で高速描画する。なぜ今急上昇か：Shopify CEO の Tobi Lütke 本人が公開し、約2日で約1.3k スター（平均 約650★/日）。作者の知名度と、単一バイナリの実用性志向が拡散を後押しした純モメンタム枠だ。

Aureliengmz/clearwater（HTML / WebGL2・⭐約450）

解決したい課題：フォトリアルな水面表現は通常、外部ライブラリやビルド工程を伴い敷居が高い。提供する機能：依存もビルドも一切使わず、1つの HTML ファイルだけで屈折・波・光の揺らぎ（コースティクス）をリアルタイム描画する WebGL2 デモ。なぜ今急上昇か：公開約3日で約450 スター。「依存ゼロ・単一ファイルで本物のような水が動く」インパクトと、コピペで即動く教材性の高さが拡散要因。Web 表現／シェーダ入門の実例として読める。

brannondorsey/chattervox（TypeScript・⭐約790）

解決したい課題：インターネットに依存せず、なりすましを防ぎながらテキストメッセージをやり取りしたい。提供する機能：アマチュア無線の AX.25 パケット通信の上で、デジタル署名とバイナリ圧縮に対応したチャットを行うプロトコル／CLI。電波でメッセージを送受信し、署名で送信元を検証する。なぜ今急上昇か：2018 年公開の既存リポだが、この日の Trending 日次で当日 +227 と再浮上。ネット非依存の通信手段への関心が背景と見られる。
