8月リリース目前のFlutter 3.44系 総点検 — ImpellerがAndroid既定・Material/Cupertino分離、AOTでraster約50%短縮

現行安定は3.44.6/Dart 3.12.2。3.44はImpellerがAndroid既定でSkia撤去・Material/Cupertino分離・AI強化。ImpellerのAOTでraster約50%短縮・バッテリー約17%減、予算はraster<4ms(60fps)/frame<8.3ms(120fps)。

📅 2026年8月1日 ⏱ 約2分 🔗 出典 3 件

Flutter は年4回（2/5/8/11月）の機能リリースで、次は2026年8月。区切り前のいまは、現行安定版Flutter 3.44.6 / Dart 3.12.2（2026-07-09）で足場を固める好機だ。

何が新しいか：3.44の3本柱は、ImpellerがAndroidの既定になりSkiaがコアから撤去、Material・Cupertinoがコアから独立パッケージへ分離、そしてAIツーリング（Agentic Hot Reload・Generative UI）の強化。Dart 3.12は private named parameters・primary constructors(experimental)・dot shorthands で定型コードを削減する。2026ロードマップ『Finishing the Job』は Android の Impeller 移行完遂と Web の WebAssembly 既定化を掲げる。

仕組みとパフォーマンス：Impeller はAOT（ビルド時）シェーダー事前コンパイルでランタイムのシェーダージャンクを排除し、iOSは Metal、Androidは Vulkan をネイティブ利用する。結果、複雑シーンでframe rasterization を約50%短縮、アニメ重負荷ではSkia比 約17%低いバッテリー消費。目安は60fps=raster<4ms、120fps=frame<8.3ms（UIスレッド4ms＋Rasterスレッド4ms）。フレーム予算は 60fps=16ms / 90fps=11ms / 120fps=8.3ms。

自分が試すなら：8月アップデート前に flutter --version で 3.44.6 を確認し、const ウィジェットと RepaintBoundary の戦略配置で再ビルド/再描画を削る。60Hz端末では MediaQuery でリフレッシュレートを取得して120fps狙いの過剰最適化を避ける（バッテリーの無駄）。状態管理は新規ならRiverpod 3.3.x＋codegen、監査・大規模はBloc 9が基本線。注意点：Material/Cupertino が別パッケージ化されたので、移行時は依存とimportを点検する。まとめ：8月の機能リリースは3.44の地ならしの上に来る。const/RepaintBoundary/Impellerで足場を固めておこう。
