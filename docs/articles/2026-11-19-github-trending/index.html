getarcaneapp/arcane（Go・⭐約9.5k）

解決したい課題：Docker コンテナや Compose スタックの運用を、CLI コマンドの暗記や寄せ集めの管理画面に頼らず、誰でも扱える形にしたい。提供する機能：バックエンド Go＋フロント SvelteKit で、コンテナ・Compose・スタックをモダンな Web UI で一元管理するセルフホスト型ツール（BSD-3-Clause・forks 約344）。本日 +547 は総⭐約9.5k に対し率約5.8%＝当日最高率級。AI 一色のトレンドに対する『実直なインフラ系×Go/Svelte』という多様性と、vendor ロックインの無いセルフホストの手触りが評価されている。

p-e-w/heretic（Python・⭐約42k）

解決したい課題：ローカルで動かす LLM の、過剰な拒否（検閲）・冗長な常套句（slop）・過度な迎合（sycophancy）を、高価な再訓練なしで手元で調整したい。提供する機能：訓練せずに数学的な steering でこれらを取り除く『abliteration』ツール（AGPL-3.0・forks 約4.3k・既定動作は拒否除去）。コンセプトは『Modify, rather than merely run, language models＝モデルをただ動かすのでなく改変する』。本日 +620（率約1.5%）。エージェント/スキル束が並ぶなかで、LLM 内部をいじるモデル工学という別軸の新規性が面白がられている。※AGPL-3.0 なので開発ツール利用は問題ないが製品組み込みは要注意。

cursor/plugins（TypeScript・⭐約17k）

解決したい課題：コーディングエージェント（Cursor）を社内ツールや SaaS と連携・拡張したいが、共通の拡張仕様が無いと各自バラバラの作り込みになる。提供する機能：Cursor 公式のプラグイン仕様と、GitHub・Salesforce・Playwright・Cursor SDK 等の公式プラグイン群を束ねたリポジトリ（MIT・forks 約1.3k）。各プラグインは .cursor-plugin/plugin.json マニフェストを持つ独立ディレクトリという明快な構造。本日 +315（率約1.9%）。エージェント拡張エコシステムが公式に一段進んだニュースとして話題化し、プラグイン機構の設計は .claude/skills+agents 構成の参照にもなる。

ひとこと：自分が今すぐ触るなら、セルフホスト運用に直結する arcane。設計の参照としては、独立ディレクトリ＋マニフェストという素直な拡張モデルの cursor/plugins が学びになる。heretic はローカル LLM をいじる“実験の面白さ”枠だ。
