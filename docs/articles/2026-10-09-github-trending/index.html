10/9の話題リポジトリ — ブラウザ常駐エージェント・公開データの3D地球・依存ゼロのローカルMoE推論

本日のモメンタム枠3本を貫くのは"身近さ"——ブラウザ拡張・ブラウザ完結・一般的なコンシューマ機で動く、の3本。

📅 2026年10月9日 ⏱ 約3分 🔗 出典 3 件

本日のGitHub日次は老舗が上位を占める古いキャッシュ状態だったため、Trendshift日次＋複数トラッカー（gittrend・gitnova・coddykit）を突き合わせ、総スターは各GitHubページで実測検証して選んだ。急上昇の"モメンタム枠"3本を貫くのは「誰のPCでもすぐ動く身近さ」——ブラウザ拡張・ブラウザ完結・一般的なコンシューマ機で動く、という共通点だ。

webbrain-one/webbrain（JavaScript・⭐約694）

解決したい課題。AIエージェントは強力だが、導入にCLIや専用アプリのセットアップが要り「今見ているページを手伝ってほしい」という日常作業には重い。提供する機能。ブラウザのサイドパネルにエージェントを常駐させ、開いているページへの質問に加えクリック・入力・ページ遷移まで代行する。モデルはBYOキー、Chrome/Firefox対応のMIT拡張で、インストール即利用。実測スターは小さいが、日次トラッカーで本日2位表示と増加"率"が突出した。

bilawalsidhu/gods-eye-view（JavaScript・⭐約48.6k）

解決したい課題。航空機・船舶・衛星・地震・公開カメラといった"今"の公開データは散在し、関連づけて俯瞰する手段がない。提供する機能。それらのライブフィードをフォトリアルな3D地球儀上にリアルタイム表示する。CesiumJS＋バニラJS＋Viteでサーバ不要・ブラウザ完結、MIT。エージェント/スキル一色のトレンドのなか"非AIのデータビジュアライゼーション"として突出し、既知クリエイター発で各所に拡散した。

JustVugg/colibri（C・⭐約40.6k）

解決したい課題。大規模MoEモデルはVRAMを食い、クラウドAPIはコストがかさむ——手元の普通のPCで動かしたいという実需に既存ランタイムは応えきれない。提供する機能。依存ゼロのC製推論エンジンで、エキスパートの重みをディスクからストリーミングすることで、VRAMの限られたコンシューマ機でも巨大MoEを実行する。Apache-2.0。ローカル/エッジ推論という"非クラウドAI基盤"の系譜で高増加枠に入った。

まとめ・自分が試すなら。まずwebbrainをBYOキーで入れ、日常ブラウジングのエージェント化を体験するのが最短。可視化の着想はgods-eye-viewのデータ地球が刺激的で、毎朝digestのビジュアル表現の参考になる。コスト最適化の実験ならcolibriでローカルMoEを一度動かしてみたい。
