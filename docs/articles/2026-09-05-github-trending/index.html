今日の3本を貫くのは「アプリ層のエージェント/スキルが席巻する上位に、別レイヤーの新規リポが割り込んだ」こと。デザイン、科学、AI推論評価という毛色の違う3本が、それぞれ具体的な課題設定の鋭さで急伸した。

lnkiai/m3e-canvas（TypeScript・⭐約900・New 2026）

解決したい課題：デザインとコード生成の断絶。頭の中の画面イメージを、コーディングエージェントに正確に伝える標準的な手段がなかった。提供する機能：ブラウザ上で Material 3 Expressive（M3E） の UI 画面をスケッチし、それをそのまま「vibe-coding」用のプロンプトに変換する。『M3E準拠でスケッチ→エージェント向けプロンプト化』という具体性がデザイン×vibe coding の流れに刺さり、本日 Trendshift 日次1位に急伸した。エージェント一色の上位にUI/デザインの多様性を足す純モメンタム枠。

K-Dense-AI/scientific-agent-skills（Python・⭐約43k・+7.2k/8d≈17%）

解決したい課題：汎用エージェントには文献調査・実験計画・解析といった科学的ワークフローの型が欠けている。提供する機能：任意の AI エージェントを「AIサイエンティスト」化するスキルの大型ライブラリで、科学ワークフローを段階実行させるスキル束を提供する（自称「科学用途で#1」）。スキル運用ブームの中で研究者層に強く刺さり、8日で+7.2k（総約43k）と本日候補で最大級の実測モメンタム。「科学」という一段深いドメインで多様性に効く。

pathwaycom/arc-task-gen（Python・⭐約10k・+2.7k/8d≈27%）

解決したい課題：一般化推論ベンチ ARC-AGI に対し、評価に使える新規タスクが不足している。提供する機能：公開評価セットに分布を合わせたARC-AGI-1 形式の独自タスクを量産する（Pathway 発）。推論モデル評価への関心の高まりの中で、増加率約27%と本日最高クラスの伸び。アプリ層が席巻する中で「AI推論研究」という骨太レイヤーが上位入りする新規性も効いた。

まとめ

自分が試すなら、まず m3e-canvas で普段のUI着想をプロンプト化する体験を試したい。研究寄りの探索をエージェントに任せたいなら scientific-agent-skills、推論モデルの評価データを自作したいなら arc-task-gen が刺さる。共通するのは「曖昧な作業を、型のある入力へ変換する」着眼だ。
