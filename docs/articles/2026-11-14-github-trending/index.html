今日の3本は一見バラバラ（グラフィックスSDK／チームチャット／レビューワークスペース）だが、後ろ2本には human-in-the-loop＝人が要所で止めて承認・指示するという共通線が通る。エージェントを“速く動かす”より“止められる”ことに価値が移りつつある局面を映している。各リポジトリについて「解決したい課題」と「提供する機能」を分けて見ていく。

apex-compute/ANR（C++・⭐1.4k）

解決したい課題：リアルタイム描画では「解像度を上げる」と「フレームレートを保つ」が両立しにくい。従来は職人芸のシェーダ最適化やハード依存のアップスケールに頼ってきた。提供する機能：フレーム生成（FG）・超解像/アップスケール（SR）・レイ再構成＝デノイズ（RR）を束ねた、DLSS/FSR系のニューラルレンダリングSDK（Apex Compute製）。なぜ急上昇：created 2026-11-11＝公開約3日で1,449★・forks21（日平均約483★/日と本日計測で最速級）。AIチャット/エージェント一色のトレンドの中で希少なグラフィックス/低レイヤー題材が目を引いた格好だ。ライセンス未記載（beta段階）＝組込時は要確認。

agentes-chat/agentes-chat（TypeScript・⭐1.3k）

解決したい課題：人は Slack、AIは各ツールと、会話とエージェント操作が分断されがちで、機微データを外部SaaSに預ける不安もある。提供する機能：人と複数のAIエージェント（Claude/Codex/Gemini/Grok等）が同じチャンネル/DMで協働するセルフホスト型のOSS Slack代替。human-in-the-loop・computer-use・ブラウザ自動化・MCPを備える。なぜ急上昇：created 2026-11-09＝公開約5日で1,337★・forks227（日平均約267★/日）で、本日 GitHub Search の claude-code/mcp 両トピックに登場＝複数ソースで確認できる急上昇。セルフホストで機微データを自組織内に留められる点が、1人×複数PJ運用の設計参照になる。AGPL-3.0（SaaS提供時は要注意）。

backnotprop/plannotator（TypeScript・⭐10.4k）

解決したい課題：エージェントが出すプラン・仕様・差分・PRは量も粒度もバラバラで、人が「どこで止めて指示するか」を掴みにくい。提供する機能：エージェント生成のプラン/仕様/Markdown/HTMLや差分・PRを1つのInboxでレビュー→注釈→フィードバック送信できる human-in-the-loop のレビュー・ワークスペース（Claude Code/Codex/OpenCode/pi 等に対応）。なぜ急上昇：本日 Trending(daily) に当日+100★（総10,425★に対し率約1.0%）で登場。総スターは大きいが本日明確な増加があり採録。実行の可視化や自動ループとは別レイヤーの「レビュー/注釈」に特化している点が、要所で承認を挟みたい運用に直撃する。Apache-2.0。

まとめ：自分が試すなら

いま自分の運用（1人×Claude Code×複数PJ横断）に最も刺さるのは plannotator。実行を速めるより「エージェント成果物を一箇所に集めて要所で止める」観測性が足りていないからだ。agentes-chat は将来の集約像（会議/タスク）の設計参照として読む価値がある。ANR は畑違いだが、“AI飽和の中で低レイヤーが刺さる”という需要の揺り戻しとして面白い。いずれも Tier B＝鵜呑みにせず評価枠で触る前提で。
