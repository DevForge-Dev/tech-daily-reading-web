本日の急上昇はAI一色の飽和局面でも純モメンタムで突き抜けた3本。貫く傾向は明快で、「ローカルで・速く・隔離して動かす」——クラウド頼みからの揺り戻しが新規リポジトリの共通テーマになっている。それぞれ「どんな課題を解こうとしているか」と「何ができるか」を見ていく。

Edge0-AI/Edge0（Python・⭐約8.7k）

解決したい課題は「35Bクラスの大型モデルはノートPCやスマホには重すぎて載らない」こと。提供する機能は、重みをSSDからストリーミングし、学習済みルーターが次に必要な重みを1ステップ先読みでロードすることで、35B級MoEを約2.5GB RAMで動かすオンデバイス推論エンジン。Mac/iPhone/Android/Windows対応(Apache-2.0)。created 2026-09-08＝約52日で実測約8,720★/forks1,272(日平均約168)まで伸び、trendshift日次にも掲載。急上昇の理由は、省メモリ×マルチプラットフォームという旬テーマを“スマホで35B”という大胆な見出しで突いた点だ。

milind-soni/OpenMausBot（TypeScript・⭐約7.4k）

解決したい課題は「Claude/Codex/Grokなど複数のAI系CLIを束ねつつ、エージェントが生成・実行するコードをどう安全に隔離するか」。提供する機能は、それらを1つのチャットアプリに統合し、各ボットに専用の仮想マシン(クラウドPC)を割り当てて作業させるOSSのGrok Bot代替(Apache-2.0)。急上昇の理由は、GitHub日報(Qiita 2026-10-30)で+約1,190・率約16%と当日のFirst Timer筆頭に躍り出たこと。ボット単位のVM隔離という設計が、エージェント実行の安全性という関心に刺さった。

l0ng-ai/openidea（TypeScript／ネイティブはRust・⭐約1.0k）

解決したい課題は「高機能な重量級IDEは起動も動作も重い」こと。提供する機能は、IntelliJ IDEA風のキーマップ/ツールウィンドウ/Search Everywhereに、エディタ・補完・デバッガ・Git・ターミナル・DB/HTTPクライアントを統合し60+言語に対応した、Rustでネイティブ再構築した高速IDE(Apache-2.0)。急上昇の理由は、公開わずか9日で実測約1,030★(日平均約114・率高位)と伸び、「重量級IDEのネイティブ化」という新規性が拡散したこと。

自分が試すなら——まずEdge0を手元のMacで動かして“35Bが本当に2.5GBで回るか”を体感し、エージェントを多用する自分の運用にはOpenMausBotのVM隔離の思想を参考にする。openideaはまだ公開9日なので、常用より“Rustネイティブの体感速度”の偵察用に触るのが現実的だ。
