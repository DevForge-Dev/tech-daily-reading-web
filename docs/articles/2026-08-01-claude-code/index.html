8月のコスト転換点 — 週次+50%増枠は8/19まで延長、Sonnet 5プロモは8/31終了で9/1から$3/$15＋トークナイザ増、/forkと暴走防止キャップ

利用枠の一時増枠が8/19まで延長、既定Sonnet 5のプロモ価格が8/31で終了し9/1から標準$3/$15＋実効トークン1.0〜1.35倍、/forkのバックグラウンド化とWebSearch/サブエージェントのキャップ(既定200)。9月以降は『どう安く安全に回すか』が主戦場。

📅 2026年8月1日 ⏱ 約2分 🔗 出典 3 件

週明けの予算・運用計画に効く更新が3つ重なった。利用枠の一時増枠が延長され、既定モデルの価格改定が目前に迫り、暴走防止のガードレールが入った——いずれも『どれだけ賢いか』より『どう安く安全に回すか』に関わる話だ。

何が新しいか：まず週次利用上限+50%ブーストが当初期限から2026年8月19日まで延長。Pro/Maxに自動適用され、並列エージェントや大規模作業でクォータが律速になる人ほど恩恵が大きい（一部で /usage 表示に増枠が反映されない報告あり）。あわせてFable 5が Max・Team Premium で選択可能に。次に価格：既定のSonnet 5のプロモ（100万トークンあたり入力$2／出力$10）が8月31日で終了し、9月1日から標準の入力$3／出力$15へ。単価は約50%増で、さらに更新トークナイザが同一コンテンツを従来比1.0〜1.35倍のトークン数に写像するため、実効コストは価格改定幅以上に膨らみうる。最後に安全：/forkが会話をバックグラウンドセッションへコピーして分岐できるようになり、WebSearchのセッション呼び出し上限（既定200）とサブエージェント生成キャップ（既定200）が検索ループ・委譲の暴走を抑える。

仕組みの噛み砕き：コストは『単価 × トークン数』で決まる。9月以降はこの両方が同時に上がるので、単価だけを見て『+50%』と見積もると外れる。同じPRレビューでも、コンテキストに載せる差分が大きいほどトークン係数(×1.35)の効きが大きくなる。

自分が試すなら：8月中に典型ワークロード（中規模PRレビュー1本、横断リファクタ1本など）の入出力トークンを実測し、×1.35と新単価で9月の月額を先に出しておく。定型作業は effort を絞り、重い設計だけ厚く配分する。注意点：増枠が /usage に出ないことがあるので数字は自分のログで確認。/fork のバックグラウンド化は便利だが、長時間セッションでサブエージェント200キャップに当たるなら委譲設計を見直す。ひとことまとめ：モデル選定より『トークンをどう減らすか』が9月の主戦場になる。
