11/1の話題リポジトリ — 鍵もクラウドも足さずに動くAI：hex・apfel・harvey

AI一色で新顔の少ない静かな日。拾えた3本を貫くのは「新しいクラウドAPIキーを足さずにAIを動かす」——端末内で完結する音声入力、Mac内蔵AIをCLIから、既存のClaude Code/Codexで回す自律エージェント。

📅 2026年11月1日 ⏱ 約3分 🔗 出典 3 件

本日はAI一色の飽和かつ新規first-timerの少ない静かな一日。そんな中で選んだ3本に共通するのは「新しいクラウドAPIキーを足さずにAIを動かす」という地面だ。端末内で完結する／Mac内蔵のAIを使う／手元のエージェントで回す——クラウドAPI前提への静かな揺り戻しとして、それぞれ「解決したい課題」と「提供する機能」を見ていく。

anomalyco/hex（Rust・⭐約2.0k）

解決したい課題は「音声入力を使いたいが、発話をクラウドに送りたくない」こと。提供する機能は、ショートカットを押している間だけ話し、離すと任意のアプリに貼り付けられる macOS 向けのローカル完結型音声ディクテーション(Rust・MIT)。音声認識は端末内(オンデバイス)で動きクラウドに送らない。急上昇の理由は、created 2026-07-17 の新しめのリポが当日 +約289(実測約1,987★/forks124・増加率約14.5%＝当日計測組で最高位)まで伸びた点。AI一色の飽和局面で希少な生産性/アクセシビリティ×プライバシー(ローカル完結)の切り口が拡散を押した。Linux ベータも進行中。

Arthur-Ficial/apfel（Swift・⭐約6.5k）

解決したい課題は「Mac に既にある無料の AI を、鍵も課金もなしにコマンドラインから使いたい」こと。提供する機能は、Mac 内蔵の Apple Intelligence を CLI ツール／OpenAI 互換サーバー／対話チャットとして使えるようにする(Swift・MIT)。API 鍵不要で推論は完全オンデバイス。急上昇の理由は、trendshift 日次掲載の当日上位(実測約6,545★/forks251)で、クラウド API 前提の飽和局面に「既にある AI を鍵なしで、しかも OpenAI 互換で」という新規性を持ち込んだこと。Swift/Apple/オンデバイスという言語・プラットフォーム多様性枠も兼ねる。

ethanplusai/harvey（Python・⭐約3.7k）

解決したい課題は「営業の発掘からクロージングまでの定型フローを、専用の AI API を契約せずに自動化したい」こと。提供する機能は、Claude Code/Codex 上で動く自律型 AI 営業エージェントで、見込み客の発掘→コールドメール作成→キャンペーン送信→返信対応→商談設定までを自動で回す(Python・MIT・API 鍵不要)。急上昇の理由は、当日 +約244(実測約3,707★/forks765・増加率約6.6%)のモメンタムに加え、「手元の Claude Code/Codex をそのままエージェント基盤にする」構成が、別途 API 契約なしに自律エージェントを立てたい層に刺さったから。MIT で社内利用・組み込みも可。

自分が試すなら——まず apfel を入れて Mac 内蔵 AI を OpenAI 互換サーバーとして立て、軽い要約や分類をローカルでさばけるかを実測する(鍵も課金もなしで効けば定番化)。hex はオンデバイス音声入力の手触りを確かめる偵察用に、harvey は「Claude Code をエージェント実行基盤にする」設計パターンのストックとして読むのが現実的だ。3本とも派手な新規プロダクトではなく、クラウドAPI前提への揺り戻しとして現れた“手元で動かすAI”の芽として記録しておきたい。
