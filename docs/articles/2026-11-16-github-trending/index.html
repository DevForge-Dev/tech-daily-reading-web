今日のモメンタム上位3本は、Go製のエージェント・オーケストレーション、金融ドメインのClaude Skills、ローカルFFmpegのMCPツールと見事にバラバラだ。だが重いクラウドやAPIキーに頼らず自前・ローカルで動き、コーディングエージェントに「役割」や「専門スキル」を与えるという一点で通じている。AIエージェント一色の局面で、こうした「自己ホスト・ローカル完結」の層が急伸しているのが今日の傾向だ。

Tencent/LoopForge（Go・⭐1.4k）

解決したい課題：「fix this bug」の一発頼みはrun依存で不安定——計画スキップ・テスト忘れ・自己レビュー・途中停止が起きる。提供する機能：チャットで要件を伝えるとDockerサンドボックスを開いてリポをチェックアウトし、計画・実装・レビュー・テストを別プロンプト／別executor／別model／別Skills・MCPの役割に分離、要所に人間承認ゲートを置き、ノード状態・ツールトレース・ログを一元観測して失敗ノードから再開できる。実績ある流れはSOP（標準ワークフロー）として保存し再利用。CodeBuddy/Codex/Claude Code/OpenCode/Cursor CLIなど10種のCLIをexecutorに選べ、すべて自前インフラ上・MIT。なぜ今：本日の日次トレンドで+484（総⭐1,439に対し増加率約33.6%＝当日最高率級）、AIエージェント運用の「チーム化」を正面から狙う点が刺さった。

tradermonty/claude-trading-skills（Python・⭐5.5k）

解決したい課題：時間の限られた個人投資家は、相場レビューやリスク管理が場当たりになりがちだ。提供する機能：相場レビュー・リスク管理・トレード計画・ジャーナリング・継続改善をClaude Skillsベースで構造化するワークフロー集。長期投資・ETF・配当を核にしつつ、条件が良い時だけ規律あるスイングを衛星戦略として足す設計で、「売買判断をAIに丸投げしない／シグナルサービスでも利益保証でもない」と明記する。なぜ今：本日+707＝クリーン新規で当日最大の増加数（総⭐5,489に対し率約12.9%）。TypeScript/UIに偏りがちな当日トレンドの中で、AI×金融という非・開発ドメインの希少枠。日本語READMEあり・MIT。

kajisho5/ffmpeg-skill（Python・⭐6.0k）

解決したい課題：動画編集をエージェントにやらせたいが、クラウドやAPIキーは重く、素材をアップしたくない。提供する機能：コーディングエージェント（Claude Code/Cursor/Codex等のMCPクライアント）にローカルFFmpegの42ツール（字幕アニメ／カラオケ、9:16リフレーム、無音カット、ラウドネス正規化 -14LUFS等）をCLI＋MCPで与え、エージェントが編集→自分で出力を検証する。npx ffmpeg-skillで導入でき、クラウド/APIキー不要のオフライン完結。各ツールのMCP定義は同じargparseパーサからランタイム生成する「SPEC」で、CLIと乖離すればCIが落ちる契約駆動設計だ。なぜ今：公開約2.4か月で⭐5,953、本日+285（率約4.8%）の継続モメンタム。Python標準ライブラリのみ・MIT。

まとめ：自分が試すなら

3本は「エージェントに何を授けるか」の3方向——運用の骨格（LoopForge）、ドメインの型（trading-skills）、手元の実行環境（ffmpeg-skill）だ。まず試すならffmpeg-skill（npx一発でローカル動画処理をエージェントに繋げられ、SPECの契約駆動も学べる）。チーム運用に関心があればLoopForgeの「役割分離＋人間ゲート＋観測＋SOP再利用」という設計思想が、Skillsの書き方の参考にはtrading-skillsの「丸投げしない」構造化が効く。いずれもMIT/自己ホストで、読んで学ぶ素材として素直だ。
