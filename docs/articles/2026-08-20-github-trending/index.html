s1dashu/ip-as-logo-skill（—・⭐1.1k）

解決したい課題：プロダクトやキャラのロゴを起こすのは毎回手間で、トーンもバラつく。デザイナー不在の個人開発では特に「それっぽい統一感」を出すのが難しい。提供する機能：企業やプロダクトのIP（キャラ）を、影を排し角丸・控えめな立体感でトーンを揃えた擬似スキュアモーフィズム調のマスコット風ロゴに一発で起こすCodexスキル。Codex/Claude Code等のエージェントに読ませれば即生成できる。誰でも欲しい用途の明快さが刺さり、本日Trendshift日次1位（New 2026）に躍り出た。

volcengine/OpenViking（—・⭐439）

解決したい課題：エージェント運用では記憶（Memory）・ナレッジRAG・スキルがバラバラの仕組みに分散しがちで、横断的なコンテキスト管理が煩雑になる。提供する機能：この3つを1つに束ねた自己進化型コンテキストデータベース。運用に沿ってコンテキストを蓄積し、記憶＋RAG＋スキルを単一基盤で扱える。VolcEngine（ByteDance）公式という信頼感もあり本日日次7位（New 2026）。エージェントの記憶運用やRAG最適化の参照実装として効く。

dob323/session-kit（—・⭐286）

解決したい課題：エージェントがSSH越しに作業すると、セッションが切れて状態が失われたり、実行範囲が広すぎて危険だったりする。提供する機能：Linux/macOSで永続SSHセッションと厳密なローカル安全制御を両立するツールキット。Claude Code/Codex/シェル向けに、実行範囲を絞る安全ガードを効かせつつ長時間のセッションを維持する。本日日次11位（New 2026）。承認フローや安全実行の運用に直結する。
