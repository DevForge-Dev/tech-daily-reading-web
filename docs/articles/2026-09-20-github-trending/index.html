robbietilton/Compositor（言語: 非公開・⭐スター非公開／Trendshift日次1位）

解決したい課題：写真・画像制作の中核ツールがサブスク型の商用製品に寡占され、月額課金や重さに不満を持つ Mac ユーザーが多い。提供する機能：macOS ネイティブの「Photoshop 代替」を掲げ、レイヤー編集など画像制作の中核機能を買い切り・ネイティブで提供する。エージェント系が上位を占める中で非AIのクリエイティブ枠が日次1位に立ったこと自体が新規性で、「王道の切り口はまだ刺さる」ことを示した。

trycua/cua（言語: 非公開・⭐スター非公開／Trendshift日次3位・言及約300）

解決したい課題：GUI 操作エージェント（computer-use）を単発で動かす段階から先へ進めない——複数 OS での並列運用や、動作の学習・評価の仕組みが弱い。提供する機能：computer-use 2.0 をスケールさせる基盤として、オープンソースのドライバ・クロス OS のマシン群（fleet）・学習/評価/データ生成のベンチマークを備える。表彰台圏に定着しており、エージェントを「再現評価まで回す」段階へ引き上げる位置づけが支持されている。

vercel-labs/json-render（言語: 非公開・⭐スター非公開／Trendshift日次11位）

解決したい課題：LLM の生成結果を自由な HTML としてそのまま描くと、安全性・保守性・レイアウト崩れの問題が出る。提供する機能：Vercel Labs 公式の「生成 UI（Generative UI）」フレームワークで、LLM 出力を JSON 記述に落とし込み、定義済みの安全な UI コンポーネントへレンダリングする。Next.js（App Router）標準スタックと親和性が高く、AI チャット回答のリッチ化や AI 生成フォームの画面化に直結する。

ひとことまとめ

自分が今日1本試すなら、Next.js 前提の json-render を生成 UI の実験台に置くのが最短。「作る道具（Compositor）」「動かす基盤（cua）」「橋渡し（json-render）」という三層が同日に並んだのが今日の面白さだ。
