Claude Code

デスクトップに内蔵ブラウザ、/doctor が「診断→修正」へ — 強力なエージェントを健全に保つ地固めの回

Cmd+Shift+B でアプリ内ブラウザが開き、/doctor は未使用 Skills/MCP や CLAUDE.md 肥大を洗って直す。派手さより「長時間・安全に回す土台」を固める更新。

📅 2026年8月12日 ⏱ 約2分 🔗 出典 4 件

今回の目玉は2つ、いずれも日々の運用を軽くする地固めだ。ひとつは Claude Code のデスクトップ版にタブ型の内蔵Webブラウザが付いたこと（macOS は Cmd+Shift+B／Windows は Ctrl+Shift+B）。Claude がドキュメントやデザイン、任意サイトを開いて読み取り・クリック・操作でき、ローカル開発サーバーのプレビュー確認と同じ感覚で Web アプリを検証できる。ブラウザはサンドボックス化され閲覧セッションを保持するか選べ、外部サイト上の操作は安全性分類器がレビューする。Chrome を別に立ち上げずアプリ内でテスト・調査が完結するのが実利だ。

もうひとつは /doctor の刷新。従来の「読み取り専用レポート」から、問題を診断してその場で修正する運用へ進化した。インストールの健全性を点検し、コンテキストコストに見合わない未使用の Skills・MCP サーバー・プラグインを洗い出す。ローカル CLAUDE.md とリポジトリ管理版の重複を排除し、コードベースから導出できる記述の削減を提案、遅い Hooks も警告する。セットアップの肥大化を抑え、コンテキストを健全に保つメンテ機能だ。加えて 8月のまとめ記事では、auto mode がトランスクリプト改ざんをブロック、Remote Control をセッション名で開始、subagent スポーン上限の撤廃なども入った。

使いどころ。実務ガイド各所が繰り返す原則は「良いプロンプト」より良いハーネスを組むこと。役割を分けると重複が減る——強制は Hooks／権限、知識は Skills、委譲は Subagents、常時適用の指針だけを短い CLAUDE.md に置く。/doctor はまさにこの規律を機械的に点検してくれる相棒になる。内蔵ブラウザは、生成した UI の目視確認やドキュメント参照をワンウィンドウで回せる。

注意点。Claude Code は日次で小刻みにパッチが出るため、CI やスクリプト連携では固定バージョン運用が無難。内蔵ブラウザで外部サイトを操作させる際は、分類器が挟まるとはいえ未知リンクの安全性は自分でも確認する姿勢が要る。/doctor の削減提案は機械的なので、消す前に本当に未使用か一度確認したい。

ひとことまとめ：新機能というより「強力なエージェントを長時間・安全に・軽く回す」ための足回り強化。並列・自動運用ほど恩恵が大きい回だ。
