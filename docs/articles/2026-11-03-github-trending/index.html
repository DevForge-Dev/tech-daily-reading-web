11/3の話題リポジトリ — AI飽和の中で光った『開発体験』の3本：blaze・reylo・dimensional-drawing

ツール飽和のAIトレンドの中で、ビルドを速くする・SQLを型で守る・UIを寸法図にする、開発現場に直結する3本。各リポジトリの「解決したい課題」と「提供する機能」を対で読む。

📅 2026年11月3日 ⏱ 約3分 🔗 出典 3 件

導入。 本日のGitHub Trendingも大半はAIエージェント/スキル系と、移植・DRM解除等のグレー系で埋まる飽和局面だった。その中で純粋に「開発体験（DX）を速く・安全にする」実務直結の3本を拾う。ビルドを刻む blaze、SQLを型で守る reylo、UIを寸法図に落とす dimensional-drawing——いずれも作者の信頼性か完成度で伸びた、量産AIツールではない新星だ。

indexable-inc/blaze（Rust・⭐約1.9k）

解決したい課題。 Rustの cargo/rustc は型安全と引き換えにビルド/再ビルドが遅く、編集→確認のループが詰まる。提供する機能。 cargo のドロップイン置換として blaze と打つだけで、cranelift JIT＋ホットリロードにより増分・ミリ秒単位で再ビルド（「最大92倍速」をうたう）。独自Rustツールチェーンを同梱し curl | sh 一発で導入でき、rustupの有無を問わない。公開約15日で実測約1,912★（日平均約127★/日）——AI一色の中で希少な、純DXの速さで拡散した。Apache-2.0。

colinhacks/reylo（Rust実装／TypeScript向け・⭐約1.5k）

解決したい課題。 生SQLは書きやすい反面、戻り値の型がTS側に伝わらず、ORMやcodegenパイプラインを挟むとビルド/CIの段取りが増える。提供する機能。 .sql ファイルをTypeScriptへ型推論付き・コード生成ゼロで直接importでき、select ... の行型・パラメータ型が完全に型付けされる。Zod作者 colinhacks の新作（公開約13日・実測約1,475★）で、Supabase（PostgreSQL）×TS構成に直撃。コード生成を挟まない＝既存Turborepoの段取りを増やさず試験導入できる点が刺さった。MIT。

enesozturk/dimensional-drawing（HTML・⭐約1.7k）

解決したい課題。 UIコンポーネントの「余白・ギャップ・角丸・レイヤー・配置」といった構造仕様が口頭/スクショ頼りだと、誰かに渡しても同じUIを再現できない。提供する機能。 コンポーネントを渡すと、Appleが各デバイスに公開する「dimensional drawing（寸法図）」のような数値ラベル付き技術図面を1枚返すAgent Skill。コピーや本文は意図的に除外し、テキストが変わっても図が崩れない。公開約11日・実測約1,745★。UI品質レビューや、標準UIアセット/デザイン規約の共有に効く。MIT。

自分が試すなら。 日々Rustを触るなら blaze をまず curl | sh で体験、Supabase×TSの型安全を詰めたいなら reylo をRLS多数テーブルの読み取りで試す。UIレビューの属人化を減らすなら dimensional-drawing をデザイン規約の共有フォーマットに。3本とも許容ライセンスで製品組み込みも可能だ。
