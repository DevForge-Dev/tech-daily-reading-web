10/29のFlutter — Dart 3.13 primary constructorsが本番解禁、shader/Riverpod3/raster cacheも総点検

クラスヘッダ1行でフィールド＋コンストラクタを宣言するprimary constructorsが現stableで今すぐ使える。あわせてフラグメントシェーダの実装作法、Riverpod 3.xの一本化、RepaintBoundaryの「焼きすぎ」計測を読む。

📅 2026年10月29日 ⏱ 約4分 🔗 出典 5 件

この日はリリース・アニメ・状態管理・パフォーマンスの4本立て。まず本番で今すぐ効くのが Dart 3.13 の primary constructors だ。Dart 3.13.0（2026-08-12）で正式化され、現stable Flutter 3.47.8 / Dart 3.13.7 に載っている。beta限定の dot shorthands（3.14）と違い本番で使えるのが大きい。クラス名直後の括弧に final 型 名前 を並べるだけで、その場でフィールド化＋コンストラクタ生成——this. の繰り返しも初期化リストも要らない。

// 従来
class Temperature { final double celsius; Temperature(this.celsius); }
// primary constructors（3.13）
class Temperature(final double celsius);
// 呼び出しは従来どおり Temperature(21.5)

// named / const / private
class Config({required final String host, final int port = 8080}){ }
class const Meters(final double value);   // const は class と名前の間
class Store(final Cache _cache);          // private は引数名に _

const は class const Meters(...) とclassと名前の間に置く点が独特で、widgetのconst正準化に効くので移行時は維持したい。enumもヘッダ引数化でき、リダイレクト/factoryは本体に残し new ショートハンドで書く。移行を後押しする新lint（use_declaring_parameters 等）はあるが、dart fix の自動変換は未提供で書き換えは手動だ。

フラグメントシェーダは、.frag（頂点シェーダ非対応）を pubspec.yaml の flutter: shaders: に列挙→CLIがコンパイルしてアセット同梱。FragmentProgram.fromAsset() でロードし、FragmentShaderはフレーム間で使い回す（毎フレーム生成しない）。uniformは宣言順indexで setFloat／sampler2Dは setImageSampler（samplerはfloat indexを消費せず別カウント）、色はpremultiplied alphaで0.0–1.0正規化。座標は FlutterFragCoord().xy を使い gl_FragCoord は避ける。widgetへは flutter_shaders の AnimatedSampler でchildをui.Imageに焼いて渡すのが定石だ。

Riverpod 3.x（最新3.4.3）は2.xからの大刷新で、AutoDisposeNotifier／FamilyNotifier を Notifier に統合、プロバイダ別Ref型も単一 Ref に統一。StateProvider 等は legacy.dart へ移動した。初期化失敗時の指数バックオフ自動リトライ（既定200ms→倍々→上限6.4秒）、Ref.mounted によるasyncギャップ後の生存確認が実務で効く。offline永続化（persist()／riverpod_sqflite）とmutations（Mutation<T>→.run()）はまだ実験的で、ライフサイクル変更が「見えにくい形で既存を壊す」警告がある点に注意。

自分が試すなら：新規のデータクラス/小widgetからprimary constructorsを手で導入しconst正準化を崩さないか確認。パフォーマンスは debugPrintRasterCacheStatistics でmiss数を数えてから RepaintBoundary を「静的グリッドだけ」に絞る。落とし穴はRepaintBoundaryの付けすぎ（照合コストで逆に遅くなる）とRiverpod実験機能の本番投入。
