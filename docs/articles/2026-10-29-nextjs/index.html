10/29のNext.js — FABスピードダイヤルが「ほぼ標準機能」で組める時代（Popover API + @starting-style）

丸い主ボタンから子アクションが扇状/縦列に飛び出す定番UI。2026はPopover API＋@starting-style＋transition-behavior:allow-discreteでトップレイヤー・外側クリック閉じ・enter/exitアニメが標準だけで組める。

📅 2026年10月29日 ⏱ 約4分 🔗 出典 5 件

画面右下に浮く丸い主ボタン（FAB）を押すと、2〜6個のアクションが縦列や扇状に、時間差（stagger）＋スプリングで飛び出す——Gmailや各種SaaSに遍在する「スピードダイヤル」。見た目の割に実装は軽いが、素朴に作るとアクセシビリティ（aria-expanded無し・フォーカス迷子・Escape非対応）を落とす、display:none絡みで開きアニメが走らない、祖先のtransformでposition:fixedが崩れる、といった罠に落ちやすい。

何が新しいか。2026は Popover API ＋ @starting-style ＋ transition-behavior:allow-discrete（いずれもBaselineで出揃った）で、「トップレイヤー投入・外側クリック閉じ・Escape閉じ・enter/exitアニメ」をほぼ標準機能だけで組めるようになった。Material Design 3 Expressive も従来の "speed dial" を公式に FAB menu（2〜6アクション＋クローズボタン）へ置き換えている。

仕組みの肝は「開きが動かない問題」の解消だ。display:none→表示やPopoverのトップレイヤー投入は通常トランジションが走らない。そこで @starting-style に初期値を書き、transition に display と overlay を allow-discrete 付きで列挙すると、enter/exit両方が補間され閉じアニメ中も要素が残る。

.dial{ opacity:0; transform:translateY(8px) scale(.96);
  transition:opacity .25s, transform .25s,
             overlay .25s allow-discrete, display .25s allow-discrete; }
.dial:popover-open{ opacity:1; transform:none; }
@starting-style{ .dial:popover-open{ opacity:0; transform:translateY(8px) scale(.96); } }
/* 子の時間差 */
.dial > button{ transition-delay:calc(var(--i) * 40ms); }

stagger（時間差）は各子に transition-delay: calc(var(--i)*40ms)、閉じる時は逆順にすると「吸い込まれる」自然さが出る。動かすのは transform と opacity のみ＝コンポジタ合成で軽く、top/left/width のアニメ（リフロー）は禁物。放射配置はCSS三角関数 sin()/cos()（Baseline）で角度θ・半径rに散らすが、DOM順＝論理順を保ち見た目だけtransformで散らすのが鉄則だ。

Next.js（App Router）での組み込み：'use client' は必須だが小さなクライアント島に留め、<Fab/> だけclientにして中身は children でRSCを流す。設置は app/layout.tsx に置けばルート遷移で再マウントされず「ナビの度に勝手に開く」チラ付きを防げる。position:fixed が崩れる最大の救済がPopover APIで、top-layerに投入されクリッピングも重なり順も自動で超越する（Popover非使用なら createPortal(node, document.body)）。初期状態はSSR/CSR共に「閉」固定にしてハイドレーション一致を守る。

自分が試すなら：まずDisclosure＋Popover APIの最小形で作り、遷移アクションは <Link prefetch>、サーバー変更は <form action={serverAction}> ＋ useActionState で繋ぐ。落とし穴は prefers-reduced-motion:reduce の未対応（translate/stagger/scaleを止めopacityのみに）とタッチ標的44×44px未満、そして祖先の transform/filter/contain がfixedの基準を奪う点。
