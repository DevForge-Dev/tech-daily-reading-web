Material/Cupertino が正式 deprecated — material_ui へ移行と、素の Flutter リアクティブ2種

3.50 で SDK 同梱の material.dart が正式非推奨。dart fix 一発で移行。あわせて TweenAnimationBuilder と ValueNotifier を押さえる。

📅 2026年11月25日 ⏱ 約5分 🔗 出典 5 件

stable は 3.50.1／beta は 3.51.0-0.2.pre で5日連続“据え置き”。版の動きが薄い日なので、今日は 3.50（11/11 公開）が持ち込んだ構造変化を深掘りする。公式 blog いわく「Flutter 3.50 は結合した package:flutter/material.dart と package:flutter/cupertino.dart を正式に deprecated にする」。つまり SDK 同梱の Material/Cupertino（＋ localization delegate）が正式に非推奨になり、移行先は pub.dev のスタンドアロン material_ui ／ cupertino_ui（1.0 は 3.47 で launch 済み）になった。

何が変わるか — import の付け替え

移行には自動化がある。公式は「dart fix --apply --code=migrate_design_widgets を実行すれば、既存 import と localization delegate を自動で書き換える」と明記。flutter create の新規プロジェクトは既定で package:material_ui を import し、DevTools 自身も material_ui/cupertino_ui へ移行済み。削除リリース/日付は未アナウンスなので今すぐ全面移行の緊急性は低いが、新規コードは material_ui 前提で書くのが無難。この材料パッケージ分離が、go_router 18.0.0 / animations 3.0.0 が material_ui 依存になった背景でもある。

3.50 の他ヘッドラインも軽く：Direct native interop（FFIgen for Obj-C＋JNIgen for Java/Kotlin）が stable、Wasm web が Safari 26.2+・Firefox 147+ で JS 比2倍超 fps（opt-in）、iOS タッチ入力が 60Hz で 16ms・120Hz ProMotion で 8ms 高速化。Dart 3.14 は dart:html/dart:js 系を deprecated（dart:js_interop＋package:web へ）。

仕組み — 素の Flutter リアクティブ2種

状態管理ライブラリの前に押さえておきたいのが、依存ゼロの2つ。TweenAnimationBuilder<T> は「target 値が変わるたびに widget のプロパティを新しい値へ自動アニメする implicit builder」。内部に AnimationController を持ち、尺・curve・target を渡すだけ。アニメ版が無いプロパティ（サードパーティ widget 含む）を後付けでアニメ化できる。注意は「渡した tween の所有権を奪い mutate する」点——tween はインスタンス変数に持たず build 内で都度生成する。より細かい制御が要るなら AnimatedBuilder＋自前 AnimationController へ。

もう一つが ValueNotifier<T> ＋ ValueListenableBuilder<T>＝「単一値の最小リアクティブ」。.value 代入が == 判定で変化していれば listener へ通知し、builder だけ再描画する。落とし穴は in-place mutation が通知されないこと：ValueNotifier<List> で list.add(x) しても参照同一で発火しない。新 List を代入し直すか、複数フィールドなら ChangeNotifier を直接 extend する。dispose() は必須。

パフォーマンスの軸

公式「Performance best practices」の軸は build() を速く小さく保つこと。setState() は変化する subtree に局所化し、再利用は関数ではなく StatelessWidgetに。変わらない child を同一インスタンス（const／親から受け渡し）で保てば再 build traversal が止まる。Opacity/clip/saveLayer() は節約、大リストは lazy builder。60Hz のフレーム予算は 16ms（build 8ms＋render 8ms）。render を下げれば見た目不変でも電池・発熱が改善する。

ひとことまとめ

3.50 の本丸は material_ui へのパッケージ分離（移行は dart fix 一発、除去時期は未定）。新規コードは material_ui 前提で。状態は素の ValueNotifier/TweenAnimationBuilder を土台に、「代入で発火・mutation は無通知」だけは体に入れておく。
