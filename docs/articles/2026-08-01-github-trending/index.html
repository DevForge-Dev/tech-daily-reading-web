8/1の話題リポジトリ — 動画生成基盤・ターミナル内ブラウザ・自前ホストPM

生成AIの基盤と、エージェントに実務を任せる道具。LongCat-Video/terminal-browser/kaneo の3本を『解決する課題→提供機能』で読む。

📅 2026年8月1日 ⏱ 約3分 🔗 出典 3 件

今日の3本は毛色が違うが、『生成AIの基盤』と『エージェント／開発者に実務を任せる道具』という2軸で括れる。動画生成の大型モデル、ターミナルに溶け込むブラウザ、そして軽量な自前ホスト型PMツール——AI一色のトレンドの中で実装の幅を映す3本だ。

meituan-longcat/LongCat-Video（Python・⭐約5.3k）

解決したい課題：テキスト・画像・既存動画から高品質な映像を作りたいが、用途ごとにモデルを使い分けるのは重い。提供する機能：Text-to-Video / Image-to-Video / 動画継続生成を1つの13.6Bパラメータ基盤モデルで担う、Meituan LongCatチーム発のオープンモデル。なぜ急上昇：Trendshift日次17位。動画生成の競争激化と大手研究チーム発の信頼性が拡散を後押ししている。

zenbu-labs/terminal-browser（New 2026）

解決したい課題：SSH越しやターミナル中心の作業で、いちいちGUIブラウザに切り替えたくない／エージェントにWeb操作を任せたい。提供する機能：kitty graphics protocolでChromiumをターミナル内にピクセル描画する『本物のブラウザ』。マウス/キーボード入力を合成イベントで送り、SSH越しにリモートで動くローカルサイトをプレビューでき、エージェントからも直接操作できる。なぜ急上昇：Trendshift日次16位のNew。『ターミナル内にChromium』という発想の新鮮さが刺さった。

usekaneo/kaneo（TypeScript）

解決したい課題：Jira/Linearは多機能すぎて重く、SaaS依存になる。もっと軽く自前で持てるプロジェクト管理が欲しい。提供する機能：かんばん/リスト・担当/優先度/ラベル/期限・時間計測を過剰設定なしで提供。Hono＋PostgreSQL(Drizzle)＋ReactのTSモノレポで、GitHub/Gitea連携やSlack/Discord通知のプラグイン、Docker/Helmでセルフホストできる。なぜ急上昇：Trendshift日次13位。エージェント一色の中で数少ない自前ホスト生産性ツール枠として存在感を出した。

自分が試すなら：まず terminal-browser——SSH先のローカルプレビューとエージェントのWeb操作は日々の開発に直に効く。kaneo はセルフホストPMの候補、LongCat-Video は動画生成の当たりを付ける実験用に置いておく。
