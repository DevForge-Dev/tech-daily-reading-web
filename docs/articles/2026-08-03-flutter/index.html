Dart 3.12 の3機能でボイラープレート削減 — private named parameters・primary constructors・dot shorthands、値クラス5行を1行に

現行安定版は Flutter 3.44.7 / Dart 3.12。①private named parameters は先頭_で公開名を自動決定しカプセル化を保ったまま named 引数化、②primary constructors（experimental）はクラス宣言にコンストラクタを畳み込み5行の値クラスを1行に、③dot shorthands は文脈から型が明らかなら enum/static を .value に省略。3.44系のうちに dart fix で段階適用。

📅 2026年8月3日 ⏱ 約3分 🔗 出典 3 件

Dartの直近テーマは一貫して「定型コードを言語機能で削る」ことだ。現行安定版は Flutter 3.44.7 / Dart 3.12で、次の機能リリースは2026年8月（年4回・2/5/8/11月、3.45系はまだ未リリース）。今日の主役は、値クラスやコンストラクタ周りの冗長さを消す3つの新機能である。実務では小さな値クラスやenum参照が積み重なってノイズになりがちで、そこへ直接効く。

何が新しいか。①private named parameters：初期化仮引数やprimary constructor引数で先頭 _ を付けると、公開名は _ を除いた名前に自動で決まる。カプセル化（privateフィールド）を保ったまま named 引数で受けられ、this._x を本体に書く定型が消える。②primary constructors（experimental・primary-constructors フラグ）：クラス宣言そのものにコンストラクタを畳み込み、5行の値クラスを1行に圧縮する。③dot shorthands：型が文脈から明らかなら enum値やstaticを .value と略記できる。

仕組みのポイント。private named parameters は「privateにしたいが呼び出し側は named で書きたい」という長年の綱引きを、公開名と内部名を機械的に対応づけて解消する。dot shorthands は型推論が効く文脈（引数、戻り値、switch/case のパターン等）でのみ働くので、あいまいな場所では従来通り明示が要る。primary constructors は構文が今後変わり得るため、experimentalフラグを外すのは時期尚早だ。

自分が試すなら：まず private named parameters と dot shorthands を新規コードで使い、dart fix / dart format / flutter analyze で警告を潰しながら3.44系のうちに段階適用する。primary constructors は実験ブランチで感触を見るに留める。土台側は Impeller が Android 既定・Skia 撤去、Material/Cupertino のパッケージ分離、AIツーリング（Agentic Hot Reload・GenUI・Genkit Dart）が進み、2026ロードマップ『Finishing the Job』は Android の Impeller 移行完遂と Web の WebAssembly 既定化を掲げる。注意点：experimentalフラグ前提の構文をチーム共有リポジトリに混ぜると、フラグ未設定の環境でビルドが割れる。まとめ：3.12は「安定した2機能を今すぐ、実験の1機能は待つ」で取りこぼしなく定型を削れる。
