EL4CTEO/fast-anything（Rust・⭐約1,824）

解決したい課題：「速くしたいから全部 Rust で書き直す」は現実にはコストもリスクも重すぎる。Python/Node/Ruby アプリの遅さは往々にして一部のホット関数に集中しているのに、全面移植は工数が大きい。提供する機能：アプリをプロファイルして“遅い5%”の関数だけをコーディングエージェントで Rust に移植し（napi-rs/pyo3/FFI）、移植前後の挙動が等価であることをテストで証明する。「速くなったが壊れていない」をデータで担保するのが肝。作成約2日で日平均約912★＝当日最速級、MIT。既出の全面 Rust 移行系と違う“部分最適”の新規性で急伸した。

leanprover-community/riemann-hypothesis（Lean・⭐約605）

解決したい課題：2026-11-20 に発表されたリーマン予想の Lean 形式化（Alpöge）は、人間が目視で正しさを保証しきれない。提供する機能：その証明を機械チェック可能な形で独立検証する Comparator 環境を leanprover-community 公式で用意する。open issues は96と極めて活発で、「AI/計算機 × 数学・定理証明」の話題性で作成約3日・日平均約200★。Lean という希少言語 × 形式検証ジャンルの多様性枠で、話題性ドリブンの急上昇。

siliconjungle/shapeshift-labs-ink-studio（JavaScript・⭐約1,028）

解決したい課題：生成 AI 一辺倒のトレンドの中で、「手で造る」グラフィックス表現の場が乏しい。提供する機能：ピクセルアートとガウシアンスプラットを掛け合わせ、ブラウザ上で点群的な3D風表現を彫刻・アニメーション・シミュレーションできる toolkit。JS/MIT、作成約7日で日平均約147★。AI 生成でない創作ツールとしての新規性でグラフィックス多様性枠として伸びた。
