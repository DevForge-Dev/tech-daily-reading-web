beta 3.48 / Dart 3.14 — ImpellerのAndroid一本化とdot shorthands、Riverpod 3のresilience

betaでAndroidのImpeller opt-outをdeprecateし、Skia→Impeller移行が最終フェーズへ。Dart 3.14はdot shorthands・build hooks stable・analyzer plugin。状態管理はRiverpod 3.3.1のMutations／自動リトライ／offline persistenceが軸に。

📅 2026年9月18日 ⏱ 約3分 🔗 出典 4 件

今日の主役は beta 3.48 / Dart 3.14 の言語・ツール強化と Impeller の Android 一本化だ。beta では Android の Impeller opt-out が deprecate され、Skia→Impeller 移行がいよいよ最終フェーズに入る。現行の安定版は Flutter 3.47 系 / Dart 3.13 系（確認は flutter --version）で、次の安定機能リリースは 2/5/8/11 月サイクルの 2026 年 11 月見込み。Impeller の Android 一本化と WasmGC 既定化がその布石になっている。

Dart 3.14 の言語強化

実装で効くのは dot shorthands。型が推論できる文脈なら .start と書くだけで MainAxisAlignment.start を意味し、enum 値・static メンバ・constructor を先頭ドットで省略できる。加えて build hooks が stable になり、Dart パッケージにネイティブコード／アセットを直接コンパイル・同梱できる。独自解析ルールと IDE quick fix を足せる analyzer plugin system も入った。AI ネイティブ方面では、MCP で AI エージェントが Dart コードを検査し hot reload をトリガでき、GenUI パッケージで動的 UI を生成できる。

状態管理は resilience が軸

新規プロジェクトの既定は Riverpod 3.3.1 ＋ @riverpod codegen、監査・規制業界は Bloc 9.0、という基本線は変わらない。3.x で効くのは resilience 三点だ。Mutations（experimental）が副作用の Idle / Pending / Success / Error を UI へ公開し、provider の automatic retry（指数バックオフ）、opt-in の offline persistence（experimental）が加わった。テストは provider override でツリーを起動せず書け、Bloc 比で平均 30〜40% 行数が減る。再描画は ref.watch(provider.select(...)) で最小スライス購読に閉じる。fintech / healthcare のように監査証跡が要るなら、event→state が 1 対 1 で追える Bloc 9.0＋hydrated_bloc が向く。

自分が試すなら・注意点・まとめ

試すなら flutter channel beta && flutter upgrade で dot shorthands と Impeller 挙動を確認し、戻すときは flutter channel stable。パフォーマンスは DevTools の flame chart で 16ms 超のフレームを狙い撃つのが定石で、最頻の原因は不要な widget rebuild。不変プロパティは const で完全スキップ、重い計算は Isolate.run() / compute() で背景 isolate へ。注意点は、動きは Transform・フェードは Opacity に閉じること（width/height の setState は layout pass を誘発して jank になる）。まとめると、レンダラは Impeller 前提、言語は dot shorthands で短く、状態は Riverpod 3 の resilience で堅く——2026 秋の Flutter はこの三本柱だ。
