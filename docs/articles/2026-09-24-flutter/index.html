11月stableに迫るmaterial_ui移行と、Impeller全既定が変えるアニメ・120fps設計

3.47でMaterial/CupertinoはSDKから独立パッケージ化。正式deprecationは11月stableから——「まだ壊れない＝11月までに移行」。Impeller全既定・Riverpod 3.x・Android HCPPも今日の要点。

📅 2026年9月24日 ⏱ 約4分 🔗 出典 3 件

Flutter は年 4 回（2/5/8/11 月）の安定リリースサイクルで進む。現行安定版は Flutter 3.47.4 / Dart 3.13.3（2026-09-11 patch）、beta は 3.48 / Dart 3.14。今いちばん締め切りが近いのは 11 月 stable に向けた material_ui / cupertino_ui 移行だ。

移行：material_ui / cupertino_ui

3.47 で Material/Cupertino は SDK から独立パッケージ（material_ui / cupertino_ui 1.0）へ切り出された。ただし正式な deprecation は 2026 年 11 月の stable からで、3.47.x の間は既存コードがそのまま動く。つまり「まだ壊れない＝11 月までに移行」が要点。移行コマンドは dart fix --apply --code=migrate_design_widgets。--code= を付けずに dart fix --apply だけだと成功表示でも該当変更が入らない罠がある。fix は pubspec.yaml に material_ui: any を書き込むので、直後に キャレット制約（例 ^3.0.0）へ置換して破壊的変更の無警告流入を防ぐ。よくある誤解として ChangeNotifier は移動していない（SDK 内に残り deprecated でもない）。

Impeller全既定とFragmentShader

3.47 で Impeller が全デスクトップ既定になり（Android は 3.48 で一本化）、GLSL カスタムシェーダは AOT（事前）コンパイルされる。グラデーション流動・ノイズ・波紋・溶暗などの GPU 演出が first-frame から jank なく動く（Skia 時代の実行時コンパイル stutter が消える）。3.44 で FragmentShader.getUniformFloat() が入り、uniform をインデックスでなく名前でバインドできる（.frag 変更に強い）。制約はラスタ ~4ms を守るため重い分岐(if/else)を避け、mix()/smoothstep()/clamp() など数式関数を優先、シェーダ実行は 4〜5ms 未満。既存カスタムシェーダは Impeller 既定化で要再テスト。

状態管理：Riverpod 3.x

現行は Riverpod 3.x（3.3.x 系）。要点は unified Ref、@riverpod による code generation（Notifier 生成でボイラープレート削減）、automatic retry（失敗 provider に指数バックオフ）、experimental persistence（選択 provider のオフライン保存）。再描画は ref.watch(provider.select(...)) で最小スライス購読。監査/規制・大規模チームは明示的な event→state 遷移の Bloc（blocTest/hydrated_bloc）が向く。原則は「一つ選んで一貫させ、テストを書く」。

120fpsのフレーム予算

Android の HCPP（Hybrid Composition++、Vulkan でレイヤ合成を OS 側へ委譲）で PlatformView 混在画面の jank/入力ズレが緩む。フレーム予算は 120fps = 8.33ms（UI ~4ms＋ラスタ ~4ms）。リストは ListView.builder で itemExtent（高さ固定＝レイアウト予測可）・cacheExtent: 800・addRepaintBoundaries: true、アニメ領域は RepaintBoundary で隔離。Impeller 移行で jank フレーム 30〜50%減・ラスタ約 50% 高速化の報告もある。

ひとことまとめ

今日の最優先は 11 月までの material_ui 移行（dart fix --code=migrate_design_widgets → 制約固定）。Impeller 全既定で GPU 演出と 120fps がぐっと現実的になった。
