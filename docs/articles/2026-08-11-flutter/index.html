AIネイティブ開発ループが本流へ — Flutter 3.44 の GenUI・Agentic Hot Reload・Widget Previewer

現行安定版 3.44 / Dart 3.12。エージェントが UI を合成し、ホットリロードの結果を自動消費し、プレビューは IDE メモリを最大50%削減する。

📅 2026年8月11日 ⏱ 約2分 🔗 出典 3 件

現行安定版は Flutter 3.44 / Dart 3.12（3.44.0 は 2026-05-18・Google I/O 2026 公開）で、次の機能リリース窓（年4回 2/5/8/11月）に入った。今回の主役は、ツールチェーンがAI ネイティブな開発ループへ寄せてきたことだ。コード補完の域を超え、UI 生成・ホットリロード・プレビューがエージェント前提に再設計されつつある。

目玉は3つ。GenUI（A2UI プロトコル）はエージェントが自然言語から実際の Flutter UI をその場で合成する仕組みで、I/O 2026 のイベント企画アプリ「Hatcha」でデモされた。Agentic Hot Reloadは 3.44 の中核で、Dart MCP server 経由で dart analyze／dart format の結果をエージェントが自動で消費し、修正ループを回す。Widget Previewerは Flutter プロセスを丸ごと起動せず Dart Analysis Server に依存する設計に変わり、IDE メモリを最大50%削減、Web ターゲットは 40% の性能向上を得た。

土台の言語側も進む。Dart 3.12 は primary constructors（値クラスを1行に）、private named parameters（先頭 _ で公開名を自動決定）、dot shorthands を追加し、Dart 製 Firebase Cloud Functions と合わせて Full-Stack Dart を後押しする。描画は Impeller が Android 既定・Skia 撤去（Vulkan／iOS=Metal）、iOS/macOS は Swift Package Manager が新規プロジェクトの既定（CocoaPods 段階的廃止）へ。

自分が試すなら、まず既存プロジェクトを 3.44 に上げて Widget Previewer のメモリ改善を体感し、Dart MCP server を有効化して Agentic Hot Reload の修正ループを小さな画面で回してみる。注意点は、GenUI/A2UI はまだデモ段階でプロダクション前提の API 安定性を期待しないこと、SPM 既定化で既存の CocoaPods 依存プラグインの移行確認が要ることだ。まとめると、3.44 は「エージェントが開発ループの内側に入る」転換点で、まずはメモリ削減と MCP 連携という実益から触るのが良い。
