Flutter 3.44系のAIネイティブ開発ループ — Agentic Hot ReloadとGenUI(A2UI)がframeworkの中核へ

今日の主役はAIが開発ループの中核に入る流れ。Dart & Flutter MCP Serverが起動中アプリを自動検出し、AIの編集を即hot reload（手動接続不要）。GenUIはオープンなA2UIプロトコル上でAIが実Flutterウィジェットをランタイム合成。現行安定はFlutter 3.47.x/Dart 3.13.x、3.48/Dart 3.14はbeta、次の安定は2026年11月。

📅 2026年9月14日 ⏱ 約3分 🔗 出典 3 件

今日のFlutterの主役はAIネイティブな開発ループがframeworkの中核へ入ってきたことだ。これまでAIは「コードの上のレイヤー」にいたが、Google I/O 2026前後の一連の発表で、Flutterは開発ループそのものにAIを織り込む方向に舵を切った。中心にあるのが Dart & Flutter MCP Server と、その上で動く2つの体験——Agentic Hot Reload と GenUI である。

何が新しい/重要か

Agentic Hot Reload は、MCP Serverが起動中のアプリを自動検出し、AIエージェントがコードを編集した瞬間に手動接続なしでhot reloadする。人間が保存→リロードしていたループをエージェントが自走できる。GenUI（生成UI） はGoogle制定のオープンな A2UI（Agent-to-UI）プロトコル上に構築され、AIが実Flutterウィジェットをその場で合成して完全インタラクティブな画面をランタイム生成する——事前定義レイアウトもアプリストア更新も不要だ。土台の Dart/Flutter MCP Server は dart analyze / dart format の結果を自動消費し、language toolingとAIワークフローを接続する。

いま何が安定版か

足元のバージョンも押さえたい。現行安定版は Flutter 3.47.x / Dart 3.13.x（3.47.0は2026-08-12）、次の Flutter 3.48 / Dart 3.14 はbeta。3.47系の到達点は material_ui / cupertino_ui の1.0 standalone化、Impellerが全デスクトップで既定、Widget Previews stable、Dart 3.13のprimary constructors / dot shorthandsだ。機能リリースは年4回（2/5/8/11月）で、次の安定機能リリースは2026年11月見込み。

実務での使いどころ・注意点

自分が試すなら、まずMCP Serverを繋いでAgentic Hot Reloadで「編集→即確認」を自走させ、UIの試作にGenUIを当てて反復速度を測りたい。ただしGenUI/A2UIはまだ新しく、ランタイム合成UIは予測可能性とテスト容易性が課題になりやすい。プロダクション投入は、状態管理を新規ならRiverpod 3.3.1＋codegen、監査/規制はBloc 9.0という基本線を崩さず、生成部分を局所に閉じるのが安全。性能面はImpeller前提でフレーム予算（60fps=16ms/120fps=8.3ms）を守り、計測は必ずprofileモードで。

ひとことまとめ

AIが「コードを書く道具」から「開発ループの一部」へ。MCP Serverを軸にhot reloadと実ウィジェット合成が回り出した。まずは試作の反復速度で恩恵を測るのが良い入り口だ。
