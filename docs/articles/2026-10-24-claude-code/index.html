Claude Code

v2.1.309 — `sed -i`に権限プロンプト、bypassで危険な`rm`を即時拒否、`/claude-api`がManaged Agentsのチームを構築

3日で小刻みパッチが続く2.1系の中でも一段大きい版。芯は破壊的操作の明示ゲート化と、サブエージェントをチーム編成する/claude-apiの進化。

📅 2026年10月24日 ⏱ 約3分 🔗 出典 3 件

2.1系は10月に入って権限・サンドボックス・MCP安定性まわりの小刻みパッチが連続していたが、10/22は v2.1.308→v2.1.309 の2連続リリースで、後者がこの系列で一段大きい。公式changelog／サードパーティ追跡(havoptic)のいずれでも、本日2026/10/24(JST)時点で10/23・10/24付の新規版は確認できず、最新は v2.1.309(10/22) のままだ。芯は「破壊的操作を見えない自動実行から明示ゲートへ」と、サブエージェントをチーム編成する /claude-api の進化にある。

何が新しいか。①sed -i は他のBash編集と同様に通常の権限プロンプトを出して記述どおり実行するが、/rewind では復元されなくなった＝一括置換が「承認は要るが巻き戻せない」操作に。②claude ultrareview はワークスペース信頼を必須化（端末は確認、非対話は拒否。回避は --trust-workspace か CLAUDE_CODE_DISABLE_ULTRAREVIEW_TRUST_CHECK=1）。③Desktop/VS Codeのbypass権限モードでは危険な rm/rmdir をプロンプトせず即時拒否する＝「何でも通す」bypassでも、取り返しのつかない削除だけは別格に扱う。④worktree作成/再利用でgitのオンデマンド取得を停止。⑤同梱datavizにAPCAコントラスト指標と apca(text,background) 検証関数を追加。⑥/claude-api が multiagent_20261001 上でManaged Agentsのサブエージェント「チーム」を構築し、動的ワークフローが既定でON。改善8件・バグ修正62件（サンドボックスBashがサンドボックス外のシェル起動ファイルを実行しない等）。

実務での使いどころ。多数の定期タスクをbypass寄りで回す運用でも、rm -rf 相当の事故が構造的に止まるのは大きい。収集と分析を別コンテキストに分けるSubagent運用を、Managed Agents側でもチームとして組めるようになった点は、重い調査を安価モデルに逃がす設計をそのまま持ち込める。注意点：sed -i は承認後は巻き戻せないので、重要ファイルは置換前にコミット済みにしておく。ultrareviewはCI/非対話で止まるため --trust-workspace の明示が要る。

市場面では、Ramp指標(2026年8月)で法人の 43.8% がAnthropicを購入しOpenAI(39.8%)を逆転したとの報道もあった（ただし「購入企業の割合」で売上シェアそのものではない点に留意）。ひとこと：「速さ」より「壊さない」を積む系列で、bypassでも消えない安全弁が入ったのが今日の芯。
