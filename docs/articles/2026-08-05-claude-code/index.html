Claude Code

v2.1.221 & サブエージェント深さ3 — VSCode『Focus view』・サンドボックス資格情報マスキング・FastモードがOpus 5/4.8対応

8/3–4のv2.1.221でVSCodeに実行詳細を畳む『Focus view』、Linux/WSLで資格情報の mask モード、plugin validate に名前拒否警告。あわせてサブエージェントが深さ3までネスト可能に、/model ピッカー改善、FastモードがOpus 5/4.8へ拡大。Enterpriseはモデル別エンタイトルメント＋支出アラートを追加。

📅 2026年8月5日 ⏱ 約3分 🔗 出典 4 件

Anthropic社内では新規プロダクションコードの約80%を既にClaudeが書くと報じられ、CLI型エージェントは『人が主体・AIが補助』から『エージェント主体・人がレビュー』へ移りつつある。規模が上がるほど焦点になるのが、実行の見通しの良さ・秘匿情報の扱い・並列タスクの制御だ。8/3〜4のv2.1.221とその周辺リリースは、まさにこの3点に効く更新を束ねている。

何が新しいか。VSCode拡張に Focus view が加わり、ツール実行の詳細をターンごとの展開式サマリーの背後へ隠して実行中インジケータだけを表示する（Ctrl+Alt+F または『Claude Code: Toggle Focus view』で切替）。セキュリティ面ではLinux/WSL向けにサンドボックス資格情報ファイルの mode:"mask" を追加——サンドボックス内のコマンドはセンチネルのコピーを読み、送信時にプロキシが実値へ差し替える（macOSは deny にフォールバック）。claude plugin validate にはDesktopの管理同期で名前が拒否される場合の警告が付き、zshの隠しコマンドでBash権限チェックを回避できる不具合も修正された。

並列制御も一段深く。サブエージェントが入れ子のサブエージェントを 深さ3 まで生成できるようになり、大規模な並列タスクの分割がより柔軟になった。サブエージェントは独立コンテキスト・独立ツール・独立モデルを持つ別インスタンスで、メインには最終サマリーだけが返る——だから並列リサーチ・独立ファイルの並列改修・メイン会話を汚したくない隔離タスクが適所だ。/model ピッカーの表示・選択が見直され、FastモードがOpus 5とOpus 4.8にも適用されるよう拡張。autoモードでは並列ツール呼び出しの権限チェックがキャッシュ効率化され、保留中にモードを切り替えても古い結果を適用せず再プロンプトする。

Enterprise側は管理者アナリティクスを強化し、モデル別エンタイトルメント（利用可否制御）と支出アラートを追加、Teamプランの標準シートにもClaude Codeアクセスが入った。自分が試すなら：VSCodeで長い自律実行を回すときにFocus viewで画面ノイズを消し、深さ3のサブエージェントで『調査』『改修A』『改修B』を並列に切り出してメイン会話を軽く保つ。注意点：mask はLinux/WSL限定でmacOSは deny 動作、分割しすぎるとサマリー統合コストが増えるので境界設計が肝。まとめ：v2.1.221は『実行を見やすく・秘匿を安全に・並列をより深く』を同じ更新でそろえた。
