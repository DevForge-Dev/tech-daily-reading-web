アコーディオン/折りたたみを“高さ計測なし”で滑らかに — grid-template-rows 0fr→1fr と ネイティブ <details> + ::details-content + interpolate-size

「height:0→auto はアニメできない」壁のせいで長年 JS で scrollHeight を測っていたアコーディオンを、2026 は CSS だけで滑らかに開閉できる。全ブラウザで動く grid 0fr→1fr トリックが実務の第一候補、マークアップとa11yがタダで付く <details> + ::details-content + interpolate-size が新標準。App Router では純CSSなら Server Component のまま置ける。

📅 2026年9月5日 ⏱ 約4分 🔗 出典 3 件

クリックで開く FAQ・設定パネル・サイドバーのグループ＝アコーディオン/折りたたみは最頻出のUIだが、「height:0→auto はアニメーションできない」という古典的な壁があった。そのため長年、JS で scrollHeight を測って height を px で毎回セットする実装（Radix の --radix-accordion-content-height もこれ）が定番だった。2026 時点では、中身の高さを一切測らず CSS だけで滑らかに開閉できる方法が2系統そろい、多くのケースで計測フックを畳める。

手法1: grid-template-rows 0fr→1fr（実務の第一候補）

外側を display:grid にし、grid-template-rows を 閉=0fr / 開=1fr でトランジションする。fr は数値なので 0fr↔1fr を補間できる（auto は不可だがこれは可能）。1fr＝利用可能高さ＝中身の自然高なので測らず実寸へ開く。内側の overflow:hidden が必須で、これを忘れると 0fr でも中身がはみ出す（最頻出ミス）。Firefox 対策に内側へ min-height:0 も入れる。Chrome/Safari/Firefox 全対応・ResizeObserver 不要。

.collapse{display:grid;grid-template-rows:0fr;transition:grid-template-rows .3s ease}
.collapse[data-open="true"]{grid-template-rows:1fr}
.collapse__inner{overflow:hidden;min-height:0}

手法2: ネイティブ + ::details-content + interpolate-size

<details><summary> だけで開閉・キーボード操作・状態のSRアナウンスがタダで付く。2025年に ::details-content（summary を除いた中身の匿名ボックス）が Baseline newly available に到達し中身をアニメできるように。高さ開閉は interpolate-size:allow-keywords（height:0↔auto の補間許可）と transition-behavior:allow-discrete（閉じる側も見せる）を組み合わせる。同じ name 属性を各 details に付ければ JS ゼロで排他アコーディオンになる。ただし interpolate-size は現状 Chromium 系のみで、Firefox/Safari は瞬時開閉（＝プログレッシブエンハンスメント）。手法1を details の中身側に併用すると全ブラウザで高さアニメが効き、堅い。

App Router での判断・注意点

静的な FAQ・ドキュメントの折りたたみはネイティブ details + CSS＝'use client' 不要・hydration ゼロで INP/CLS に有利、排他は name 属性。state/URL 連動やfetch連動ならトグルの島だけ 'use client' にして手法1を data-open で切替、初期 open を props で渡せば mismatch なし。複雑操作やDS統一は Radix/shadcn Accordion。a11y はまずネイティブを試し、カスタム時は本物の <button>＋aria-expanded＋aria-controls。prefers-reduced-motion:reduce では transition を切り、開閉自体は残す。

まとめ：測らず・依存ゼロ・全ブラウザなら grid 0fr→1fr（内側 overflow:hidden 必須）。a11y/排他をタダで欲しければ details+name、高さアニメは grid 併用で堅く。迷ったらネイティブ details を第一候補に。
