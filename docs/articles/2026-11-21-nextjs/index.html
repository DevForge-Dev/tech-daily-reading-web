CSS `corner-shape` — `border-radius` の「丸」を超え、角の“曲線タイプ”そのものを純CSSでアニメーション（squircle / superellipse）

20年近く「角を丸める」唯一の手段だった border-radius は、形が常に円弧だった。corner-shape は、その角の曲線タイプ自体を round / squircle / bevel / scoop / notch や連続パラメータ superellipse(k) に差し替える新プロパティ。最大の旨味は補間可能＝ホバーで「bevel→squircle」とぬるっとモーフできること。Chrome/Edge 139 でフラグなし搭載済み。

border-radius は長らく「角を丸める」唯一の手段で、形は常に真円の一部（円弧）だった。iOS 風のなめらかな角丸＝スクイクル（squircle）や面取り（bevel）、えぐれた角（scoop）を作るには、SVG の clip-path/mask、figma-squircle 等の JS ライブラリ、border-image といったハックが必要で、どれも「角のサイズが変わると破綻」「中身のクリップが面倒」「JS 計算が要る」弱点を抱えていた。CSS corner-shape は、border-radius が丸める“その角”の曲線タイプ自体を差し替える新プロパティで、これらを純CSSで置き換える。

値とジオメトリ：superellipse(k) の指数が形を決める

構文は border-radius と同じ 1〜4 値（1値＝全角、4値＝TL から時計回り）。キーワードは連続パラメータ superellipse(k) に対応づく——曲線 |x|^(2k)+|y|^(2k)=1 の指数 k が、k=1 で真円、k=0 で直線（bevel）、2 付近で squircle、2超で直角寄り、負値で凹（scoop〜notch）になる。superellipse(1.8) のような中間値も書ける。

最重要の前提：border-radius が無いと一切効かない

corner-shape は「border-radius が丸める角」を別カーブに置き換えるプロパティなので、半径が 0 に解決されると置き換える対象が無く無反応になる（最頻出ミス）。役割分担は「半径の大きさ＝コーナーの“深さ”、corner-shape＝その“曲率タイプ”」と覚える。

本題のアニメーション：transition を書くだけでモーフする

MDN の Animation type は各 longhand が「superellipse interpolation で補間」。キーワード同士の遷移もそれぞれの superellipse() 等価値に変換してなめらかに補間されるので、transition: corner-shape .3s ease; と書くだけで「bevel⇄squircle」が連続モーフする。@keyframes で曲率を脈動させるのも可。ただし端点が無限大（square＝∞ / notch＝−∞）を含む遷移は仕様の詳細が薄く要実機検証で、できれば有限値の superellipse() を端点に使うのが無難だ。

.card { border-radius: 24px; corner-shape: squircle; } /* = superellipse(2) */

/* ホバーで bevel → squircle にモーフ */
.btn {
  border-radius: 18px;
  corner-shape: bevel;                 /* = superellipse(0) */
  transition: corner-shape .3s ease;   /* ← これが無いとモーフしない */
}
.btn:hover { corner-shape: squircle; }

対応状況と Next.js（App Router）での組み込み

Chrome / Edge 139+（2025・フラグ不要）で動き、Safari・Firefox は未対応（2026年半ば時点）。非対応ブラウザは宣言を無視して素の丸角を表示＝自然縮退するので、@supports (corner-shape: squircle){…} で段階導入し、ベースは border-radius だけで成立させるのが鉄則だ。純CSSなので 'use client' 不要・Server Component のまま使え、JS・ハイドレーション・追加バンドルはゼロ、レイアウトは border-radius で固定されるため CLS 0。曲率をサーバー側から出し分けたいときは CSS 変数で注入できる（style={{ ['--k']: 1.8 }} → corner-shape: superellipse(var(--k))）。Tailwind v4 なら className="rounded-3xl [corner-shape:squircle]" のように半径とセットで。

ひとことまとめ

これまでの SVG マスク／JS squircle ライブラリを丸ごと置き換えられるのが実務的インパクト。ただし Chromium 限定なのでブランドアイコンの“squircle”をこれだけに依存させないこと——squircle は「対応ブラウザへのご褒美」と割り切り、border-radius の丸角で完成するデザインの上に @supports で重ねるのが安全だ。prefers-reduced-motion では形状の結果は見せつつ transition / animation だけ止める。
