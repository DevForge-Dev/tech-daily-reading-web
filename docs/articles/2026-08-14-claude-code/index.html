Auto Modeが既定に — 承認待ちゼロへ舵、v2.1.231とVS Code Focus viewで統制も両立

8/14からAuto Modeがデフォルト化。分類器が「平均的ユーザーのクリックと同等かそれ以上に安全」と判断したツール実行を自動承認し、追加トークンはPro/Max/Team無課金。自律実行を前へ押し出しつつ、マーケットプレイス制御・Focus view・資格情報maskで統制も同時に厚くする回。

📅 2026年8月14日 ⏱ 約3分 🔗 出典 4 件

この数日のClaude Codeは「承認の摩擦を減らす」方向が一気に前進した。The Registerによると、Anthropicは8月14日からAuto Modeを既定にする。従来はツール実行のたびにユーザーがクリックして許可していたが、これからは分類器が「平均的なユーザーがプロンプトをクリックするのと同等かそれ以上に安全」と判断した操作を自動承認する。承認待ちで作業が止まる摩擦を消し、エージェントの自律実行をさらに前面に出す動きだ。

何が新しいか。Auto Mode既定化にあわせ、分類器が消費する追加トークンをPro・Max・Teamは無課金化した。加えて8月13日リリースの v2.1.231 ではマーケットプレイス制御（許可/ブロックの owner ワイルドカードでリポジトリ単位の統制）、モデル/セッション警告表示の明確化、クラウドのセッションをローカルへ移す /teleport ヒントが加わった。VS Code拡張にはFocus view（Ctrl+Alt+F）が入り、ツール実行ログを1ターン単位の折りたたみ要約に隠して会話の見通しを確保できる。さらにLinux/WSL向けに資格情報のmaskモード——サンドボックス側はセンチネル値を読み、egress時に実値へ置換する仕組みが追加され、extract正規表現・JWTデコード・AWS SigV4再署名にも対応した。

仕組みのポイントは、承認を人手の一律クリックから分類器による安全判定ゲートへ置き換えたこと。安全と見なせば自動実行、危険なら従来どおり確認を挟む。同時にマーケットプレイス制御と資格情報maskで「実行の自由度」と「配布・秘密情報の統制」を両輪で上げているのが今回の設計思想だ。

自分が試すなら、Auto Mode＋Focus viewで長時間のリファクタや横断調査を回し、承認待ちが消える体感とログの見通しを確かめたい。Linux環境ではmaskモードを有効化し、実鍵をegress時だけ使う運用でシークレット漏れの面を検証する。

注意点。自動承認の基準は「平均的ユーザーのクリック相当」であって無謬ではない。破壊的操作の前は権限設計やPreToolUse Hooksで二重の歯止めを掛けたい。導入面ではNECがグループ約3万人へ展開、クラスメソッドがコードレビュー80%短縮を報告し、ランレート売上は25億ドル超と成長が続く一方、Microsoftの事例どおりコスト・予算ガバナンスとセットで入れるのが安全だ。

ひとことまとめ：今回は「止まらない自律実行（Auto Mode）」と「配布・秘密の統制（マーケット制御・maskモード）」を同時に底上げする回。自由度と統制を両取りする地固めが主眼だ。
