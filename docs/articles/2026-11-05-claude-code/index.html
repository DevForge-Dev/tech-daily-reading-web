Claude Code

11/5のClaude Code — v2.1.318が無人運用の地雷を潰す：サインイン期限の可視化・共有ホーム保全・背景サブエージェント3分背景化

派手な新機能はないが、複数モデル×長時間×共有環境で踏む落とし穴を静かに修正。毎日スケジュールでエージェントを回す使い方にこそ効く挙動変更を、仕組みから読む。

📅 2026年11月5日 ⏱ 約3分 🔗 出典 4 件

背景・なぜ今これか。 11/5時点の公式最新は v2.1.318（11/3公開）。昨日扱った v2.1.317 より新しい。中身は目を引く新機能ではなく、「複数モデル・長時間・共有環境」で静かに踏む事故を潰す修正群だ。まさに自分のように無人スケジュールでサブエージェントを回す使い方に直撃するので、読み飛ばすと痛い順に整理する。

何が重要か①：サインイン期限の可視化。 保存済み claude.ai サインインの有効期限が表に出た。claude auth status が loginExpiresAt を、claude -p の JSON 結果が credential_expires_at を返し、期限の10日前から stderr に1行の警告を出す。無人運用で一番怖い「気づいたら認証切れでジョブが全部落ちていた」を、事前に検知できるフックができたということ。

何が重要か②：共有ネットワークホーム（NFS等）の設定保全。 ~/.claude.json・設定・ログインが削除／空化／古いコピーに置換される、空き容量が尽きるとログインが空ファイル化する、/logout や claude mcp remove が失敗を黙殺する——といった事故を多数修正。claude mcp add/remove はロックを取得してから書き込むよう直した。複数PCで同一ホームを共有する環境ほど効く。

何が重要か③：挙動の最適化いろいろ。 背景サブエージェントは全プロバイダで3分後に実行中シェルコマンドを背景へ回し、待機中にプロンプトキャッシュが失効しないようにした（長時間ジョブのコスト悪化を防ぐ）。deniedMcpServers の URL 指定が、上流URLの一致する Anthropic 提供サーバやクラウド/自己ホスト runner のコネクタも遮断するよう拡張。IDE 端末内で起動した Claude Code はIDE拡張を自動インストール/更新しなくなった。mod の $.model.fork に effort が付き、軽い脇作業をセッションのeffortと無関係に low で走らせられる。クラウドは「リポジトリ無し」起動が可能に。

実務での使いどころ。 毎日スケジュールで回すなら、まず claude auth status の loginExpiresAt を監視対象に入れて期限切れを先回りする。クラウド実行では「リポジトリ無し起動」で調査系の軽いタスクをコード無しに回せる。長時間サブエージェントを多用するなら、3分背景化でキャッシュが保たれる前提でプロンプト設計を見直すと無駄な再送が減る。

ニュースも一言。 Morph の比較（11/2再検証）では Terminal-Bench 4.0 で Claude Code+Opus5.5 が 64.85%、Codex+GPT-6.1 Sol が 58.18%。文脈窓は双方約100万トークンでほぼ互角だが、API単価は GPT-6.1 Sol（$2/$10）が Opus5.5（$4/$20）より安い。別件で The Next Web は「Claude Code がゲーム再現作業を拒否する」との開発者報告（GitHub Issue #106167、受託の正規案件まで止まる例）を伝えるが、Anthropicは変更を公式アナウンスしておらず未確認。

注意点。 v2.1.318 の詳細は gradually.ai（公式CHANGELOG由来）と公式changelog準拠。ベンチ数値はベンダー（Morph）の主張で独立検証ではない。ゲーム拒否は開発者報告ベース。

ひとことまとめ。 「新機能ゼロでも読む価値のある回」。無人・共有・多モデルで回す人ほど、期限可視化とホーム保全と3分背景化の3点だけは押さえておくと事故が減る。
