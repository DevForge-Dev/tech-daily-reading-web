Flutterの手触りは物理で決まる — animateWith×damping ratioとSliver遅延生成

duration固定のカーブを卒業。SpringSimulationとdamping ratioで、時間ではなく物理で手触りを設計する。

📅 2026年9月29日 ⏱ 約3分 🔗 出典 4 件

Flutterは11月の次期安定版へ向けてbeta 3.48 / Dart 3.14が進行中（現行安定は3.47.4）。この時期に効くのは派手な新機能より「仕上げ」の実務ノウハウで、なかでも物理ベース（spring）アニメーションは手触りを一段引き上げる。

何が新しい・重要か

duration固定のカーブから、物理法則で減衰・振動する動きへ発想を移す。核は AnimationController.animateWith(simulation) に SpringSimulation を渡すこと。動きの表情は SpringDescription.withDampingRatio(mass, stiffness, ratio) の ratio ひとつで決まる。

仕組みを噛み砕く

ratio<1 でオーバーシュート（バウンド）、=1 で臨界減衰（最短・無振動）、>1 で過減衰（ゆっくり接近）。放り投げ（fling）は GestureDetector.onPanEnd の velocity.pixelsPerSecond を初速として渡すと、指を離した勢いをそのまま引き継げる。

final sim = SpringSimulation(
  SpringDescription.withDampingRatio(
    mass: 1, stiffness: 500, ratio: 0.8),
  0, 1,                        // start, end
  velocity.pixelsPerSecond.dy, // onPanEnd の初速
);
controller.animateWith(sim);

実務での使いどころ

ドラッグ可能なカードやボトムシートに好適。Material 3 Expressive は標準モーションがspring化され、割り込み時も現在の速度から滑らかに継続する——途中で向きが変わっても不自然にならない。自分が試すなら、既存の AnimatedContainer のドラッグ解放部だけを animateWith に差し替えて、着地の違いを体感するのが早い。

注意点・落とし穴

explicit系は AnimationController の dispose 必須（忘れるとリーク）。微小変化はimplicitで十分で、何でもspringにすると過剰になる。長いリストと併用するなら描画側も締める：CustomScrollView ＋ Sliver で遅延生成し、固定高なら SliverFixedExtentList(itemExtent:) で各要素の測定パスを省く。120fps＝8.33ms/フレームの予算内に収め、土台のImpellerがshader jankを排除する。

ひとことまとめ

springは「時間」でなく「物理」で動きを設計する発想転換。ratioを一つ変えるだけで表情が変わるので、まず0.8から始めて詰めるとよい。
