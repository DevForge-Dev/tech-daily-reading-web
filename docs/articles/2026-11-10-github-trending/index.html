11/10の話題リポジトリ — スマホ操作エージェント・COWフォルダ隔離・自分のCCセッションでローカル微調整

AI飽和の中、3本を貫くのは「エージェントに実務をどこまで安全に任せるか」。操作・隔離・自前モデル化の道具が同日に急上昇。

📅 2026年11月10日 ⏱ 約3分 🔗 出典 3 件

本日もトレンドは AI 一色だが、グレーや既出を除いた純・新規で光った 3 本を貫くのは「エージェントに実務をどこまで安全に任せるか」という一本の線だ。実機スマホを操作させる、作らせたコードを元フォルダから隔離する、そして自分の作業ログで自前モデルに写し取る——“任せる”の前後を固める道具が同日に急上昇した。

lxe/phoneuse（Python・★534）

解決したい課題：スマホの自動操作は従来、脱獄や開発者登録、専用 SDK が要る“割れ物”寄りの領域だった。提供する機能：改造していない iPhone を、画面は AirPlay で Linux PC に取り込み、操作は PC を Bluetooth のマウス/キーボードに化けさせて返す——脱獄も開発者登録も不要でタップ/入力を送れる。ミラー窓を手で触ってもよいし、CLI や MCP 経由でエージェントに操作させることもできる。公開約 3 日で 534★（本人も“技術デモ”と明記）。全自動化志向と噛み合って急上昇した。

stencil-hq/ovnfs（Go・★205）

解決したい課題：エージェントにコードを書かせると、元フォルダを汚す・機微データに触れるリスクがある一方、VM まるごとの隔離は重い。提供する機能：任意のフォルダ（git でなくても可）をコピーせず copy-on-write の隔離ビューとして開かせ、diff でレビュー → 3-way でマージできる。1 つのデーモンが各チェックアウトを macOS=NFSv3 / Linux=FUSE / Windows=SMB の単一マウント配下に提供し、root も重いカーネル拡張も不要。スナップショット/フォーク/別マシンへのアタッチも可能で、使い捨て VM とは別角度（COW フォルダ）で補完する。公開約 5 日で 205★。

drost-ai/tinker-ai-skill（Python・★288）

解決したい課題：エージェントのトークンコストは積み上がるが、自分の“作法”を写したローカルモデルがあれば削減余地がある。提供する機能：自分のコーディングエージェントのセッション（Claude Code 等）を教師データにして、Thinking Machines の Tinker で学習 → マージ → llama.cpp 用 GGUF を出力するまでを Agent Skill 化。「直近 3 か月の Claude Code セッションで Qwen3 系を微調整して」と言うだけで、課金が発生する手前で止まる設計。Claude Code/Codex/OpenCode 対応で、公開約 3 日で 288★。

自分が試すなら：すぐ効くのは ovnfs——エージェント作業の“元フォルダを汚さない隔離”は今日から入れられる。phoneuse は手元の実機があれば MCP 連携で遊べる技術デモ。tinker-ai-skill はコスト最適化の将来枠として、まず GGUF 出力までの手触りを確認する順がよさそうだ。（★数は公開直後の実測値で、確定の当日増加ではない点に留意）
