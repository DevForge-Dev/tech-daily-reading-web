モメンタム枠（純粋な急上昇）

os6/nospeaker（Swift・⭐約1,393）

解決したい課題：MacBook のトラックパッドにはスピーカーが無く、本体をミュートすると音が出せない。提供する機能：クリック感を生む触覚モーターを毎秒最大4,000回駆動して可聴音を合成し、トラックパッドに喋らせる・歌わせる・楽器化する（Mac をミュートしても鳴る）。curl -fsSL a90.com/nospeaker | sh 一発・約1分半で動くローカル実行のインパクトで、作成約1.5日・日平均約955★＝当日最速級に急伸した。Swift×haptics という希少ジャンルの多様性枠。MIT。

AFK-surf/xnulinux（Objective-C++・⭐約1,948）

解決したい課題：macOS のプロセスを Linux と同じ CPU 上でネイティブに併走させたいが、通常はハイパーバイザや仮想化が要る。提供する機能：Apple が公開する XNU（macOS カーネル）のソースからビルドし、未改変の arm64 Linux カーネルにロード可能モジュール xnu.ko として読み込む。Linux 側の小インターフェース fki.ko がメモリ/タイマ/ファイル/ネット/GPU を XNU へ貸与し、insmod xnu.ko で stock Ubuntu 上に macOS 27 のデスクトップ（WindowServer/Dock/Finder/Safari）が起動する。ハイパーバイザ無しという衝撃で作成約3.5日・日平均約551★。ライセンスは NOASSERTION＝要確認。

sshkeda/minecraft-server-on-orange-cloud（TypeScript・⭐約420）

解決したい課題：Minecraft サーバー運用は VPS 契約やポート開放・常時課金が面倒。提供する機能：Paper サーバーを Cloudflare だけ（Spectrum で TCP:25565→Worker→Durable Object がコンテナ化サーバーを起動・中継、R2 に永続化）で動かし、10分無人でワールドを R2 保存しスリープ→次の接続で約30秒復帰。VPS もポート転送も不要というエッジ/サーバーレス構成の面白さで作成約3日・日平均約147★。非AIのインフラ多様性枠。TS/MIT。

DevForge適合枠（今/将来の開発に効く）

erkamyaman/safe-anything（Rust・⭐約475）

解決したい課題：多くの CI に自動セキュリティ検査（SAST/DAST）が無く、依存脆弱性スキャンも未導入。提供する機能：100% Rust 製スキャナで、1コマンド（npx safe-anything .）でコード（9言語+SQL）の SQLi/XSS/SSRF/path traversal/弱い暗号、.env・クラウド・AI キー等のシークレット、Android/iOS/Docker/GH Actions/K8s/Terraform/nginx の危険設定、locked 依存の CVE（OSV.dev 照合）、さらに MCP/Claude Code/Codex/Cursor のエージェント設定までを走査し、各 finding に「行・理由・修正」を付ける。rust-anything 作者の新作で作成約1.5日・日平均約375★。Claude Code plugin/GitHub Action 対応・MIT＝CI のセキュリティゲート候補。

sybil-solutions/skill-distill（Python・⭐約513）

解決したい課題：frontier モデル（Claude Code/Codex）の作業はトークンコストが高く、同じことを安価なローカルモデルで再現したい。提供する機能：良かったセッション（教師）を読み、open-weight モデル（生徒）が同じタスクを再現できる「スキル」へ蒸留する。生徒を tmux で新規状態から実行→参照出力と比較→最初に失敗した箇所でスキルを修正するループを3試行/版で回し、完了判定は人間承認（Yes-man 禁止）。作成約3日・日平均約177★。トークンコスト削減とスキル運用の両取りを狙う実務ツール。MIT。

lukendeasy/open-diagram（Python・⭐約346）

解決したい課題：Mermaid/D2/draw.io は「その図のレイアウトが破綻していないか」を自分で保証できない（ラベルはみ出し・パネル衝突・線の交差が起きても気付けない）。提供する機能：密なアーキテクチャ図をパネル/タイル/線/グループの短い Python スクリプトで記述し、フォントから全ラベルを実測して配置、パネル衝突や線の交差を自己検出して「破綻していない」ことを検証する。Claude/Codex/Cursor が書く前提の diagrams-as-code で、system map/release pipeline/layered stack/data model を同一ブロックで描ける。作成約6日・日平均約66★。MIT・SVG/PNG 出力。

自分が試すなら：実務直結はまず safe-anything を既存リポに npx で当て、シークレット／依存 CVE の棚卸しをする。トークンコストが気になるなら skill-distill で頻出タスクのスキル化を試し、構成図は open-diagram にエージェント経由で描かせて“自己検証”の実力を見る。驚き系3本は実務価値より「何が可能か」を広げる刺激として眺めるのがいい。ひとことまとめ：この日のトレンドは「低レベルの何でもアリ」と「エージェント開発の地盤固め」が同居した、2026らしい一日だった。
