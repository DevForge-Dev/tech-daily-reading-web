Flutter 3.44の実像 — Agentic Hot Reload・GenUI・SPM既定化・HCPP、Material/Cupertinoはコア凍結

現行安定版は Flutter 3.44.7 / Dart 3.12。3.44の目玉は Agentic Hot Reload・Generative UI・Androidの Hybrid Composition++・iOS/macOSで SPM が既定。Material/Cupertino は3.44でコア凍結され、将来 material_ui / cupertino_ui として独立パッケージへ分離。次の機能リリースは2026年8月。

📅 2026年8月5日 ⏱ 約3分 🔗 出典 4 件

Flutterは年4回（2/5/8/11月）の機能リリースで進み、3.44は Google I/O 2026 で公開された。現行安定版は Flutter 3.44.7 / Dart 3.12。採用例としてFlutterが2026 Toyota RAV4のインフォテインメントで稼働するなど、組込み領域にも広がっている。次の機能リリースは2026年8月で、3.45系はまだ未リリース——いまは3.44系で足場を固める局面だ。

何が新しいか。目玉は4つ。①Agentic Hot Reload＝AIエージェントの変更を即時反映、②Generative UI（GenUI）、③Androidの Hybrid Composition++（HCPP） でプラットフォームビュー合成を改善、④iOS/macOSで Swift Package Manager（SPM）が既定に。ロードマップ『Finishing the Job』はAndroidのImpeller移行完遂（Android 10+でlegacy Skiaバックエンド撤去）とWebのWebAssembly既定化を掲げる。

設計上の一番大きな変化は、Material・Cupertinoが3.44でコアに凍結され、将来 material_ui / cupertino_ui として独立バージョニングのパッケージへ分離する点だ。狙いはM3更新を四半期SDKリリースを待たずに届けること。新デザイン（M3 Expressive等）はコアSDKでは新規開発されず、分離後の新パッケージ側で進むため、採用計画はコアSDKではなく新パッケージの動向で立てる必要がある。

UIプリミティブも増えた。ShapedInputBorder は任意の ShapeBorder で入力枠を作れ、RoundedSuperellipseBorder で入力枠をiOS風にできる。ExpansionTile の基盤 Expansible が柔軟になり toggle メソッドが追加、Cupertinoには CupertinoMenuAnchor。土台の Impeller（iOS=Metal / Android=Vulkan、API 29+既定）は shader compilation jank を排除し、目標は UI〜4ms＋raster〜4ms。フレーム予算は60fps=16ms／90fps=11ms／120fps=8.3msで、計測はDevToolsをprofileモードで。

状態管理の基本線は不変：新規の既定は Riverpod 3.0（compile-time safety・最小ボイラープレート、現行3.3.x）、監査証跡が要る規制業界（fintech/healthcare）は Bloc 9.0（現行9.2.x）。両者は共存でき移行はscreen-by-screen。自分が試すなら：iOS/macOSプロジェクトをSPMへ寄せてCocoaPods依存を減らし、入力枠は RoundedSuperellipseBorder でネイティブ感を出す。注意点：3.45待ちで機能を止めず3.44系の最新パッチへ追随し、Impellerは実機（特にミッドレンジAndroid）で検証。まとめ：3.44は『開発ループと合成と依存管理を底上げしつつ、Material進化の主戦場をパッケージへ移す』転換点だ。
