Flutter 2026-10-01 — 3.50へ降りる土台と、AnimatedList・feature-first・ValueNotifierの実務

現行安定は3.47.5。11月の3.50へWasmGC既定化とImpeller一本化が降りてくる。アニメ（リスト増減）・設計（feature-first 3レイヤ）・パフォ（ピンポイント再ビルド）を実務目線で。

📅 2026年10月1日 ⏱ 約4分 🔗 出典 5 件

現行の安定版はFlutter 3.47.5 / Dart 3.13.4（9/18 patch）、betaは3.49.0-0.1.pre / Dart 3.14。次の安定機能リリース3.50は2026年11月で、そこへ降りてくる主目玉がWebのWasmGC既定化（flutter build web --wasm、dart:html→package:web）とAndroidのImpeller一本化（legacy Skiaバックエンド撤去、API29+）だ。2026ロードマップ“Finishing the Job”は年4回サイクル（2/5/8/11月）、Performance・DX/Tooling・Web/Accessibility・Stability＋AIの4本柱で進む。

アニメ：リストの増減はAnimatedListに任せる

行の挿入/削除を自然に見せるならAnimatedList。GlobalKey<AnimatedListState>を保持し、_key.currentState!.insertItem(index)/removeItem(...)を呼ぶと該当行だけをフレームワークがアニメする。肝はデータ配列の変更とListへの通知を必ず対で行うこと（片方だけだとindexがずれる）。itemBuilderのanimationをSizeTransition(sizeFactor: animation, child: FadeTransition(...))に通すと高さ＋フェードの出入りになる。removeItemのbuilderには“削除直前の中身”を渡す（配列からは既に消えているため）。使い分けの軸は、micro=implicit（AnimatedContainer）→リスト増減=AnimatedList/AnimatedGrid→連鎖=flutter_animate→精密/多段=explicit（dispose必須）→重いアート=Rive/Lottie。土台のImpellerがshaderをAOT precompileして120fpsを支える。

設計：feature-first × 3レイヤ

lib/features/<feature>/の下をpresentation（widgets・ViewModel/Notifier）/domain（entities・repository抽象・use cases）/data（models・data sources・repository実装）に割り、横断コードはlib/core/へ。肝はdomainをFlutter/パッケージ非依存に保つこと——抽象クラス（interface）だけ置き、dataが実装する。依存方向はpresentation → domain ← dataで内向き固定（domainは他層をimportしない）。エラーはEither<Failure, T>（fpdart）かDart 3のsealed Resultで型として表し、UIはswitch/whenで網羅チェックする。DIはget_it＋injectableでrepository/use caseを登録し、Riverpod Notifierへ注入、テストはoverrideWithValueで差し替える。

パフォ：ValueNotifierでピンポイント再ビルド

単一値ならValueNotifier＋ValueListenableBuilderでその builder だけ再ビルドでき、setStateのようにwidget全体を巻き込まない（パッケージ不要）。不変の重い子はchild:へ逃がして毎フレームの再生成を防ぎ、使い終えたらdispose()で破棄。複数値はListenable.merge([a, b])でまとめて購読できる。局所UI state（フォーム1項目・カウンタ・スクロール位置・アニメ値）に最適で、アプリ全体の共有・DI・非同期はRiverpod/Blocの担当という役割分担になる。計測は必ずprofileモードのDevTools PerformanceでUIスレッド（Dart実行）とRasterスレッド（GPU）を分離して見る（フレーム予算 60=16.6 / 90=11.1 / 120=8.33ms）。

ひとこと：新規既定はRiverpod 3.3＋go_router＋Freezed、監査/規制/大規模はBloc 9.2。11月の3.50に向けて、Web（Wasm）とImpeller一本化は今から手元で試しておきたい。
