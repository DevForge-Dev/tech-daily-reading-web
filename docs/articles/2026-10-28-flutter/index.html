Dart 3.14のdot shorthands — 型名を落として書く（11月3.50を前にbeta先取り）

文脈型が分かる所で .center や .all(16) と書ける新言語機能。あわせてBlocのbloc_concurrencyで並行イベントのレース対策（sequential/droppable/restartable）も整理する。

📅 2026年10月28日 ⏱ 約4分 🔗 出典 5 件

11月の stable 3.50 を前に、Dart 3.14 の dot shorthands（ドット短縮）が beta に載った。深くネストした widget ツリーの型名ボイラープレートを削る言語機能で、現状は beta 3.50.0-0.2.pre 同梱（stable 3.47.8 / Dart 3.13.7 は未搭載）。本番は 3.47.8 を pin しつつ別CIジョブで beta を緑化、という従来の二枚看板運用のまま先取りできる。

何が変わるか

コンパイラがcontext type（期待される型）を確定できる場所なら、static メンバー・enum 値・コンストラクタ呼び出しの型名を省略して . から書ける。

// before
Container(
  alignment: Alignment.center,
  padding: const EdgeInsets.all(16.0),
  child: Column(
    mainAxisAlignment: MainAxisAlignment.center,
    crossAxisAlignment: CrossAxisAlignment.start,
  ),
)
// after（Dart 3.14）
Container(
  alignment: .center,
  padding: const .all(16.0),
  child: Column(
    mainAxisAlignment: .center,
    crossAxisAlignment: .start,
  ),
)

対象は enum（.spaceEvenly 等）、static プロパティ（FontWeight.bold → .bold）、named コンストラクタ（EdgeInsets.all() → .all()）。多くのプロパティは基底型（例 EdgeInsetsGeometry）を受けるため、Flutter 側が基底クラスに redirecting constructor を足してサブクラスへ橋渡しする。注意は文脈型が不明な所では使えないこと（型推論が効く引数・初期化・return 位置が前提）。公開 API など型を明示したい箇所は従来表記も併用する。

同じ日のもう一つの実務ネタ：Bloc のイベント並行性

Bloc は v7.2.0 以降イベントが既定で並行（concurrent）処理。これが read-then-write を含むとレースコンディションの温床になる。bloc_concurrency の transformer を on<E> の named 引数 transformer: に渡すだけで制御できる。

勘所は書き込み/累積は sequential・冪等でない単発送信は droppable・検索/最新入力は restartable・独立I/Oは concurrent。残高 $100 への加算が2件来ても、sequential なら後勝ちで $40 を失わない。

ひとことまとめ

dot shorthands は「書く速さと読みやすさ」、bloc_concurrency は「正しさ」。前者は 3.50 を待たず beta CI で素振りし、後者は今日から既存 Bloc の on<E> を用途別に貼り替えるだけで効く。material_expressive 0.8.0（spring モーション＋morphable shape）や flutter_animate の .animate().fade().scale() も、同じ「宣言的に効果を積む」潮流だ。
