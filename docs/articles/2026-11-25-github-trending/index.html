11/25の話題リポジトリ — 広告なしデスクトップ実用3本と、エージェント開発を支える基盤3本

Rust/Tauri 製の“軽いデスクトップ道具”と、iOSテスト・ローカルモデル継続学習・一貫ビジュアル生成という開発基盤。消費者向けの快適さと、エージェント開発の地味な穴埋めが同じ日に並んだ。

📅 2026年11月25日 ⏱ 約5分 🔗 出典 6 件

今日の6本を貫くのは2つの流れ。前半は Rust/Tauri でネイティブに作り直した“軽いデスクトップ道具”——広告やブラウザのタブから逃れる方向。後半は エージェント開発の地味だが効く穴埋め——Mac なしの iOS テスト、遊休GPUでのローカルモデル継続学習、一貫したビジュアル生成。消費者の快適さと開発基盤が同じ日に並んだ格好だ。各リポジトリについて「どんな課題を解こうとしているか」「何ができるか」を押さえる。（本日は daily 未掲載のため、増加は日平均★で代替評価。数値はリポジトリ実測。）

Avaneesh-Inamdar/Stream-Tube-Desktop（Rust・⭐約857）

解決したい課題：「ブラウザのタブを開きっぱなしにせず、広告も自動再生もなしで YouTube を観たい」という素朴な不便。提供する機能：gpui(Rust GUI)＋mpv のネイティブ再生で、広告・トラッキングなし(Windows/Linux)。SponsorBlock・DeArrow・Return YouTube Dislike を標準内蔵。作成約3日で日平均約286★＝本日クリーン新星の最速級。非AIの消費者向け道具が純粋なモメンタムで伸びた例。

qianyiai/kurocat（TypeScript/Tauri・⭐約602）

解決したい課題：配信者が使う Bongo Cat 系オーバーレイを、OSS・クロスプラットフォーム・MCP 対応で手軽に。提供する機能：キー入力に合わせて動く透明・最前面のデスクトップ「打字猫」兼 OBS 透明ソース。6種の猫＋鯨娘、パスワード入力時の覗き見防止、AI での見た目生成(MCP)に対応(Win/Mac/Linux/Android)。Tauri v2＋Rust/TS。可愛さと実用の合わせ技で急伸。

tristanbuckmaster/navier-stokes（Lean・⭐約424）

解決したい課題：ミレニアム級の未解決問題（ナビエ–ストークス正則性）に関わる主張を、人手の査読だけでなく機械検証可能な形に落とす。提供する機能：Alpöge・Buckmaster の「有限時間爆発」を主張する79ページ論文と、Lean 4 形式化を同梱。各定理の形式ステートメント・証明に加え、使用公理を propext/Quot.sound/Classical.choice に限定する comparator を持つ。先の Riemann 予想 Lean 形式化と同じ Alpöge による「大問題を Lean で」潮流の中核。（主張の真偽判断はせず、話題化している事実のみを扱う。）

Developing-Gamer/agent-sim（Rust・⭐約544）

解決したい課題：iOS の E2E/ビジュアルテストは Mac 必須で CI に載せづらい、という長年の壁。提供する機能：Mac も GPU も使わず x86-64 Linux VM 上で iOS シミュレータ(x86Sim)を動かし、AI エージェントに「.ipa インストール→画面をテキストで読む→タップ/入力/スクロール→ブラウザで目視」をさせるエージェント層。Apache-2.0。モバイル E2E をクラウド/CI で回す将来の土台になり得る。

sous-labs/songe（Python・⭐約631）

解決したい課題：「1人×エージェント×多プロジェクト」で効いてくるトークンコストを、ローカルモデルで削りたい。提供する機能：普段使いのローカルモデルを opencode/pi 等 OpenAI 互換ツール越しに使いつつ、各アクション後の結果・エラー・次指示を観察し、エージェントが空いている間に遊休GPUで継続学習(蒸留/LoRA/MLX)してモデルを鍛える学習エンジン。既存ワークフローに非侵襲。生徒モデルのローカル実行基盤が前提な点は要注意。

xikhar/papercraft（JavaScript・⭐約606）

解決したい課題：エージェントに作らせるビジュアルが毎回バラバラで、統一した“らしさ”を出しにくい。提供する機能：ゲーム・インタラクティブシーン・Web・アニメ・動画を、立体の「飛び出す絵本(ポップアップ紙工作)」風の統一スタイルで生成させるエージェントスキル。出荷済み three.js ゲームの「写真に写った紙模型に見せる」ノウハウ（マット紙・薄い切り口・世界の色で染まる影・ティルトシフト）を数値化して移植。MIT。

まとめ — 自分が試すなら

消費者枠なら Stream-Tube-Desktop を一度入れて SponsorBlock 内蔵の快適さを体感するのが手軽。開発基盤として本命は agent-sim——Mac 不要の iOS テストは CI に組めれば効果が大きい。コスト最適化に興味があれば songe を小さなローカルモデルで観察運用から。いずれも作成数日のクリーン新星で、採用判断は自動実行せず様子見から。
