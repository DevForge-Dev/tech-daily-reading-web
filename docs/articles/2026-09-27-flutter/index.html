Flutter 3.47深掘り — Impellerが全デスクトップ既定に、アニメは宣言的チェーン、go_routerは型安全へ

現行安定3.47/Dart3.13。Impellerのデスクトップ既定化、flutter_animateの連鎖、go_routerのcodegen、画像デコード最適化までを一望。

📅 2026年9月27日 ⏱ 約3分 🔗 出典 4 件

2026 年秋の Flutter は「レンダラの世代交代」が節目になった。現行安定は Flutter 3.47 / Dart 3.13.3（9/11 パッチ）、次の安定機能リリースは 11 月、beta は 3.48 / Dart 3.14。日々の UI 実装に効く変更が広範囲に入っている。

何が新しいか

最大の節目は 3.47 で Impeller が macOS / Windows / Linux の既定レンダラに昇格したこと。SDF（Signed Distance Function）レンダリングで文字が鮮明になり、macOS では Wide Gamut Color が既定 ON。最低 OS が iOS 15 / macOS 12 に引き上げられ、iOS の Swift Package Manager 移行は上位100プラグイン中92 まで到達した。デザイン面では material_ui / cupertino_ui 1.0 が standalone パッケージ化され、dart fix --apply --code=migrate_design_widgets で移行できる（旧ライブラリは11月に deprecate）。Web は WasmGC 既定化へ前進した。

仕組みの勘所（アニメとアーキ）

アニメは flutter_animate が Effect をメソッドチェーンで宣言する——widget.animate().fadeIn().slide().scale() のように書き、.then(delay: ...) で順次連結、AnimationController の定型を排除できる。ループや外部制御は onPlay / Animate(controller:) で行う。アーキテクチャは go_router が中心で、@TypedGoRoute の codegen で type-safe routes を生成し（const XRoute().go(context)）、文字列パスの typo を排除する。ボトムナビ等のネストしたタブは StatefulShellRoute.indexedStack で各ブランチの state（スクロール位置・入力）を保持したまま切替。認証ガードは redirect に集約する。新規の既定は Riverpod 3.3.x（@riverpod codegen・自動リトライ）、監査/規制/大規模は Bloc 9.2.x という住み分けだ。

パフォーマンスとフレーム予算

UI パフォーマンスで最重要なのは 画像のデコード解像度を落とすこと。Image(..., cacheWidth: 300) や ResizeImage で表示サイズにデコードし、元解像度のまま抱えない。ネットワーク画像は cached_network_image（memCacheWidth）＋幅・高さ明示。再描画の隔離は RepaintBoundary、長リストは ListView.builder ＋ cacheExtent / itemExtent。そして計測は必ず profile モードで DevTools を使う。

まとめ

「Impeller が全デスクトップで既定」「アニメは宣言的チェーン」「ルーティングは codegen で型安全」の3点が、いま新規プロジェクトで押さえるべき既定値だ。自分が試すなら、既存の implicit アニメを flutter_animate に寄せて定型を削り、go_router を @TypedGoRoute 化して文字列パスを一掃するのが投資対効果が高い。
