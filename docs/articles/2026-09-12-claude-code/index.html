Claude Code

v2.1.268 — gateway.yamlのpricingで/costがメーター一致、/diffライブ差分パネル、既定はFable 5.1・1Mコンテキスト

派手さより「運用の締め」の週。gateway.yamlのpricingでサインイン済みクライアントに同一レートを配り/costを組織の支出メーターに一致させる管理強化、会話の横で未コミット変更を追う/diffライブパネル、そしてFable 5.1既定化と1Mコンテキスト標準化を棚卸しする。

📅 2026年9月12日 ⏱ 約3分 🔗 出典 3 件

9月のClaude Codeは新機能の派手さより「組織としての運用を締める」方向に効く更新が続いている。今日は9/10公開の v2.1.268 のゲートウェイ課金管理、少し前に入った /diff のライブ差分パネル、そして Fable 5.1 の既定化＋1Mコンテキスト標準化を、この時期に効いてくる変更としてまとめて押さえ直す。

何が新しい/重要か

v2.1.268 の目玉は gateway.yaml の pricing: 設定だ。これを置くと、サインイン済みのClaude Codeクライアントが managed settings 経由で組織と同一のレートを受け取り、/cost やテレメトリの表示が組織の支出メーターと一致する。価格は multiplier と overrides（upstream / model / input / output / cache_read / cache_write）で細かく指定でき、ゲートウェイ v2.1.227 以降＋admin:、または 2.1.268 以降の managed:（1つ以上のポリシー必須）で有効化する。あわせて access_control.allow_cidrs が空のときの起動時警告、公開アドレスからの初回リクエスト警告、社内IPv4帯から /login を許す gatewayInternalNetworks も入った。

/diff と 既定モデル

/diff は v2.1.260 で追加され、フルスクリーン表示中に会話の横へ差分パネルを開き、Claudeが編集するそばから未コミットの変更をライブ更新する。これまで2つ目のターミナルやIDEを併用して追っていた変更を、同一画面で並べて確認できる。トグル式で、1回目で開き2回目で閉じる。フルスクリーン外では従来型の差分表示になる。モデル面では v2.1.257 以降 Fable 5.1 が新しい既定のFableモデルになり、Opus 5・Fable 5.1・Sonnet 5 はいずれも1Mコンテキストが標準、価格も改善した。時刻表示のカスタマイズ設定も新設されている。

実務での使いどころ・注意点

ゲートウェイ運用のチームは、まず pricing: を入れて /cost を実支出と一致させ、誰がいくら使ったかを同じ物差しで見るところから始めたい。allow_cidrs 空の起動警告は放置せず、公開面を絞る。/diff は大きめのリファクタを回すときに常時開いておくと、Claudeの編集の当否をその場で判断できる。注意点として、pricing: は上流の実価格ではなく組織が見せたいレートなので設定値の管理を明確にすること、managed: はポリシー最低1つが必須である点を押さえる。

ひとことまとめ

「いくらで、どこから、どのモデルで」を組織で締める回。pricingでコストの見え方を揃え、/diffで変更を可視化し、既定はFable 5.1・1Mへ。毎日回すエージェント運用の足回りが一段固くなった。
