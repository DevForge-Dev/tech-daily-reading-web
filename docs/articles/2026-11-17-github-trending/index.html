dream-num/univer（TypeScript・⭐27.7k）

解決したい課題：表計算・文書・スライドのような“業務オフィス”機能を自社プロダクトに持たせたいが、編集・計算・共同編集・ファイル処理を一から作るのは重い。しかも今は人だけでなく AI エージェントも同じ文書を操作する前提が要る。提供する機能：スプレッドシート/ドキュメント/スライドの編集・計算・共同編集・ファイル処理を1つの SDK で提供する、人にも AI エージェントにも使える『自分だけの AI オフィス』基盤（Apache-2.0＝組込可）。なぜ急上昇：本日 +1,878 で当日の増加数トップ（総⭐27,742・率約6.8%、前日 +1,041 の #2 から #1 へ加速）。AIチャット/エージェント運用に偏る当日トレンドの中で、業務オフィス SDK という多様性枠として突出した。created 2022-09-29 の老舗だが当日スパイクが明確だ。

elementalsouls/Claude-BugHunter（Python・⭐7.4k）

解決したい課題：Claude Code を使ったアプリのセキュリティ検査が体系化されず、脆弱性カテゴリごとの観点が属人的・手動頼みになりがち。提供する機能：Claude Code 向けのバグハンティング/外部レッドチーム用スキル束で、24 の中核脆弱性カテゴリにわたる 82 スキル・15 スラッシュコマンド・681 の公開レポート由来パターンを収録（防御的/正規のバグバウンティ用途、MIT）。なぜ急上昇：本日 +1,057＝率約14.3%で当日ランキングに新規登場（#2）。AIオフィス/UI系に偏る中でセキュリティという希少ジャンルが刺さった。脆弱性カテゴリ別に整理されたスキル束は、手動監査の底上げ・レビュー強化の一次情報源になりうる。

Noniv/abyssal-garden（JavaScript・WebGPU・⭐1.7k）

解決したい課題：没入感のある 3D 体験を Web で届けるには重いエンジンやアセット配信が要る、という常識。提供する機能：揺れる海藻の森・差し込む光・沈没船・泳ぐマンタが広がる幻想的な海中世界を、すべてコードと WebGPU で生成し、ブラウザで泳ぎ回れるインタラクティブ作品（MIT）。なぜ急上昇：当日 daily には未掲載（gain『—』）だが、created 2026-11-12＝公開約5日で⭐1,674（日平均約335★/日）の高速新星で、fork率も約15%と不自然さはない。エージェント運用一色の当日トレンドに対する、希少なクリエイティブ/グラフィックス（WebGPU）多様性枠だ。
