Next.js 16 — JS不要で“広がる画像パネル”: flex-growトランジションだけ、RSCのままアクセシブルに

flexとフォーカスだけで、'use client'もバンドル増もなしに横アコーディオンを作る。

📅 2026年10月5日 ⏱ 約3分 🔗 出典 4 件

横並びの画像パネルのうち、カーソルを乗せた(またはキーボードでフォーカスした)一枚だけが大きく広がり、他は細く縮む——「expanding panels / horizontal accordion」と呼ばれる定番インタラクション。ヒーロー、ギャラリー、特集セクション、プラン比較で「少ない面積にリッチな選択肢を詰める」ために使われる。

何が新しい/効くのか。肝はJavaScriptが一切要らないこと。Flexboxのflex-grow(ショートハンドのflex)はCSSトランジションで補間できるので、:hoverと:focus-withinにtransitionを掛けるだけで滑らかに開閉する。JSゼロということは、Next.js App Routerでは'use client'不要のReact Server Componentのまま実装でき、ハイドレーション負荷ゼロ・バンドル増ゼロで成立する。

仕組み。display:flexのコンテナに子パネルを並べ、各パネルにflex:1。.panel:hover／.panel:focus-withinでflex:6にするだけ——兄弟は相対的に縮むので個別指定は不要。画像は親をposition:relativeにして<Image fill>、object-fit:coverで追従させ、min-width:0を必ず付ける(付け忘れるとflexアイテムが縮まず崩れる定番の罠)。補間できるのはflex-grow/basis/shrink/gapで、justify-content/align-items/orderは離散的に「カクッ」と切り替わる(滑らかにしたいならFLIPが必要)。

.panels { display:flex; gap:.5rem; height:60vh; }
.panel  { flex:1; min-width:0; overflow:hidden; border-radius:14px;
          transition: flex .5s cubic-bezier(.22,1,.36,1); }
.panel:hover, .panel:focus-within { flex:6; }
.panel img { width:100%; height:100%; object-fit:cover; display:block; }
@media (prefers-reduced-motion: reduce){ .panel{ transition:none; } }

自分が試すなら。サーバー描画の一覧はRSCのまま置き、クリック開閉が要る時だけ小さなclient子に切り出してaria-expandedをトグルする。LCPになる先頭画像にはpriority、sizesでオーバーフェッチを防ぐ。

落とし穴。flex-growの遷移は毎フレームレイアウト(リフロー)を起こす——transform/opacityのようなコンポジットのみの最適化は効かず、will-changeも効果が薄い。数枚〜十数枚なら実用上問題ないが、数十枚を同時アニメートは避ける。アクセシビリティでは、:hoverだけだとキーボード/タッチで開けないので:focus-withinを必須にし、中に実リンク/ボタンを置く。折り畳み時のラベルはdisplay:noneで消すとスクリーンリーダーからも消えるので、見た目だけ隠してラベルは担保する。:focus-visibleを潰さず、prefers-reduced-motionでtransitionを無効化する。

ひとこと。「広げる」ためにJSを足す前に、flexとフォーカスだけで足りないかをまず疑う。
