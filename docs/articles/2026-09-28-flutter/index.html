Flutter 3.48 beta の実務地図 — Widget Preview安定化・Impellerで起動最適化・Riverpod 3.3のAsyncNotifier

11月安定版へ向け、開発体験（Widget Preview/DevTools）とデータ層設計が一段進んだ。

📅 2026年9月28日 ⏱ 約4分 🔗 出典 7 件

現行安定版は Flutter 3.47.4 / Dart 3.13.3（9/11 patch）、beta は 3.48 / Dart 3.14、次の安定機能リリースは2026年11月。この節目に向けて、派手な新 API より開発体験とデータ層設計が一段進んだのが今回の要点だ。

目玉は Widget Preview の安定化。@Preview() を付けた関数を flutter widget-preview start で専用ウィンドウにホットリロード表示でき、デバイス起動なしで複数ウィジェットを並べて確認できる。Preview(size:, textScaleFactor:, brightness:, theme:) で条件も切れる。DevTools 3.x は Performance view で UI／Raster（GPU）スレッドを分離表示し、Impeller の shader compile が0であることを確認できる。新設の「Rebuild counts」タブでウィジェット単位の再ビルド回数も追える。dart fix --apply --code=migrate_design_widgets は material_ui / cupertino_ui 1.0 への移行を収録（旧デザインライブラリは11月stableで deprecate）。iOSはSPM既定化がbetaで前進、WebはWasmGC既定化へ。

アニメーションは粒度で使い分けるのが定石だ。精密な時差（staggered）は1本の AnimationController から CurvedAnimation(curve: Interval(0.0,0.5)) で複数 Tween を時間帯に割り当て、フェード→スライド→スケールを順次発火させる。画面遷移は Hero（flightShuttleBuilder で飛行中ウィジェットを差し替え、createRectTween で弧を描く軌道に）や PageTransitionsTheme（Androidの予測型「戻る」は PredictiveBackPageTransitionsBuilder）で一元設定する。

データ層は sealed class の Result<T>（Success/Failure） でネットワーク結果を表し、switch の網羅性チェックで握り潰しを防ぐ（Freezed 3.x の sealed/union で生成）。状態管理の新規既定は Riverpod 3.3.x の AsyncNotifier——build() が Future を返し、UIは AsyncValue.when(data/loading/error) で分岐、ref.watch(p.select(...)) で必要フィールドだけ購読して再描画を最小化する。AutoDispose で画面を離れると破棄、必要時のみ ref.keepAlive()。監査・規制・大規模チームは Bloc 9.2.x（event transformer・blocTest）が向く。

実務でどう試すか：まず Widget Preview で主要画面のバリアント（ダーク／文字拡大）を並べ、DevTools の Rebuild counts で無駄な再ビルドを1つ潰す。注意点は、旧デザインライブラリの11月deprecate（dart fix で早めに移行）、AutoDispose 忘れによるメモリ保持、Web の WasmGC 既定化に伴うビルド確認。サイズは flutter build appbundle --analyze-size の Tree Map でコード／アセット内訳を見て、アイコンの tree-shaking と可変フォント集約で削る。Impeller により旧来の SkSL warm-up は不要になった。

ひとこと：11月stableは「速く作って速く動かす」土台固め。Widget Preview＋Rebuild counts で作る速さを、Impeller＋Result/AsyncNotifier で動く速さと堅さを取りにいく。
