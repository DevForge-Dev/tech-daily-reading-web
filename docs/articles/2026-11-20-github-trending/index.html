XiaoYouChR/Ghost-Downloader-3（Python・⭐約12.7k）

解決したい課題：ファイルや動画を落とす手段は HTTP ダウンロード、BitTorrent、HLS（m3u8）とバラバラで、既存の DL マネージャは UI が古かったり一方式しか扱えなかったりする。提供する機能：「下載器の集大成」を掲げ、HTTP/BT/m3u8 等を asyncio で非同期・並行に高速ダウンロードするオールインワンDLマネージャ。Fluent Design のモダン GUI でクロスプラットフォーム対応。本日 +449（率約3.5%）——AIエージェント一色のトレンドで、純粋な実用デスクトップユーティリティとして根強い支持を集めた非AI多様性枠だ。GPL-3.0 なので製品組み込みは注意、開発利用は問題ない。

openvinotoolkit/openvino（C++・⭐約11.5k）

解決したい課題：学習済みの深層学習・生成AIモデルを、GPU クラウドに頼らず手元の CPU/GPU/NPU で速く・省リソースに動かしたい。提供する機能：Intel 発の OSS 推論ツールキットで、モデルを各種ハードウェア向けに最適化してデプロイする。computer-vision から diffusion-models・generative-ai まで幅広くカバーする。本日 +246（率約2.1%）——老舗の巨大プロジェクトながら、生成AI/拡散モデルのローカル最適化需要を背景に再注目。エージェント/スキル束に偏る当日トレンドで希少な C++ 推論基盤という多様性枠で、Apache-2.0（商用可）。

zhouxiaoka/autoclip（Python・⭐約11.2k）

解決したい課題：ポッドキャストや対談・講義といった長尺動画から「切り抜き（短尺クリップ）」を作り各 SNS へ再投稿する作業は、切り出し・字幕・カバー・投稿文まで含めると手作業の塊になる。提供する機能：一本のリンクから長尺を自動で短尺クリップに切り出し、字幕・カバー・投稿文まで生成する OSS の AI 動画編集デスクトップアプリ。抖音/小紅書/TikTok/Reels/YouTube Shorts 向けに最適化し、MCP 対応でエージェントからも扱えるのが新規性だ。本日 +110（率約1.0%）、MIT（商用可）。

DevForge の文脈で一番触りたいのは autoclip。MCP 対応なので、既存の Claude 定期タスクから「長尺→切り抜き＋投稿文」まで繋げられる余地がある（devforge-shorts 系と相性が良い）。ローカル推論を詰めるなら OpenVINO、純粋に日々の DL 作業を楽にするなら Ghost-Downloader-3——いずれもクラウド非依存で手元完結する点が、今日の3本に共通する良さだ。
