Flutter 3.50 stable直前の検証プレイブック — Wasm昇格・Impeller一本化・Dart 3.14 Augmentations

11月の3.50昇格を待たず、今betaでCIを緑に。破壊的変更の先回りと、ポーズ中のmacrosを代替する言語機能まで。

📅 2026年10月20日 ⏱ 約3分 🔗 出典 3 件

11月のstable 3.50を前に、Flutterは「今のうちに検証しておくべき破壊的変更」が出そろった。現況を固定すると、安定は 3.47.7 / Dart 3.13.5(10/8 patch)、betaは 3.50.0-0.1.pre / Dart 3.14.0 で、これが11月stable 3.50へ昇格する最初のbetaビルド(ブランチ flutter-3.50-candidate.0)。昇格を待って慌てるのではなく、beta側でCIを緑にしておくのが今回の勘所だ。

3.50で確定している破壊的変更

WebAssembly遅延ロードがexperimental→stableへ昇格、AndroidはImpeller一本化が完了(legacy SkiaバックエンドをAndroid 10+で引退)、そしてAndroid 17のday-zero対応。加えてSDK内蔵のMaterial/Cupertinoは3.50で正式deprecationとなり、dart fix --apply --code=migrate_design_widgets で material_ui/cupertino_ui 系へ移行する。本番チェックは flutter build web --wasm と flutter build appbundle を今のうちに緑にしておくこと。

本番は「二本立て」で回す

pubspec/CIで安定を 3.47.7にpin しつつ、別ジョブで flutter channel beta && flutter upgrade の3.50を回す。昇格前に壊れる箇所(Wasm/Impeller/Material分離)をbeta側で先に緑化しておけば、11月の昇格日に事故らない。

# 別ジョブ（beta検証）
flutter channel beta && flutter upgrade
flutter build web --wasm      # Wasm昇格を先取り検証
flutter build appbundle       # Impeller一本化/Android 17

開発体験と言語機能

Widget Previewerが3.47でstableに昇格。ローカルビルドキャッシュで起動が速くなり、@Preview でウィジェットを隔離確認する開発ループが本採用ラインに乗った(VS Code/IntelliJ連携、プレビューの検索・フィルタがリアルタイム)。言語面ではDart 3.14のAugmentations(beta同梱)——既存クラスへ後付けでメンバー/メソッド/コンストラクタを足す機能で、無期限ポーズ中のmacrosの実務代替。freezed/json_serializable のcodegenが本体を汚さず注入する土台になる。

ひとこと：3.50は「待つ」より「今betaで検証する」リリース。Wasmビルドとappbundleを今日CIに足しておけば、昇格は非イベントになる。
