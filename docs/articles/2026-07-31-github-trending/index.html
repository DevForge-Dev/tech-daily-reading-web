7/31の話題リポジトリ — Cowork代替・2GB RAMで26Bモデル・AIペンテスト自動化

今日の3本を貫くのは「AIの主導権を手元へ」。プロプライエタリなCoworkのOSS化、巨大モデルの省メモリ・ローカル化、そしてセキュリティ作業のAI自動化。

📅 2026年7月31日 ⏱ 約2分 🔗 出典 3 件

今日 GitHub で急伸したリポジトリから、共通する潮流「AIをオープンに・ローカルに・自動で」を体現する3本を取り上げる。いずれも Trendshift 日次上位の New 2026 だ。

different-ai/openwork（—・⭐New 2026）

解決したい課題：Claude Cowork のようなエージェント常駐ツールはプロプライエタリで、自前ホストや拡張の自由が効かない。提供する機能：opencode を実行基盤に据えたCowork のオープンソース代替で、ローカルのファイル操作やアプリ連携をエージェントに委譲して成果物を仕上げる。自前ホストで拡張の自由度を確保できる点が刺さり、Cowork/常駐エージェントへの関心の高まりに乗って Trendshift 日次7位まで急拡散した。

drumih/turbo-fieldfare（—・⭐New 2026）

解決したい課題：高性能な大規模モデルはメモリ要求が大きく、一般的な Mac ではローカル推論しづらい。提供する機能：Gemma 4 26B-A4B を M シリーズ MacBook の約2GB RAM で推論できる軽量ローカル推論。26BクラスのMoEを小メモリで動かす「小メモリで大モデル」の技術的インパクトが、ローカルLLM需要の中で日次3位まで押し上げた。

zhaoxuya520/reverse-skill（—・⭐New 2026）

解決したい課題：リバース/ペネトレーション等のセキュリティ作業は手作業が多く、必要なツールチェーンの用意も属人的になりがち。提供する機能：AI が必要に応じてツールを自動ブートストラップし、経験を蓄積して自己進化するセキュリティ・スキルルーター。Claude Code/Kiro/Cursor/Cline に対応する。日次8位で、スキル・ブームの中で拡散した。攻撃的ツールゆえ自前環境限定での慎重運用が前提だ。

試すなら：まず openwork を触って Cowork の中身を理解しつつ、turbo-fieldfare で「手元で動くLLM」の体験を確かめる。reverse-skill は隔離環境でのみ。共通するのは、AIの実行をベンダー任せにせず手元に取り戻す志向だ。
