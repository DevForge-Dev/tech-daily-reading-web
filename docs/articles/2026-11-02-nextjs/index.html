回転グラデ枠・ボーダービームを『JSゼロ』で — `@property` の角度アニメ × `conic-gradient` × `mask-composite` で枠だけ・丸角対応・Server Componentのまま

SaaSのおすすめプラン強調で定番化した“光る枠/走るビーム”。ライブラリ版はクライアントコンポーネント化するが、`@property` で `<angle>` を補間しconicの開始角を回すだけなら、`'use client'` 不要・JSバンドル増ゼロ・ハイドレーションゼロ・CLS0で同じ見栄えが出る。

📅 2026年11月2日 ⏱ 約4分 🔗 出典 5 件

背景・なぜ今これか。カードやCTAの枠に沿ってグラデが回転する／光の筋が1周する演出は、Magic UI・Aceternity・Motion UI の <BorderBeam> などで2025〜2026に定番化し、プライシングカードの『おすすめプラン』強調で大量にコピーされている。要点は、この流行りの核心が純CSSだけで組め、しかもNext.jsではServer Componentのまま実現できること。ライブラリ版は便利だが 'use client' 化してJS/ハイドレーションを伴う。

何が新しい/重要か。conic-gradient(...) は画像で補間できないため直接は滑らかに回せない。そこで『角度という補間できる型の変数を動かし、グラデはそれを読むだけ』にする。未登録の --angle は汎用型扱いでカクつくが、@property で <angle> として登録すると 0→360deg を滑らかに補間する。登録時の3つ(syntax・inherits・initial-value)は必須で、1つ欠けると @property 全体が無効になる。

@property --angle { syntax:"<angle>"; inherits:false; initial-value:0deg; }
@keyframes spin { to { --angle: 360deg; } }
.card::before {
  content:""; position:absolute; inset:0; border-radius:inherit; padding:2px;
  background: conic-gradient(from var(--angle), #6ee7ff, #a855f7, #f472b6, #6ee7ff);
  -webkit-mask: linear-gradient(#000 0 0) content-box, linear-gradient(#000 0 0);
          mask: linear-gradient(#000 0 0) content-box, linear-gradient(#000 0 0);
  -webkit-mask-composite: xor; mask-composite: exclude; pointer-events:none;
}

仕組みのポイント。2枚の不透明マスク(全体＋content-box)を exclude で差し引くとリング部分だけ可視になる＝丸角が破綻せず中身は透過のまま。『ボーダービーム』は全周グラデの代わりに狭い明るい弧＋大部分 transparent の conic にすれば光が枠を走り、size(弧の角度長)・duration(1周秒)・thickness(枠px)がそのまま対応する。発光は ::after 複製＋filter:blur() で足す。

Next.js(App Router)での組み込み。純CSSなので @property・@keyframes・リングのスタイルは CSS Module か globals.css に置くだけでServer Componentのまま。動的な色/速度はサーバーからCSSカスタムプロパティをinline styleで渡す(style={{'--beam-from': plan.color}})ので、データ駆動でも 'use client' は要らない。SSRで出るのは静的な枠HTML、回すのはCSS側——だからハイドレーションmismatch無し・JSバンドル増ゼロ・CLS0。ライブラリ版を使うなら next/dynamic で遅延読込するか、要所だけ純CSS島に置換を検討する。

落とし穴・自分が試すなら。--angle のアニメは transform/opacity と違いコンポジタ合成では済まず毎フレーム再ペイント(conic再計算)になる。小さなカード枠1個なら実害は小さいが、大量/大面積に同時適用すると重い——ビームは要所に絞り、will-change は乱用しない。アクセシビリティは『色だけで状態を伝えない』＋回転は @media (prefers-reduced-motion: no-preference) の中だけに置き、縮退時は initial-value の静的グラデ枠を残すのが作法。まずは本命の方式Bで、プライシングカードの『おすすめ』1枚だけに当てて手触りと塗り残しを確かめるのが現実的だ。
