11/4のNext.js — パタパタ時計で学ぶ『時刻mismatch』撲滅術：mounted-gate・絶対時刻props・ドリフトしない自己補正ループ

空港のパタパタ式カウントダウンは装飾に見えて、App Routerで最頻出のハイドレーションmismatchを丸ごと内包する。きれいな3Dより『時刻をどこで読むか』が本題。

📅 2026年11月4日 ⏱ 約4分 🔗 出典 4 件

背景・なぜ今これか。 ローンチ／セール終了までの残り時間を、数字カードが折れて切り替わる split-flap（パタパタ式）で見せる定番UI。見た目は装飾だが、Next.js（App Router）では「サーバーが描いた残り時間」と「クライアントが描いた残り時間」は必ずズレる＝ハイドレーションmismatchの最頻出パターンそのもの。だから価値は3Dの美しさより (1)時刻をどこで読むか (2)ドリフトしない更新 (3)パタパタをSRに読ませない の設計にある。

何が新しい/重要か：3つの設計原則。 ①target は絶対時刻（エポックms）をサーバーからpropsで渡す。レンダー内で Date.now()+86400e3 と計算すると、キャッシュ/ISRされた時刻に固定されたりSSRとCSRで基準がズレる。②表示は毎tick remaining = target - Date.now() で“再計算”する。remaining-- のような減算カウンタは setInterval の遅延が累積して必ずドリフトする。③初回描画はmounted-gateでサーバーとクライアントを一致させる。

仕組み①：パタパタは4レイヤー＋2段階 rotateX。 1枚の数字カードを上下に割り、「静止2枚」＋「回るリーフ2枚」で構成する。前半は古い値のまま上半分が倒れ、中点で入れ替わり、後半で新しい値の下半分が起き上がる——これが split-flap の本質。親に perspective、リーフに backface-visibility:hidden（裏の数字の透け防止）、transformのみ＝GPU合成で依存ゼロ。

仕組み②：mismatchとドリフトの潰し方。 SSRとCSR初回は同じ安定プレースホルダ（全桁00）を描き、useEffectで mounted=true にしてから実時刻でtickを開始する。これで mounted がfalseの間はHTMLが完全一致し mismatch が出ない。さらに setTimeout を 1000 - (Date.now() % 1000) で次の秒境界に貼り直す自己補正と、visibilitychange でタブ復帰時に即再計算を入れると、放置で狂った表示も一瞬で正される。

useEffect(() => {
  setMounted(true);
  const tick = () => {
    setMs(target - Date.now());            // 毎回“再計算”＝ドリフト無し
    t.current = setTimeout(tick, 1000 - (Date.now() % 1000)); // 自己補正
  };
  tick();
  const onVis = () => document.visibilityState === "visible" && tick();
  document.addEventListener("visibilitychange", onVis);
  return () => { clearTimeout(t.current); document.removeEventListener("visibilitychange", onVis); };
}, [target]);

実務での使いどころ・自分が試すなら。 ページ本体とデータ取得はRSCのまま、「カウントダウン島」1つだけ 'use client' にして target（固定イベント時刻のエポックms）をpropsで流す構成が基本。既製で済ますなら @leenguyen/react-flip-clock-countdown（renderOnServer／stopOnHiddenVisibility／duration）を使う。これらのpropはまさにSSRズレ・タブ非表示ズレ対策そのものなので、propの名前が設計の勘所をそのまま教えてくれる。

注意点・落とし穴。 ①新しい値が先にめくれる：current/nextを分け animationend で確定。②CLS/横揺れ：font-variant-numeric: tabular-nums とカード固定寸法。③SRが数字を連呼：視覚カードは aria-hidden にし、role="timer" aria-live="polite" の人間語ライブ領域（「残り2日 4時間」）を分単位で更新。④prefers-reduced-motion: reduce では折りを止めて値だけ差し替える（WCAG 2.3.3＝動きは止めても意味は残す）。

ひとことまとめ。 パタパタの本体は純CSS。難所は3Dでなく「時刻の読み場所」。絶対時刻props＋毎tick再計算＋mounted-gateの3点を守れば、Text content did not match もドリフトも出ない。
