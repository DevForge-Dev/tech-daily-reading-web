Claude Code v2.1.234で上限リセット後の自動継続、Opus 5が新デフォルトOpusに — 1Mコンテキストで難タスク推論

8/17のv2.1.234は利用上限リセット後にセッションを自動継続（/configで無効化可）、GitLab MRバッジ、CLAUDE_CODE_PROJECT_DIR_NAMEを追加。プラットフォームではOpus 5が新デフォルトOpus（1Mコンテキスト・価格はOpus 4.8同等）に昇格し、Opus 4.1は8/5で廃止。GitLab Duo連携やmask mode、Microsoftの+24%実証も揃った回。

📅 2026年8月18日 ⏱ 約3分 🔗 出典 5 件

この日はランタイムとモデルの両方が動いた。まずCLI側、8月17日リリースのv2.1.234で、claude.aiの利用上限がリセットされた瞬間にClaude Codeがセッションを自動的に継続するようになった（/configでオフ切替可）。上限に当たって作業が止まり、手動で再開していた人には地味に効く。GitLabリモートを持つリポジトリではMR（マージリクエスト）状態バッジがフッター/ステータスラインに出るようになり、ホスト向けのCLAUDE_CODE_PROJECT_DIR_NAME環境変数、selection:clearキーバインドも新設された。

より大きいのはモデル側だ。プラットフォームのリリースノートでOpus 5が新しいデフォルトのOpusとして追加され、1Mトークンのコンテキストに対応、価格はOpus 4.8と同額に据え置かれた。一方でclaude-opus-4-1-20250805（Opus 4.1）は廃止予定日の2026年8月5日に到達済みで、移行先はOpus 4.8とされている。Claude CodeやManaged Agents（メモリ整理の「Dreams」など）もOpus 5対応に加わった。

足回りの改善も続く。VS Code拡張にFocus viewが入り、ツール実行ログを折りたたんで会話の見通しを保てるようになった。v2.1.221ではサンドボックスの資格情報にmode: "mask"が加わり、Linux/WSLで実値を渡さずに外部APIを呼べる。zipから導入するarchiveプラグインソース（SHA-256ピン留め任意）も追加された。

事例も強い。GitLabはOpus 5をDuo Agent Platformに統合し、テストでは実装構築→コミット→MR作成まで自動化。GitLab Creditsの利用上限で並列エージェントの支出にハードリミットをかけられる。市場面ではUncoverAlphaがARR 25億ドル超・週次ユーザー年初比倍増・エンタープライズ契約4倍と報じ、arXiv研究はMicrosoft導入者がPRマージ量+約24%と定量化した。

自分が試すなら：Opus 5の1Mコンテキストは、大きめのモノレポを丸ごと読ませる系のタスクで効く。ただしコンテキストが広い＝入力トークンが嵩むので、常用はOpus 4.8、難所だけOpus 5という使い分けが現実的。GitLab運用なら上限リセット自動継続とMRバッジで、放置気味の並列運用がやりやすくなる。落とし穴：mask modeはあくまで資格情報の秘匿で、Claudeが読むコード自体は推論のため送信される点は変わらない。

まとめ：v2.1.234とOpus 5で「止まらない・大きく読める」方向に進化。1Mは万能ではなくコスト意識込みで使い分けるのが吉。
