NVIDIA/Personal-AI-Router（—・⭐約168）

解決したい課題：手元に複数のマシンやデバイスがあっても、LLM推論を1台で抱え込むとメモリとスループットが頭打ちになる。提供する機能：家庭内の複数デバイスをまたいでLLM推論を仮想的に分散させるルーター(NVIDIA公式)。総約168に対し当日+26＝増加率約15%と本日トップ級で、Trendshift日次24位。エージェント一色の上位にシステム/インフラの多様性を足す純モメンタム枠だ。

openJiuwen-ai/jiuwenswarm（—・⭐約627）

解決したい課題：強力なLLMがあっても、専用アプリを開かないと使えないと日常の作業導線から外れてしまう。提供する機能：日常使う各種コミュニケーション/チャットアプリ経由で LLMエージェントを手元に届ける(openJiuwen基盤)。当日+55(総約627＝増加率約9%)・Trendshift日次8位と本日最大級の実増加で、「指先までLLM」という体験設計が刺さった。

h4ckf0r0day/obscura（Rust・⭐約417）

解決したい課題：AIエージェントや大規模スクレイピングでheadless Chromeを並列起動するとメモリを食いすぎる(10並列で2GB超)。提供する機能：Rust製の省リソースなヘッドレスブラウザ(V8でJS実行・CDP対応・約300MB)。Puppeteer/Playwrightのドロップイン代替でMCPサーバも同梱、Apache-2.0で製品組み込み可。Trendshift日次19位。
