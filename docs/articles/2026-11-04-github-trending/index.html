11/4の話題リポジトリ — AI一色の谷間で伸びた『非AI』3本：USB不要のLinux導入・LaTeXの花柄余白・欧州移住ハンドブック

トレンド上位がAIツールで飽和するなか、純粋に伸びたのはどれも非AI。面倒を消すユーティリティ、尖った創作、出典付きの知識ベース——“人の手触り”で拡散した3本。

📅 2026年11月4日 ⏱ 約3分 🔗 出典 3 件

本日もトレンドはAIツールで飽和していたが、純粋な急上昇（モメンタム枠）で上位に食い込んだのは3本とも非AIだった。システムユーティリティ・ジェネラティブアート・知識ベースと畑は違うが、共通点は「AIの便利さではなく人の具体的な面倒／好奇心／意思決定を正面から解いた」こと。各リポジトリについて〈解決したい課題〉と〈提供する機能〉を分けて見る。

Arjun-Ingole/hop（PowerShell・⭐約1.5k）

解決したい課題。 Windowsの隣にLinuxを入れたいが、USBメモリの用意・ブートメディア作成・パーティション操作といった事前準備の面倒が初心者の壁になっている。提供する機能。 入れたいディストリ・ドライブ・割り当て容量をドラッグで決めてボタン1つでインストールする単体Windowsアプリ。USB不要で、ISOは各プロジェクトの公式サーバーから取得しチェックサムを検証する堅実設計（野良バイナリに頼らない）。なぜ今急上昇か。 公開約4日で実測約1,452★（日平均約350★/日）。AI飽和の谷間で希少な、純粋な「面倒ごとを消すDX」が刺さった。MIT。

kevinraymond/florilegium（Lua・⭐約1.4k）

解決したい課題。 「LaTeXでこの花の余白はどう作るのか」というRedditの質問が発端で、組版で凝った装飾を手で描くのは難しいという創作上の壁。提供する機能。 LuaLaTeX向けに、デルフト陶器のような青い花柄のページ余白を手続き的に（毎回違う模様で）描き出すパッケージ。プレイグラウンド・CI・OpenSSF Scorecard同梱で完成度が高い。なぜ今急上昇か。 公開約5日で実測約1,406★（日平均約303★/日）。「手続き的ジェネラティブアート×組版」という尖った創作ドメインの多様性枠として拡散。MIT。

BryceYuuu/RUN（Markdown・⭐約3.0k）

解決したい課題。 海外移住は「どのルートを選ぶか」の判断が複雑で、各国の制度情報も散在している。提供する機能。 欧州36か国・110の移民ルートを、デジタルノマド／技術移民／EUブルーカード／起業・自雇／投資居留の軸で、380超の出典付きに整理した実務ハンドブック（『RUN・润』）。意思決定ガイドから各国制度詳細まで一気通貫。中英二言語・CC-BY-SA-4.0。なぜ今急上昇か。 公開約6日で実測約3,002★（日平均約547★/日）＝当日計測組で最高率級。出典リンク付きの網羅性が評価された、非AI・知識ドメインの多様性枠。

まとめ・自分が試すなら。 3本に共通するのは「AIを使わずとも、具体的な面倒／好奇心／意思決定を丁寧に解けば今でも伸びる」という事実。開発に直接効くのは hop（検証付きISO取得という堅実なDX設計の手本）と RUN（出典を必ず紐づける知識ベースの作法）——どちらも自分のドキュメント運用やツール設計の“誠実さ”の参考になる。florilegium は息抜きに眺めたい一本。
