Dart 3.12 が減らすボイラープレート — dot shorthands・private named params と Agentic Hot Reload 本番昇格

Flutter 3.44 / Dart 3.12。文脈から型が自明なら .foo で省略できる dot shorthands が成熟、初期化仮引数の先頭 _ で公開名を自動決定する private named parameters、Agentic Hot Reload が experimental→productionへ（Dart MCP server 経由で自動hot reload）。UIは Material 3 Expressive。

📅 2026年8月7日 ⏱ 約3分 🔗 出典 5 件

今日の Flutter は「書く量を減らす言語機能」と「エージェント連携」が主役だった。現行安定版は Flutter 3.44 / Dart 3.12（3.44 は Google I/O 2026 で公開）、次の機能リリースは年4回サイクルの 2026年8月。8月版が来る前に 3.44 系で足場を固める好機だ。

何が新しいか（言語）。Dart 3.10 で導入された dot shorthands が 3.12 で成熟し、型が文脈から自明なら enum 値・static メンバー・コンストラクタを .foo と省略できる（Flutter 公式サンプルも移行済み）。private named parameters は初期化仮引数・primary constructor 引数の先頭 _ で公開名を自動決定し、カプセル化を保ったままボイラープレートを削る。実験的な primary constructors はクラスヘッダにフィールドとコンストラクタを畳み込み、3行の値クラスを1行にする。

何が新しいか（エージェント）。Agentic Hot Reload が experimental から production へ昇格した。Dart MCP server 経由でコーディングエージェントが DTD 接続 URI を手動コピーせず自動で hot reload でき、AI にコードを直させながら即座に反映——という反復が滑らかになる。あわせて Generative UI（GenUI） も追加された。描画基盤は Impeller が iOS＋Android API 29+（Vulkan）の既定で、非対応端末は Skia にフォールバックする。

UI/状態管理の現在地。UI は Material 3 Expressive が焦点で、15の新規/更新コンポーネント・spring ベースの新モーション物理・35 のシェイプと shape morphing を追加し、より感情に訴える動的UXを作る（useMaterial3 は既定、2026 は M2 のままだと古く見える）。状態管理は「新規＝Riverpod 3.0（自動リトライ・offline persistence・Mutations・画面外リスナーの自動pause）、監査/大規模＝Bloc 9.0（on<Event> で event→state を直列化し監査証跡）」が基本線。アニメは約80%を implicit（AnimatedContainer 等）で、複雑な choreography だけ explicit に寄せる。

使いどころ・落とし穴。dot shorthands と private named parameters はすぐ使える生産性機能で、Widget ツリーの型名反復を大きく削れる。一方 primary constructors は experimental なので本番投入は様子見が無難。Agentic Hot Reload は MCP 対応エージェントとの組み合わせが前提で、まずは既存プロジェクトで Dart MCP server を繋いで自動反映を体験するのがよい。パフォーマンスはフレーム予算（60fps=16ms / 120fps=8.3ms）と再ビルド削減が軸で、const 徹底・select による局所再描画を効かせる。

ひとことまとめ。「言語で書く量を減らし、エージェントで反映を速く、UIはExpressiveで today らしく」。まずは .foo 省略と _ 付き名前付き引数への置換から手をつけたい。
