数値だけを美しく回す — NumberFlow を App Router に組み込む

指標・価格・いいね数が変わる瞬間を、依存ゼロ・アクセシブルに演出する @number-flow/react。Intl.NumberFormat × Web Animations API で、Client 島に隔離して使うのが定石。

📅 2026年7月29日 ⏱ 約3分 🔗 出典 4 件

ダッシュボードの指標やカート合計を「パッと差し替える」だけだと変化に気づかれない。桁がスロットのように転がる演出は効くが、自前だと桁揃え・ロケール/通貨・アクセシビリティ・reduced-motion が地味に重い。NumberFlow（Maxwell Barvian 作）はこの「変化する1つの数値」に特化した2026年の定番で、React 版が @number-flow/react（現行 v0.6.x、MIT）だ。

新しさは3点に集約される。依存ゼロでランタイム依存を持たず、ブラウザ標準の Intl.NumberFormat（整形）と Web Animations API（桁のスピン）だけで動くので軽い。アクセシブルで、内部は Custom Element + Shadow DOM。読み上げには整形済みテキストを渡し、視覚的な桁アニメだけを分離、prefers-reduced-motion を既定で尊重する。そして format/locales に Intl.NumberFormatOptions をそのまま渡せるフォーマット力——通貨・パーセント・compact（1.2K）・端数処理が宣言的だ。

App Router では、<NumberFlow> は state 変化で value を更新するインタラクティブ部品なので、それを使うコンポーネントに 'use client' が要る。ただしページ全体をクライアント化せず、値を持つ小さな島に隔離するのが定石。SSR は安全で、初期 value をサーバー値と一致させれば hydration mismatch は起きない。

'use client'
import NumberFlow from '@number-flow/react'
import { useState } from 'react'

export function Price({ initial }: { initial: number }) {
  const [value, setValue] = useState(initial) // サーバ値で初期化＝hydration一致
  return (
    <span style={{ fontVariantNumeric: 'tabular-nums' }}>
      <NumberFlow value={value}
        format={{ style:'currency', currency:'JPY', trailingZeroDisplay:'stripIfInteger' }}
        locales="ja-JP" />
    </span>
  )
}

実務では、Server Action 更新→revalidateTag で新値が来て自動スピン、useOptimistic と併用で押下即カウントが動く、という通知系に効く。親に font-variant-numeric: tabular-nums を付けると桁シフトが起きにくい。落とし穴：scientific/engineering 記法・非ラテン数字・RTL は非対応（日本語ロケールの数字はラテンなのでOK）。要素自体の枠や背景を滑らかにスケールさせたい凝ったカードは Motion for React 併用が推奨。まとめ：数値専任と割り切れば、少ないコードでプロダクトの「変化」がきちんと伝わる。
