Claude Code v2.1.224 — セルフホスト環境とセッション間メッセージングで「チーム基盤」へ

8/7のv2.1.224は31件の大型更新。claude self-hosted-runnerで自社マシン/コンテナをweb・モバイル・デスクトップのセッション実行環境にでき、セッション間メッセージング（ListAgents/SendMessage）で並行セッションが破壊検知・回答共有を横断配送。HTTPS上zipのarchiveプラグイン（SHA-256ピン留め）も加わった。

📅 2026年8月8日 ⏱ 約2分 🔗 出典 3 件

Claude Code は 8/7 の v2.1.224 で、単体のCLIから「チームの実行基盤」へと性格を変えた。31件の変更を含む大型リリースで、目玉はセルフホスト環境とセッション間メッセージングの2つ。クラウド実行の利便性（並列セッション・遠隔起動）は保ちつつ、実行の「場所」と複数セッションの「連携」という運用面の弱点を埋めにきた。

何が新しいか

claude self-hosted-runner で、自社のマシンやコンテナを web/モバイル/デスクトップセッションの実行ランナーとして登録できる（Team/Enterprise）。社内ネットワーク内・内部サービスの隣でエージェントを走らせられるため、コードやデータを外に出さずに済む。もう一つの目玉、セッション間メッセージングは、あるセッションの変更が別セッションの前提を壊す時に警告を、逆にブロック要因だった問いに答えが出た時に回答を横断配送する。仕組みは2つのツールで、ListAgents で到達可能なエージェントを発見し、SendMessage で名前を指定して届ける。あわせて git/npm を介さず HTTPS 上の zip からプラグインを導入する archive プラグインソース（任意で SHA-256 ピン留め）も追加された。

実務での使いどころ

10PJを1人で横断する運用だと、セッション間メッセージングが効く。別PJのセッションで共通ライブラリを触った時に「この変更、依存側の前提を壊すよ」と自動で飛ばせれば、破壊的変更の取りこぼしが減る。セルフホストは、機密が絡む案件でクラウド実行を避けたい時の逃げ道になる。archiveプラグインは、自作プラグインを社内配布する際に marketplace を立てずに zip 一個で配れるのが軽い。

注意点

セルフホスト・セッション間メッセージングとも macOS/Linux（WSL2内Linux含む）が前提で、Windowsネイティブは対象外。セルフホストは Team/Enterprise プラン限定。archive の zip は SHA-256 ピン留めをしないと供給元の差し替えリスクが残るので、配布時は必ず固定する。

ひとことまとめ：「どこで走らせるか」「複数セッションをどう繋ぐか」に手が入った回。個人の並行運用でも、破壊検知の横断配送は地味に効く。
