AGP 9＋built-in Kotlinへ今すぐ移行 — Hero飛行・状態復元・アダプティブUIの要点も

stable 3.47.8のセキュリティ更新と、11月の3.50昇格を見据えたKotlin内蔵化が今日の軸。Hero / RestorationMixin / M3 window size classesの実務ポイントも押さえる。

📅 2026年10月25日 ⏱ 約5分 🔗 出典 5 件

stableは 3.47.8。eMudhra中間CA失効に対応するセキュリティ更新（勧告 GHSA-frr6-h895-5pxp）で、10/8の3.47.7/Dart 3.13.5から一段上がった。betaは 3.50.0-0.1.pre / Dart 3.14.0 で、11月のstable 3.50昇格は不変。本番は3.47.8をpinしつつ別ジョブでbetaを検証するのが堅い。今この時期に緑化しておきたいのが AGP 9＋built-in Kotlin だ。AGP 9.0ではKotlin Gradle Plugin（KGP）の明示適用サポートが撤去され、FlutterがKotlinを内蔵管理する。Flutter 3.44がbuilt-in Kotlin無効のままAGP 9対応、有効化（android.builtInKotlin=true）は3.47以降。移行ツールが暫定で android.builtInKotlin=false と android.newDsl=false を自動追記する。

移行手順（アプリ）：android/app/build.gradle(.kts) の plugins{} から id("kotlin-android") を削除し、android{} 内の kotlinOptions{ jvmTarget } を削除 → トップレベルに kotlin{ compilerOptions{ jvmTarget = JvmTarget.JVM_17 } } を追加。全依存プラグインの移行を確認してから gradle.properties に android.builtInKotlin=true を設定し flutter run で検証する。未移行のFlutterプラグインがあるとKGP非互換でビルド失敗（issue #181383）。KGPを使っていないアプリは移行不要で、android.newDsl=false だけでよい。

アニメーションは Heroの飛行制御。飛行中の見た目は flightShuttleBuilder(flightContext, animation, direction, fromHeroContext, toHeroContext) で差し替え、direction（push/pop）で往復を出し分ける。円→矩形のラジアルHeroは、既定のコーナー補間だと比率が歪むため createRectTween: (b,e) => MaterialRectCenterArcTween(begin:b, end:e) で中心を弧補間する。iOSのスワイプバックに連動させるなら Hero(transitionOnUserGestures: true)。同一ルートに同じ tag が2つあるとassertで落ちるので、可変indexでなくID/モデルをtagにする。

OSキル後の状態復元は RestorationMixin。MaterialApp に restorationScopeId を定義し、TextField/ScrollView には restorationId を与えるだけで組込復元が有効。自作widgetは restoreState(oldBucket, initialRestore) 内で registerForRestoration(prop, 'id') する。対象はinstance state（未送信フォーム値・選択タブ等）でAndroid 1MB上限。開発者オプションの「アクティビティを保持しない」で破棄を再現して検証する。アダプティブUIは、窓全体のサイズは軽量な MediaQuery.sizeOf(context)、局所の制約は LayoutBuilder で測り、M3 window size classesで分岐する（<600はbottom NavigationBar、600dp以上は NavigationRail）。flutter_adaptive_scaffold はdiscontinuedなので、素の LayoutBuilder＋sizeOf＋size classesで組むのが素直だ。

自分が試すなら：まずCIに3.47.8 pin＋beta検証ジョブを用意し、AGP 9移行とKotlin内蔵化を今のうちに通す。ひとこと：11月の3.50に向け「ビルド基盤の移行」が最優先、UIはHero/復元/サイズ分岐の定番を押さえておけば盤石。
