Claude Code — denyInsteadOfPromptingと/loop・Autoモードの破壊的変更、Opus 4.8高速モードは11/30終了

無人で止まらない運用へ既定を締め直したリリース。確認待ちを拒否で続行する新設定、/loopとAutoモードの破壊的変更、そして11/30のOpus 4.8高速モード終了。

📅 2026年11月13日 ⏱ 約4分 🔗 出典 4 件

公式 CHANGELOG はこのセッションの可読範囲で v2.1.311 までしか反映されていないが、二次情報（classmethod 英語版・ClaudeWorld）で v2.1.318→319 と11月総覧の輪郭が見えてきた。今回のテーマを一言でいうと「止まらない自動運用」——人が張り付いていない headless／scheduled 実行で、確認プロンプト待ちや暗黙フォールバックに足を取られないよう、既定の振る舞いが締め直された。※バージョン番号・構文・件数はすべて二次情報に基づく。

権限：確認待ちで止めるな、拒否して進め

新設定 permissions.denyInsteadOfPrompting は、本来なら確認プロンプトで待つツール呼び出しを「拒否」してターンを止めずに続行させる（terminal／subagent／teammate で有効）。無人運用では「誰も Yes を押さないまま固まる」のが最悪なので、止まるより拒否して次へ進ませる発想だ。値の型や既定値・正確な構文は記事に記載がない点は要注意。

破壊的変更が2つ：Auto モードと /loop

Auto モードは、テレメトリや feature flag が無効な環境（LLM ゲートウェイ背後を含む）で、従来の内蔵分類器フォールバックをやめ「確認または拒否」へ変わった。内蔵分類器を維持するなら CLAUDE_CODE_AUTO_MODE_SERVER=0、ゲートウェイでサーバ判定を使うなら =1（Bedrock/Vertex/Foundry は不変）。もう一つ、自己ペースの /loop は、ターンが自分を再スケジュールしないまま終わると「終了」するようになった。従来の“フォールバック起床で生き続ける”挙動に戻すには CLAUDE_CODE_LOOP_KEEPALIVE=1。ループ運用している人は黙って止まる前に確認を。加えて MCP タスクがターミナルでも背景実行できるようになった（CLAUDE_CODE_DISABLE_MCP_TASK_BACKGROUND でオプトアウト）。

11月総覧とモデル：Opus 4.8 高速モードは11/30で終了

ClaudeWorld の11月まとめ（v2.1.308〜2.1.318・第三者集計で全9版582項目）によると、Opus 4.8 の高速モードは2026-11-30で終了予定で、記事は Opus 5.5 への移行を勧めている。ほかに ultrathink がターミナルで xhigh 実行に（v2.1.311）、permissions.blockWritesOutsideWorkingDirectories 新設（v2.1.314）、claude -p が起動エラーやフルディスクで終了コード1を返すよう修正、サインイン期限 loginExpiresAt の表示（v2.1.318）など、CI/ヘッドレスに効く修正が並ぶ。

自分が試すなら

scheduled 運用を持っているので、まず /loop の keepalive 挙動が変わっていないか既存ジョブを点検し、必要なら CLAUDE_CODE_LOOP_KEEPALIVE=1 を明示する。無人ジョブには denyInsteadOfPrompting を効かせて“固まり”を潰し、11/30 の Opus 4.8 高速モード終了に向けて使用モデルの棚卸しをしておく。設計面では DotNetNerd『5つのレバー』の整理——CLAUDE.md=常時の前提知識／skills=反復／hooks=確定的自動化／MCP=外部接続／sub-agents=並列・隔離——を基準に、今の構成を見直す。

注意点・落とし穴

数値・構文はいずれも二次情報で、一次 CHANGELOG はこのセッション時点で v2.1.311 まで。denyInsteadOfPrompting は「拒否」なので、本来人が許可すべき操作まで黙って弾いてログだけ残る恐れがあり、無人運用の“進む”と有人の“安全”はトレードオフになる。Auto モードと /loop はどちらも破壊的変更で、既存の自動パイプラインが前触れなく挙動変化しうる点が一番の罠。

ひとことまとめ

今回の Claude Code は機能追加より「無人で止まらない運用の既定を締め直した」リリース。/loop と Auto モードの破壊的変更、そして11/30 の Opus 4.8 高速モード終了は、放置すると後で刺さる。
