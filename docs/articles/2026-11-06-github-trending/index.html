KKKKhazix/agent-autoloop（TypeScript・⭐約3.2k）

解決したい課題：コマンドラインのAIエージェントは「人が指示→待つ→次を指示」の往復が重く、1人で複数プロジェクトを横断すると取りこぼしや観測性不足が起きやすい。提供する機能：エージェントを背後で常駐させ、自分でタスクを拾い最後まで追う"オートループ"。普段は邪魔せず、判断に迷う所だけカードを出して人間に決裁を仰ぐ。MCP / Claude Code / Codex対応・自己ホスト・MIT。なぜ今急上昇か：created 2026-11-03＝公開約3日で実測約3,219★/forks594（日平均約1,073★＝当日計測組で最高率33%の筆頭）。"提案ゲート＋人間決裁"という設計が、無人暴走を嫌う運用者に刺さった。

Verlintas/NOIR（Kotlin・⭐約2.5k）

解決したい課題：Androidアプリが裏で何の権限を使い、どの端点へデータを送っているかは利用者から見えない。広告除去系のdebloatは"消す"だけで、データの流れを示さない。提供する機能：PCからadb経由で各アプリの権限・通信先・データフローを静的解析してあぶり出し、ロールバック可能な対処まで提示する。プライバシー・フォレンジック寄り・Kotlin Multiplatform・MIT。なぜ今急上昇か：created 2026-10-31＝公開約6日で実測約2,451★/forks223（日平均約408★・率約16.7%）。単なる除去ツールでない防御的セキュリティの新規性で拡散した。

wquguru/cicada（Swift・⭐約1.5k）

解決したい課題：会議やライブ配信では言語の壁・聞き逃し・議事録作成の手間が同時に発生し、別々のツールを掛け持ちするのが煩わしい。提供する機能：任意の会議/配信にリアルタイム字幕・同時通訳・AI議事録を付ける無料OSS（知了 Cicada）。メニューバー常駐で音声認識＋翻訳＋要約を一体化し、Mac/Windows/Linux/Androidを横断。Swift/SwiftUI・Apache-2.0。なぜ今急上昇か：created 2026-11-01＝公開約5日で実測約1,478★/forks266（日平均約295★・率約20%）。4OS横断かつ無料という実用性が拡散理由。

まとめ（自分が試すなら）：10プロジェクト横断の日次運用に最も効くのは agent-autoloop——"迷う所だけ決裁"の設計が「提案→承認」「Yes-man禁止」の運用原則と一致する。NOIR は手持ちAndroid端末の権限棚卸しに一度回す価値があり、cicada は海外カンファ視聴や議事録の即戦力。いずれもMIT/Apache-2.0で利用に問題はない。
