Opus 5が既定Opusへ・v2.1.245でLinux起動修正 — 週次で締まる運用体験、売上25億ドル規模の定着

派手な新モデルより「毎日の使い勝手」を固める更新が続く。既定Opusが1MコンテキストのOpus 5へ、v2.1.245はLinux起動クラッシュを修正、/usageに暴走ループを見つける「Loops」内訳。裏では年換算売上25億ドル規模、エンジニアの73%が日常利用という定着が進む。

📅 2026年8月26日 ⏱ 約3分 🔗 出典 5 件

今日のClaude Codeは、最上位モデルの追加ではなく運用の細部を締める一日だった。既定Opusモデルが7月24日提供の Opus 5 に切り替わり、既定・最大とも100万トークンのコンテキストを扱える。価格は入力100万トークン $5 ／ 出力 $25 と Opus 4.8 から据え置きで、大規模リポジトリの横断調査や長時間セッションを一度に読み込める点が常用モデルとして推される理由だ。選択は /model か --model claude-opus-5。

何が新しいか

クライアント面では最新版 v2.1.245（8月25日）が一部Linuxディストリの起動時クラッシュを修正。直近では /usage に「Loops」内訳（ループごとの実行回数・総トークン・実行あたりトークン・最終実行）が加わり、暴走しがちな /loop タスクを特定しやすくなった。さらに modelPicker 設定で /model の候補を順序・ラベル付きで自由に整理でき、Vertex/Bedrock 表記のidも一覧に追加・置換できる。VS Code拡張もセッションのグループ化（作成/改名/削除・複数移動）と、ツール実行ログを畳む Focus view（Ctrl+Alt+F）を得て、多数セッションを並行運用する使い方に最適化された。

エコシステムの温度感

技術記事側では、Skills（オンデマンドに読む指示パック＝SKILL.md＋補助資産）、Hooks（PreToolUse/PostToolUse/Stop で発火する決定論シェル）、Subagents（独自コンテキストの分岐）を一気通貫で解説するガイドが2026年版として出そろった。事業面では年換算売上が25億ドル規模を突破、法人サブスクは年初比4倍・ビジネス顧客30万社超。利用統計でもエンジニアチームの73%が日常利用（前年41%）、生産性は26〜55%向上とされ、全Team/Enterpriseシートに標準付帯＋集中管理も揃った。

自分が試すなら・注意点

常用モデルを Opus 5 に寄せつつ、長時間タスクは /usage の Loops で消費を監視して暴走ループを早期に止める運用にしたい。modelPicker で候補を業務用に整理し、VS Code は Focus view で会話を見やすく保つ。注意点は更新頻度の速さで、破壊的変更の有無を確認しつつこまめに追従すること。企業導入は「ツール導入」ではなく変更管理として、1チーム起点で CLAUDE.md を磨き品質を測ってから横展開するのが定石だ。

ひとこと

モデルの世代交代が一段落し、可視化・整理・組織導入という「使い続けるための足回り」を固める局面。派手さはないが、毎日触る道具としての完成度が上がっている。
