2026年版アクセシブル・モバイルメニュー — native <dialog> + @starting-style + inert で自前フォーカストラップを捨てる

モバイルナビは全サイトに要るのに a11y との両立が難しい。dialog.showModal() はフォーカストラップ・inert化・Esc・::backdrop を標準でくれ、@starting-style/allow-discrete で開閉アニメも CSS だけ。React 側は use client のトグル状態と usePathname での遷移クローズだけで済む。

📅 2026年11月19日 ⏱ 約4分 🔗 出典 4 件

モバイルナビはほぼ全ての Next.js サイトに要るのに、見た目の作り込み（アイコンのモーフ・オーバーレイの出現・リンクの順次表示）と、アクセシビリティ（フォーカス管理・背景の無効化・スクロールロック・reduced motion）を両立できていない実装が多い。2024年にベースライン化した inert 属性と、ネイティブ <dialog> ＋モダン CSS を使えば、自前のフォーカストラップ JS を書かずに『開閉アニメ付き・アクセシブルな全画面メニュー』が最小コードで作れる。これが2026年版の最短ルートだ。

何が新しいか — <dialog>.showModal() が“ただで”くれるもの

dialog.showModal() を呼ぶだけで、フォーカストラップ・背景の inert 化・Esc で閉じる・::backdrop がブラウザ標準で付いてくる。これまで何十行も書いていたフォーカストラップ JS が丸ごと不要になる。閉じるときは dialog.close()。開閉アニメは、表示/非表示に display が絡むため transition-behavior: allow-discrete を併用し、入場の初期値を @starting-style に書く（opacity:0; translate:0 -8px → 到達値は [open]）。::backdrop にも同じ手でフェードインを付けられる。

仕組みのポイント

アイコンは 1要素＋::before / ::after 擬似要素の3本バーで作り、[aria-expanded="true"] のときに真ん中を rotate(45deg)、上下を回転・重ねて X へモーフする。transition は 対象プロパティを明示すること——transition: all を当てると擬似要素の scale(0) がスナップして崩れる。リンクのスタッガーは各 <a> に --i（0,1,2…）を振り transition-delay: calc(var(--i) * 60ms)。閉じるときに同じ遅延を使うと『最後のリンクが一番遅く消える』不自然さが出るので、閉時は遅延0か逆順が自然だ。スクロールロックは body { overflow:hidden } が基本だが、iOS Safari では効きにくいので position:fixed＋スクロール位置の保存/復元か overscroll-behavior: contain を併用する。

Next.js（App Router）への組み込み

トグル状態を持つラッパは 'use client' の Client Component にする。要はルート遷移で自動的に閉じること——SPA 遷移ではアンマウントされないため、usePathname() を購読して useEffect(() => setOpen(false), [pathname]) を入れないと、遷移後もメニューが開きっぱなしになる。アクティブリンクは pathname === href で aria-current="page" を付与。注意点として、cacheComponents（旧 PPR / use cache）有効時に generateStaticParams で網羅されない動的ルートで usePathname を使うとサスペンドするため、呼び出し側を <Suspense> で包まないとビルドが落ちる。Rewrite ＋静的プリレンダ併用時は usePathname() がハイドレーション不一致を起こしうるので、サーバでは安定なフォールバックを描き useEffect で実値を入れる。

reduced motion

@media (prefers-reduced-motion: reduce) で回転・移動・スタッガーを無効化し、瞬時表示か短いフェードだけ残す。開閉状態は aria-expanded で伝わるので、視覚アニメを削っても機能は損なわれない。

ひとこと：『アニメは CSS（@starting-style/allow-discrete）、モーダルの行儀は <dialog>、状態と遷移クローズだけ React』——役割を分ければ、JS は数行で済む。
