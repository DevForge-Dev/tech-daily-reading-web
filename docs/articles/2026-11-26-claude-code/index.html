v2.1.332 が latest 昇格 — MCPサーバー製スキルと新フック PreSkillShellCommand

next 止まりだった v2.1.332 が latest に。スキルをMCPサーバーから配れるベータと、スキル/コマンド内インラインシェルをロード時に拒否する新フックが対で入った。

📅 2026年11月26日 ⏱ 約3分 🔗 出典 2 件

前日まで npm の next タグ止まりだった v2.1.332 が本日 latest に昇格し、公式 CHANGELOG にも変更ノートが載った。日々のマイナー更新に見えて、今回は「スキルの配り方」と「スキル実行前の安全フック」という、エージェント運用の土台に効く2点が同梱されている。

何が新しいか

目玉は2つ。ひとつは MCP サーバーが提供するスキル（ベータ）で、/ メニューに server:skill 形式で並ぶ。これまでローカルの設定に置くものだったスキルを、MCP サーバー側から配布・共有できるようになる。もうひとつが新フックイベント PreSkillShellCommand。スキルやスラッシュコマンドの本文に埋め込まれたインラインシェルコマンドを、ロード時点で拒否できる。v2.1.331 以前は当該フックを書いた設定があると起動時にダイアログが出ていたが、今回これが正式イベント化された。ほかに、他セッションからの保留メッセージに「Always deliver」、応答ロギング時の OpenTelemetry assistant_response イベント、claude.ai サインイン時に起動ヘッダへ Cyber Verification Program のアクセスティア表示、など。

PreSkillShellCommand の勘どころ

スキルは「使うと便利」だが、本文にインラインシェルを含められるため、信頼していないスキルを読み込むだけでコマンドが走る余地があった。PreSkillShellCommand は、そのシェルが実行される前（ロード時）にフックを挟み、Command ハンドラの exit 2 等でブロックできる。「必ず止めたい」処理は CLAUDE.md の助言（約8割しか守られない）ではなくフックの決定論で止める、という本日の技術記事でも強調された設計思想にそのまま沿う。

実務での使いどころ・注意

MCP スキルを導入するなら、まず server:skill で何が増えたかを / メニューで確認し、未知のスキルは PreSkillShellCommand でインラインシェルを既定拒否→必要なものだけ許可、が安全側だ。加えて v2.1.332 は安定性修正が厚い——自動 compaction 失敗後の「Prompt is too long」、巨大ログや MCP 標準出力の洪水による端末フリーズ（Ctrl+C 無視）、Code Mode の4,096件超リストでツール呼び出しを黙って飛ばす不具合、Bedrock/Google Cloud/Foundry のモデルフォールバック（例：Bedrock Mantle の sonnet が Haiku 4.5 に化ける）などを修正。安定版チャネル stable も v2.1.325→v2.1.326 に前進した。

ひとことまとめ

「スキルを配れる（MCP）」「スキルを安全に止められる（PreSkillShellCommand）」が対で入った更新。エージェントを毎日動かす運用ほど、stable 追従か latest で早めに取り込む価値がある。
