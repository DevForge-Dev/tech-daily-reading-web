Claude Code

更新が止まった週にこそ読む — 権限バイパス系セキュリティ修正の中身と、v2.1.296「現在地」チートシート

新バージョンが5日連続で出ない静かな週。だからこそ直近で入った権限バイパス修正の中身と、いまのClaude Codeの全体像を棚卸ししておく。

📅 2026年10月14日 ⏱ 約4分 🔗 出典 4 件

10/14時点で公式changelogは10/9のv2.1.296が最新のままで、10/10〜10/14は5日連続で新バージョンが出ていない（直近では最長級の更新停止）。機能が増えない週は退屈に見えるが、こういう時こそ「すでに入った変更の意味」を落ち着いて読むのに向いている。今日は、週次レビュー（週of10/11）が集中して伝えている権限バイパス系のセキュリティ修正と、10/13公開のチートシートが描く「現在地」を押さえておく。

何が重要か：静かな更新の裏で「権限の穴」が4つ塞がれた

直近のリリースで目立つのは新機能ではなくセキュリティ修正だ。いずれも「許可したつもりのない操作が通ってしまう」タイプで、Auto Mode前提の運用では見過ごせない。

あわせて、WebFetchが10万字超を黙って切り捨てていた挙動をやめ、未読量の報告と offset 指定に対応（2.1.290）。過負荷(529)応答のリトライ間隔を延ばす環境変数 CLAUDE_CODE_OVERLOADED_RETRY_BASE/MAX_DELAY_MS も入った。v2.1.296本体では、全ワークフローエージェントを単一モデルで動かす CLAUDE_CODE_WORKFLOW_SUBAGENT_MODEL、サブエージェントごとの autoCompactWindow、Readの allow_large、そして managed PreToolUseフックが continue:false で拒否してもターンが終わらなかったバグの修正が含まれる。

現在地：120コマンド・33フック・Auto Mode既定・最大20並列

10/13公開のチートシートが規模感を一枚で示している。約120コマンド/スキル・33フックイベント・46ツール・243 settings.jsonキー・391環境変数。権限はv2.1.284以降Auto Modeが対話セッションの既定で、分類器が git reset --hard や terraform destroy のような破壊的操作を明示要求なしでブロックする（旧defaultは「Manual」に改称）。並列実行はサブエージェントが背景既定・3階層ネスト・最大20並列、/fork で独自ワークツリーの背景セッション複製、動的ワークフローは .claude/workflows/ にJSで保存。既定変更としてTodoWrite/Task系とGlob/Grepが新モデルに既定非提供になった点は、自前のワークフローを組んでいる人ほど影響が出る（必要なら CLAUDE_CODE_ENABLE_TODO_TOOLS=1）。

自分が試すなら

まず claude --version でv2.1.296以上か確認し、古ければ上げる（上の4つの穴が理由として十分）。運用方針は「個別承認を積むよりゴールを与えて背景agentに委譲、重要ルールはhooks/CLAUDE.md/支出上限でコード化」。/doctor・/skill-doctor で不要設定を一度掃除しておくとよい。市場面ではStack Overflow 2026でコーディングagent利用率がClaude Code 65.5% vs Codex 29.5%。API料金はHaiku5.5 $0.10/$0.50、Sonnet5.5 $2/$10、Opus5.5 $4/$20で、大量処理やサブエージェント統括にはHaikuを当てるのが定石になりつつある。

注意点

チートシートや「できること25選」系の記事は対象バージョンが1世代前のことがある（Ultraplanが廃止済みなのに新機能表に残る等）。数値や廃止状況は公式changelogで裏取りする前提で読む。週間ニュース（NTTデータが大阪にAnthropic初の日本DCで最終交渉＝$6.3B/500MW、MicrosoftがCopilot経由でClaudeに年$2B超支払い見通し等）はいずれも報道ベース・未検証なので、事実として引用しないこと。

ひとことまとめ

新機能ゼロの週＝安全に更新できる週。権限バイパス4件を取り込むだけでも、v2.1.296へ上げる価値がある。
