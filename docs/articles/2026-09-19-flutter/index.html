Widget Previews（stable）を毎日の開発ループへ — 全体ビルドなしで個別ウィジェットを反復

Flutter 3.47でstable昇格したWidget Previewsが主役。アプリ全体をbuild/起動せず個別ウィジェットをrender・inspect・iterateできる。現行安定版は3.47.4/Dart 3.13.3、@Previewアノテーションとローカルビルドキャッシュ、リアルタイム検索を搭載。beta 3.48/Dart 3.14、次の安定は11月見込み。

📅 2026年9月19日 ⏱ 約2分 🔗 出典 3 件

今日の主役は Widget Previews（stable）を毎日の開発ループに組み込むことだ。Flutter 3.47（2026-08-12）で stable に昇格し、アプリ全体を build・起動せずに個別ウィジェットだけを render・inspect・iterateできる。現行の安定版は Flutter 3.47.4 / Dart 3.13.3（2026-09-11 の patch）で、Impeller は全デスクトップで既定、最低 iOS 15 / macOS 12 に上がった。

何が新しいか

プレビュー対象は @Preview アノテーションで宣言し、IDE は dart/textDocument/getFlutterWidgetPreviews でメタデータを取得する。ローカルビルドキャッシュで起動を高速化し、リアルタイムのプレビュー検索/フィルタも載った。言語側では Dart 3.13 が primary constructors と dot shorthands を stable 化し、formatter・pub workspace・JS interop・tree-shaking を改善している。beta は Flutter 3.48 / Dart 3.14 で WasmGC 既定化と Android の Impeller 一本化を継続、次の安定機能リリースは 2026 年 11 月見込みだ。

実務での使いどころ

状態管理の基本線は変わらない——新規は Riverpod 3.3.1 ＋ @riverpod codegen、監査/規制業界は Bloc 9.2.x。DI は get_it＋injectable で Repository/UseCase/DataSource を層ごとに登録し状態層へ注入する。アニメーションは micro=implicit → 多段=flutter_animate のチェーン → component=explicit、と用途で使い分ける。パフォーマンスは RepaintBoundary＋const で描画コストを局所化し、重い計算は Isolate.run()/compute() で背景 isolate へ逃がすのが定石だ。

注意点・まとめ

計測は必ず profile モードで DevTools の flame chart を見て、フレーム予算（60fps=16ms / 90fps=11ms / 120fps=8.3ms）を超える関数を特定する。Widget Previews はあくまで開発補助で、実機の描画/入力挙動の最終確認までは置き換えられない点に注意。まとめると、レンダラは Impeller 前提、開発ループは Widget Previews で速く、状態は Riverpod 3 で堅く——2026 秋の Flutter はこの形だ。
