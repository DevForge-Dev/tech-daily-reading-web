Next.js — @propertyで動かすCSSオーロラ背景、重い所だけWebGL（Paper Shaders）

全画面の滲む背景は純CSS主軸で十分。@propertyで色を補間し、動かすのはtransform:translateだけ＝GPU合成。Server Componentのまま・JS増ゼロ・CLS 0で出せる。

📅 2026年11月12日 ⏱ 約5分 🔗 出典 3 件

Vercel / Linear / Stripe / Supabase 系の LP で定番化した、画面いっぱいにゆっくり滲み動くオーロラ／メッシュ・グラデーションのアンビエント背景。2025〜2026 で「ヒーローに静かに動く色の層を敷く」のがトレンド化し、ReactBits・Inspira UI・Paper Shaders などがこぞってコンポーネント化している。枠に光を回す「ボーダービーム」や文字の上を走る「シマーテキスト」とは違い、本テーマは面（全画面背景）を低速で滲ませるのが主眼だ。

技術の核は 2 本立て。基本は純CSS＝複数の radial-gradient ブロブを重ね、@property 登録した角度/位置/色を低速アニメする（JS ゼロ・Server Component のまま）。粒状ノイズや流体歪みが要るときだけ WebGL（Paper Shaders 等）へ逃がす。「まず CSS、足りなければ WebGL」という判断軸を持つのが実務の肝になる。

なぜ @property が要るのか。素の CSS カスタムプロパティは型が無く、ブラウザからは「画像（トークン文字列）」としてしか見えないため、グラデーション内の値はトランジション/アニメで補間されずカクつく。@property で syntax を与えて型登録すると、その値が補間可能な数値/角度/色になり、グラデが読んでも滑らかに動く。必須記述子は syntax と inherits の 2 つで、どちらか欠けるとルール全体が無効になる。@property は 2024-07-09 に Baseline Newly available（3 大エンジン対応）で、非対応時も initial-value の静止グラデが残り自然劣化する。

本テーマ最重要のパフォーマンス設計。大面積＋低速ゆえ「気づかぬうちにペイントが毎フレーム走る」のが最大の罠だ。background-position やグラデの色停止、@property の角度・位置を動かすのは毎フレーム“ペイント”（コンポジタ合成ではない）で、全画面だと面積が巨大。いちばん軽いのは、色ブロブを個別要素にして transform: translate() だけで動かす方式＝GPU コンポジタ合成で再ペイントを避ける。filter: blur() は毎フレーム再計算すると重いので、ぼかした見た目は radial-gradient のソフトなストップで“焼き込み”、要素は translate だけにする。

Next.js（App Router）では、純CSS 版は 'use client' 不要で Server Component のまま。@property とレイヤーの CSS を globals.css に置き、全画面背景要素を layout.tsx に 1 つ差すだけで、ハイドレーション mismatch なし・JS バンドル増ゼロ・CLS 0。WebGL 版だけ next/dynamic(..., {ssr:false}) の小島に隔離する（Server Component に ssr:false 直書きはビルドエラーなのでラッパ 1 枚）。Paper Shaders は 0.0.x で破壊的変更が入るためバージョン固定必須。アニメ付与は @media (prefers-reduced-motion: no-preference) の中だけに置き、縮退時は静的グラデを残すのが安全だ。

@property --h { syntax: "<angle>"; inherits: false; initial-value: 0deg; }
.aurora .blob {        /* translateだけ動かす＝GPU合成で軽い */
  background: radial-gradient(circle, oklch(72% .22 var(--h) / .55) 0%, transparent 70%);
  mix-blend-mode: screen;
}
@media (prefers-reduced-motion: no-preference){
  .aurora .blob { animation: drift 26s ease-in-out infinite alternate; }
}

ひとことまとめ：オーロラ背景は「@property で色を補間、動かすのは translate だけ」で純CSS・Server Component のまま高品質に出せる。WebGL は粒状感が本当に要るときの最後の手段に取っておく。
