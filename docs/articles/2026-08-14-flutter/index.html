Flutter 3.44.7とImpeller既定化 — SDF描画・Vulkan最適化と、新規はRiverpod 3を既定にする理由

現行安定版は3.44.7／Dart 3.12。ImpellerがAndroid既定になりshader jankを排除、複雑シーンでrasterizeを約50%短縮。状態管理の新規既定はRiverpod 3.3.1、監査/大規模はBloc 9.1という現在地を、数値とAPIで整理する。

📅 2026年8月14日 ⏱ 約3分 🔗 出典 4 件

Flutterの現行安定版は3.44.7／Dart 3.12（docsは2026-08-04更新）。次の機能リリースは2026年8月のリリース窓に入り、2026ロードマップは最低4回のstableをコミットしている。この回の主役は描画基盤の刷新だ。

何が新しいか。ImpellerがAndroid既定になりSkiaが撤去された（Android=Vulkan／iOS=Metal、API 29+）。最大の効果はAOT（ビルド時）シェーダー事前コンパイルによるshader compilation jankの排除で、複雑シーンではframe rasterizationを約50%短縮、アニメ重ワークロードではSkia比約17%低いバッテリー消費を報告する。描画品質も、円のレンダリングがsigned-distance function（SDF）ベースに刷新されエイリアシングが解消し、perspective matrixの補正で影と遠近投影が正確になった。あわせてMaterial／Cupertinoがコアから material_ui／cupertino_ui へ切り出され（独立バージョニングでM3更新がSDKを待たず届きapp size削減）、iOS/macOSはSwift Package Managerが新規既定になった。

アーキテクチャの現在地。2026の三強はRiverpod 3.0（compile-time safety）／Bloc 9.0（enterprise event tracing）／GetX（退潮）。新規プロジェクトの既定はRiverpod 3.3.1＋codegen（@riverpod・Notifier/AsyncNotifier・riverpod_lint）で、compile-time safety・context-free reads・first-class asyncを最小ボイラープレートで得られる。Riverpod 3はunified Ref・Mutations（experimental）・自動リトライ/backoff・experimental offline persistenceを備え、リビルド最適化は ref.watch(provider.select(...)) で最小スライスを購読する。監査/規制業界（fintech/healthcare）や複雑並行はBloc 9.1（on<Event>統一・event-driven audit trail・blocTest）を選ぶ。土台はfeature-firstのClean Architecture＋go_router。

パフォーマンスと移行の注意点。計測は必ずprofileモードでDevTools Performanceからtimeline traceを取り、frame rasterizationを4ms未満に。日々の最適化はconst徹底・大きなbuild()分割・selectで局所再描画・アニメ領域をRepaintBoundaryで隔離。移行前はflutter upgradeとImpellerの実機検証（差の切り分けは--no-enable-impeller）、dart fix/format＋flutter analyzeで警告を解消しておく。

ひとことまとめ：3.44系はImpeller既定化でjank排除と描画品質を底上げした回。新規はRiverpod 3、統制が要る領域はBloc 9という選び分けが2026の基本線だ。
