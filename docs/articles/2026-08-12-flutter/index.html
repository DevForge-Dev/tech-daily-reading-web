Dart 3.12 のコンストラクタ革命と material_ui 分離 — 定型削減とUIの独立配信

現行は Flutter 3.44 / Dart 3.12。primary constructors・private named parameters・dot shorthands で ViewModel/値クラスが激減。Material/Cupertino はコアから切り出され、M3更新が四半期SDKを待たず届く。

📅 2026年8月12日 ⏱ 約3分 🔗 出典 4 件

現行安定版は Flutter 3.44 / Dart 3.12（3.44.0 は 2026-05-18・Google I/O 2026 公開）で、次の機能リリース窓（年4回 2/5/8/11月）に入った。今日の主役はDart 3.12 のコンストラクタ定型削減と、Material/Cupertino のパッケージ分離という2つの構造変化だ。どちらも「毎回書いていた退屈なコードとビルド重量」を削る方向で、ViewModel やデータクラスを多用する実装ほど効く。

Dart 3.12 はコンストラクタの定型を3方向から減らす。primary constructors（experimental・opt-in）はクラスヘッダで instance 変数を直接宣言でき、ViewModel/値クラスを大幅短縮。private named parameters（既定 ON）は先頭 _ で公開名を自動決定し「this._x を _x に代入」の重複を消す。dot shorthands（3.10 導入・3.12 で成熟し既定 ON）は型が自明なら .value と書ける。

もう一方の構造変化がUIパッケージの分離。Material と Cupertino はコアから material_ui／cupertino_ui へ切り出され、3.44 では material.dart／cupertino.dart は「凍結」でコアに新機能追加なし。独立バージョニングで M3 更新が四半期 SDK を待たず届き、未使用 UI は binary から外れてアプリサイズ削減につながる。描画は Impeller が Android 既定・Skia 撤去（Vulkan／iOS=Metal）、iOS/macOS は Swift Package Manager が新規プロジェクトの既定（CocoaPods 段階的廃止）へ。状態管理の基本線は変わらず新規は Riverpod 3.3.1＋codegen、監査/大規模は Bloc 9.0（on<Event> ハンドラ・event-driven audit trail）。

自分が試すなら、まず既存プロジェクトを 3.44 に上げ、ViewModel の多いレイヤで primary constructors（experimental フラグ）と dot shorthands を局所導入して差分を測る。注意点は、primary constructors は experimental で opt-in が要ること、UIパッケージ分離に伴う SDK 内コピーは長い deprecation 期間に入るので移行を焦らないこと、SPM 既定化で既存 CocoaPods 依存プラグインの対応確認が要ること。まとめ：3.12/3.44 は「書く量とビルド重量を減らし、UI を独立配信する」整理の回。まずは値クラス短縮と Widget Previewer のメモリ改善という実益から触るのが良い。
