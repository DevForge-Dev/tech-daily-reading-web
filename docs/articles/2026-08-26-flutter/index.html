Flutter 3.47 — Impellerがデスクトップ3OSで既定、Riverpod 3.0のMutations、フレーム予算8–11ms時代

現行はFlutter 3.47.0（Dart 3.13同梱）。ImpellerがmacOS/Windows/Linuxで既定レンダラに昇格し、material_ui/cupertino_ui 1.0がコアから分離。状態管理はRiverpod 3.0のMutationsが非同期アクションのlifecycleをUIに自動公開。90/120Hz時代のフレーム予算は8–11ms。

📅 2026年8月26日 ⏱ 約3分 🔗 出典 4 件

今日の主役は現行の Flutter 3.47.0 stable（2026-08-12、Dart 3.13 同梱）。最大の変化は Impeller がデスクトップ3OS（macOS/Windows/Linux）で既定レンダラに昇格したこと。Impeller は shader を AOT（ビルド時）でコンパイルし Metal(iOS)/Vulkan(Android/デスクトップ) をネイティブ利用するため、従来の shader compilation jank を実質ゼロにし、複雑シーンで平均 raster 時間を約50%短縮する。あわせて Widget Previews が stable 昇格（ローカルビルドキャッシュで高速起動・リアルタイム検索）。次は2026年11月の機能リリースへ向け Impeller 2.0・WasmGC 既定化が進む。

ライブラリ分離とアニメの黄金律

material_ui / cupertino_ui 1.0 が Material/Cupertino をコアSDKから分離し pub.dev から週次更新に。移行は dart fix --apply --code=migrate_design_widgets でimportを自動置換でき、未使用UIをバイナリから外してapp size削減につながる（旧importは2026年秋にdeprecated予定）。アニメの黄金律は「まず implicit」——toggle・focus変化・card liftは AnimatedContainer/AnimatedOpacity/AnimatedSwitcher で AnimationController 不要・自動補間（150–500ms・easeInOut/fastOutSlowIn）。loop/physics/gestureや複雑choreographyだけ explicit にし dispose 必須、重い演出は Rive の state machine に逃がす。

状態管理は Riverpod 3.0 の Mutations

2026の選定図は、新規は Riverpod 3.0（compile-time safety＋最小boilerplate、テストはBloc比30–40%行数減）、性能特化は Signals 6.0、監査/規制は Bloc 9.0。目玉の Mutations は「Login」「Post Comment」のような非同期アクションを定義すると、その lifecycle（Idle/Pending/Success/Error）を UI へ自動公開し、ボタンのloading/success/error表示の手書き配線が要らなくなる。さらに provider は network 失敗時に指数バックオフの automatic retry で一時的なグリッチを吸収し、永続エラー画面を回避する。ref.watch(provider.select(...)) で最小スライス購読するのも定石だ。

自分が試すなら・注意点

まずデスクトップ実機で Impeller 既定下の raster を DevTools で計測し、const/RepaintBoundary/build()分割で不要rebuildを潰す。新規は Riverpod 3.0＋Mutationsでフォーム系の配線を減らす。注意は計測を必ず profile モードで行うこと（debug VMは遅い）と、UI分離の移行は dart fix 後にビルドサイズと import 欠落を確認すること。

ひとこと
