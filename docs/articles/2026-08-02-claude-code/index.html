Claude Code

Opus 4.1 が8/5廃止・Opus 5 へ移行 — 同時に効く『ハーネス設計』、30人チームで22スキル11フックが生産性+35%を4か月維持

Opus 4.1(claude-opus-4-1-20250805)は8/5にAPI廃止、移行先はOpus 5(1Mコンテキスト・新xhigh推論・$5/$25でOpus 4.8据え置き)。モデル選定より効くのは「ルール=Hooks/権限・知識=Skills・委譲=Subagents・指針=短いCLAUDE.md」のハーネス設計。実例では22スキル11フックで生産性+35%を4か月維持。

📅 2026年8月2日 ⏱ 約4分 🔗 出典 5 件

週末のClaude Code周りは「モデルの世代交代」と「使いこなしの型」が同時に動いた。8月5日には旧モデルがAPIから消え、後継のOpus 5が主力に座る。だが実務の成果を左右するのはモデルの賢さより、Hooks・Skills・Subagentsをどう配線するかという“ハーネス設計”のほうだ——という論調が今日の技術記事・ケーススタディで揃った。

何が新しいか：まず期限もの。Claude Opus 4.1（claude-opus-4-1-20250805）は6月5日にdeprecate、8月5日にAPIから完全retireされる。deprecateからretireまでちょうど60日という短さで、以降は当該モデルIDへの呼び出しが失敗する。既定モデルを使う一般利用は影響が小さいが、モデルをピン留めした自動化・CI・ルーターは廃止前に切り替えが要る。移行先は7月24日公開のOpus 5（claude-opus-5）で、1Mトークンのコンテキストと、より深い思考へ振る新しい「xhigh」推論モードを備えつつ価格は100万トークンあたり入力$5／出力$25とOpus 4.8に据え置き。最上位フロンティアはFable 5のままで、Opus 5は“実務主力（ワークホース）”枠を置き換える。あわせてClaude for Open Sourceが7月8日に拡大し、対象メンテナ／主要コントリビュータにMax 20x（月$200相当）を6か月無償提供（依存数・DL数・OpenSSF criticality等の5トラック、個人限定・自動有料継続なし）。

本題＝ハーネス設計：SmartScope・AIXplore・Totalumの上級ガイドが口を揃えるのは、プロンプトを磨くより「記憶ファイル・権限・スキル群・少数の強制フック」からなるハーネスを整えたチームが最大の成果を出すという点。役割分担はシンプルで、強制すべきルールはHooks／権限（ライフサイクルイベントで決定論的に発火し、モデルの解釈に依存せずシステムレベルで固定できる）、文脈知識はSkills（SKILL.md＋補助資産のフォルダ単位で、必要時だけオンデマンド読込＝コンテキストを常時圧迫しない）、委譲境界はSubagents（独自コンテキストで並列にタスクを切り出す）、常時参照する短い指針はCLAUDE.md。

実例の数字：Digital Appliedの30人チーム合成ケースは、90日で22の共有スキル・11のフック・3つのサブエージェントを整備し、エンゲージメント加重の生産性指標で+35%を4か月目まで維持。導入監査は19→41点（50点満点）へ改善した。鍵は3点——スキルライブラリが最大ROI、CLAUDE.mdを400行未満に保つ規律、そして毎週金曜30分のレトロで摩擦を週内に拾い“継続フェーズ”をスプリントと同じカレンダーに載せること。市場観測（Uncover Alpha／利用統計）でも、開発チームの73%がAIコーディングツールを日常利用し、常用者の71%がClaude Codeを主力に、46%が“最も愛される”と回答している。

自分が試すなら：①8/5前に、自分の自動化・定期タスク・CIでモデルIDをピン留めしていないかを洗い出し、していればOpus 5へ差し替えて動作確認。②ハーネスはスキルから着手（最大ROI）——普段の作法をSKILL.md化して数個入れる。③CLAUDE.mdは400行未満を死守し、肥大したら知識をSkillsへ逃がす。④暴走対策や規約はHooks／権限で固定する。注意点：deprecate通知に気づかず8/5に呼び出しが落ちる事故が一番怖い。プロンプト調整に時間を溶かすより、ハーネスの土台を先に作るほうが効く。ひとことまとめ：8月はモデルを乗り換える月であり、同時に“どう配線して安く賢く回すか”を仕込む月だ。
