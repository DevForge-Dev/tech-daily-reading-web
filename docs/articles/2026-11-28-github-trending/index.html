lsernau/grh-lean（Lean・⭐約1,041）

解決したい課題：発表されたばかりの数学的主張は、人手では真偽の検証・追試が難しく時間がかかる。提供する機能：一般化リーマン予想（GRH）の『短い証明』を Lean 4 で形式化したと主張するリポジトリで、形式化された証明そのものを公開し、第三者が追試・検証できる土台を置く。なぜ今急上昇：created 2026-11-25＝作成約3日で⭐約1,041（日平均約347★＝本日最速級、forks117 は検証/追試の動き）。GTA6 系グレーが上位の中で、純・話題枠かつ希少な Lean の言語多様性として殺到した。Apache-2.0。ただし『短い証明』は追試で覆る可能性が高く、内容の正しさは未検証——ここでは真偽を判断せず、話題化している事実のみを扱う。

gary23w/f-ck_data_brokers（Python・⭐約620）

解決したい課題：個人情報を売買するデータブローカーは多数あり、各社へ手作業でオプトアウト／削除依頼を出し続けるのは現実的でない。提供する機能：各社へ本人に代わってオプトアウト／削除リクエストを自動送信する、CLI 兼 MCP サーバーの Python スクリプト。CCPA/GDPR/LGPD/PIPEDA 対応で、MCP 同梱によりエージェントからも叩ける。なぜ今急上昇：created 2026-11-26＝作成約2日で⭐約620（日平均約310★、forks38）。プライバシー実務の“痒い所”が刺さり急伸した。チャットAI／ゲーム系に偏る本日に、非AI・消費者プライバシーという毛色の違う多様性枠。MIT。

linjiejim/ohmwork（TypeScript・⭐約518）

解決したい課題：電子回路は、数式や静的な図だけでは直感に落ちにくく、“触って動かして”学べる教材が少ない。提供する機能：実際にツマミやスイッチを手で弄りながらシミュレーションで学べる、インタラクティブな電子回路学習サイト（React/MDX 製）。なぜ今急上昇：created 2026-11-24＝作成約4日で⭐約518（日平均約130★、forks36）。“触って動く教材”の面白さが刺さり、エンジニアリング教育×可視化という本日唯一のエドテック/電子工学多様性枠として伸びた。MIT。

まとめ：自分が試すなら

いちばん手を出しやすいのは ohmwork——触って動く UI 教材として、インタラクティブ学習サイトの作り（React/MDX＋シミュレーション）を読む題材になる。f-ck_data_brokers は MCP サーバー同梱が実務的で、“エージェントから叩けるプライバシー自動化”という構成の参照になる。grh-lean は内容の真偽を保証しないが、形式検証（Lean 4）が数学クラスタを一気に巻き込む様子を観測する価値がある。3本に通底するのは「身近な不便を、手元のツールで潰す」という手触りだ。
