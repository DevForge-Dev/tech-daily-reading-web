本日の github.com/trending 上位は GTA6/Xbox 系の recompilation・エミュレータや star-farm 群で埋まっていたため、それらグレー枠を除いた「純・話題枠」を Search API で拾い直した3本。共通点は明快で、どれも“一点特化”で急伸した新星だ——Rust・HTML・CUDA と言語もジャンルもバラけ、AIコーディング時代の“後始末”や“擬似3D”“GPU特化推論”に一芸で刺さっている。

deterministic-machines/deslop-please（Rust・⭐約1,055）

解決したい課題：Claude Code / Codex でAIに書かせると、やたら長く・過剰に抽象化された“slop（贅肉）”コードが積み上がる、という実感。提供する機能：その冗長・過剰抽象を削ぎ落とし、読みやすく保守できるコードへ戻す Rust 製 CLI。既存コードベースに後付けできる。作成約4日で⭐約1,055（日平均約264★＝本日のクリーン新星で最速級）、MIT。“deslop”という明快なキャッチが時代の実感に真正面から刺さった。

danielwh2/sprite-stacking（HTML・⭐約903）

解決したい課題：ドット絵だけで“くるくる回せる擬似3D”を作りたいが、昔のアーケード的な「スプライトを層状に積む」技法は手作業がつらい。提供する機能：4方向のピクセルアートから fake-3D/voxel モデルを生成するエージェントスキル。Claude Code/Codex/Cursor/OpenCode/Gemini CLI/Pi で呼べる。古い技法を現代のコーディングエージェント用スキルに落とした新規性で急伸。作成約6日で日平均約151★、MIT。

tensorfish/squid5090（CUDA・⭐約252）

解決したい課題：汎用推論ランタイムは「どのモデル×どのGPUでもそこそこ」で、特定構成の限界性能を引き出せない。提供する機能：小型モデル「Inkling Mini 2」を NVIDIA RTX 5090 上で動かすために手書き最適化した CUDA 推論エンジン。「1モデル×1GPU」に張り付く割り切りが、汎用に飽きた層へ刺さった。本日唯一の CUDA/GPU 枠。作成約3日で日平均約84★、ただしライセンス未記載＝利用時は要確認。
