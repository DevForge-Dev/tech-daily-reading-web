Flutter 3.47.1が現行、Widget Previewsがstableに・Impellerのprecompiled shadersで初回jank解消 — Riverpod 3のoffline persistenceとDart 3.13 primary constructorsも

派手な新ウィジェットより開発ループと描画の底上げが主役。Widget Previewsがstable昇格で全体ビルド不要の個別UI検証、Impellerのprecompiled shadersが初回jankを消し90–120fpsで安定・重いシーンのrasterをSkia比約50%短縮。状態管理はRiverpod 3のoffline persistence＋Mutations、言語はDart 3.13のprimary constructorsが正式化。

📅 2026年8月31日 ⏱ 約4分 🔗 出典 5 件

Flutter は 2026-08-19 リリースの 3.47.1 パッチ（Dart 3.13.1 同梱）が現行で、機能セットは 3.47（2026-08-12）を継承しつつ安定性・バグ修正を積み増した堅実な更新だ。派手な新ウィジェットより、日々の開発ループとレンダリングの底上げが今日の主役になっている。とくに開発体験（Widget Previews の stable 昇格）と描画（Impeller の precompiled shaders）の二本柱は、そのまま「書く速さ」と「動く滑らかさ」に直結する。

何が新しいか

Widget Previews が stable に昇格した。アプリ全体をビルド／起動せずに個別 UI を即 render・inspect でき、ローカルビルドキャッシュで起動が速く、プレビューのリアルタイム検索／フィルタも付いた。コンポーネント単位で見た目を詰める作業のフィードバックループが一段短くなる。描画側では Impeller の precompiled shaders がファーストラン jank（初回のシェーダーコンパイル由来のカクつき）を排除し、複雑 UI を 90–120fps に安定、重いシーンでは平均 raster を Skia 比で約50%短縮する。Impeller は 2025 に iOS/Android 双方で既定化済みで、3.29–3.35 の一連の最適化（テキスト描画高速化・効率的 blur・GPU 対応拡大）と合わせ、複雑アニメの jank frame を 30–50% 削減している。

仕組みと使いどころ

状態管理は新規なら Riverpod 3.3.1＋codegen が既定で、compile-time safety・unified Ref・最小 boilerplate に加え、experimental の built-in offline persistence（opt-in）がキャッシュを復元し stale-while-revalidate でオフライン対応する。Mutations（experimental）は Login や Post Comment のような副作用の lifecycle（Idle/Pending/Success/Error）を UI へ自動公開し、失敗時は automatic retry/backoff で transient エラーを吸収する。テストは provider override でツリーを起動せずに書けるため、Bloc 比で 30–40% 行数が減るという。ただし監査証跡が要る規制業界（fintech/healthcare）や複雑並行は引き続き Bloc 9.0 が向き、on<Event> で全 state 変化を event に対応づけ blocTest で検証できる。購読は ref.watch(provider.select(...)) で最小スライスに絞るのが定石だ。言語面では Dart 3.13 の primary constructors が正式化され、クラスヘッダで constructor と instance 変数をまとめて宣言できる。使うには language version を ^3.13.0 に上げる。

自分が試すなら・注意点

まず flutter upgrade で 3.47.1／Dart 3.13.1 に合わせ、flutter --version で確認する。UI 調整は Widget Previews を常用してコンポーネント単位で回し、パフォーマンス計測は必ず profile モードで行う（debug の VM は遅く数値が当てにならない）。最も多いボトルネックは不要な widget rebuild なので、const で再ビルドを完全スキップし、大きな build() を分割し、Selector/select で局所再描画に寄せる。フレーム予算は 60fps=16ms / 90fps=11ms / 120fps=8.3ms を基準に、90/120Hz 端末では 1 フレーム 8–11ms を死守する。注意点は offline persistence と Mutations がまだ experimental であること、そして precompiled shaders の恩恵は Impeller 前提なので旧 Skia 経路を残している場合は移行を確認しておくことだ。

ひとこと

新機能の華やかさより、書く・見る・動かすの各段が一段ずつ速く・滑らかになった日。地味だが、複雑 UI を 120fps で回すための土台と、コンポーネント単位で詰める開発ループが噛み合ってきている。
