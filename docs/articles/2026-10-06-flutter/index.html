Flutter 2026-10-06 — 明日開幕Next.App DevCon、3.50で“Finishing the Job”: WasmGC既定化・Impeller一本化

DevCon直前。既定化される技術(WasmGC/package:web・Impeller)への追従準備と、アニメ/DI/描画の地固め。

📅 2026年10月6日 ⏱ 約4分 🔗 出典 6 件

主役は明日。10/7からFlutterConとDroidconが合流した新カンファレンスNext.App DevCon 2026(10/7–9)が開幕する。ロードマップ『Finishing the Job』の締めくくりと、3.50(2026年11月)の確定情報、基調講演が主役になる見込みだ。現行安定版はFlutter 3.47.5 / Dart 3.13.4、betaは3.49系/Dart 3.14で、リリースは年4回(3.41/3.44/3.47/3.50)。

何が“締め”なのか。3.50の目玉は3本柱。WebのWasmGC既定化(flutter build web --wasm、dart:html→package:web移行)、AndroidのImpeller一本化(legacy Skiaバックエンド撤去・API29+)、そしてMaterial/Cupertinoの分離(material_ui / cupertino_ui 1.0、移行はdart fix --apply --code=migrate_design_widgets——--code無しは無変更の罠)。AIの意図に動的追従する適応型UIを実現するGenUI SDK×A2UI(Agent-to-UI)プロトコルもDevConのAIネイティブ開発トラックの中核になる。

土台も固める。アニメーションは、AnimatedContainerなどのimplicit系が第一選択——プロパティを変えてsetStateするだけでduration/curveに沿って自動補間し、AnimationControllerの生成・disposeが要らない。独自プロパティはTweenAnimationBuilderでcontroller無しに、子の差し替え演出はAnimatedSwitcher(Keyで検知)で。選び方は次の通り。

アーキとパフォーマンス。DIはget_it(サービスロケータ)＋injectable(@singleton等＋codegen)でRepository/Service/Dioを一元管理し状態層へ注入する。Riverpod 3自体がDIコンテナにもなるので併用が実務的——純粋サービスはget_it、UI/状態に紐づく依存はRiverpod provider。新規はRiverpod 3既定、監査要件・大規模・イベント駆動はBloc 9.2、細粒度はsignals。描画負荷はRepaintBoundaryで再描画領域を別レイヤに隔離し、計測は必ずprofileモードでDevToolsのUI(Dart)とRaster(GPU)を分離する(赤がUI側ならbuild()、Raster側ならsaveLayer/Opacity/BackdropFilterを疑う)。フレーム予算は60=16.6 / 90=11.1 / 120=8.33ms。

落とし穴。macrosは無期限ポーズが継続——コード生成は従来どおりbuild_runner＋source_genで行う。

ひとこと。DevConは“仕上げ”の節目。新機能を追う前に、既定化されるWasmGC/package:web・Impeller前提への追従準備を進めておきたい。
