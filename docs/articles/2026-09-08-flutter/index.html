Dart 3.13 で型安全 lint を標準化、Widget Previews 安定版 — 60→120fps はラスタ予算で詰める

現行安定版は Flutter 3.47.1 / Dart 3.13.1。no_raw_types・no_dynamic_casts で型を締め、Widget Previews が stable に。性能は raster スレッドを 60fps=16／90=11／120=8.3ms に収めるのが軸。

📅 2026年9月8日 ⏱ 約3分 🔗 出典 4 件

2026-08-12 の Flutter 3.47 / Dart 3.13 を軸に、型安全・プレビュー・性能の3点を整理する。年4回（2/5/8/11月）サイクルなので次の機能リリースは 2026 年11月。今の安定版は flutter --version で Flutter 3.47.1 / Dart 3.13.1。

何が新しいか

Dart 3.13 は新 lint no_raw_types（raw 型の使用を禁止）と no_dynamic_casts（暗黙の dynamic キャストを禁止）で型チェックを一貫化。primary constructors が stable 化し、クラスヘッダで constructor と instance 変数を1行宣言でき boilerplate を大幅削減（language: ^3.13.0）。3.47 では Widget Previews が stable に昇格し、ローカルビルドキャッシュで起動が高速化、プレビューのリアルタイム検索/フィルタに対応。editor 連携用の LSP メソッド（getFlutterWidgetPreviews ほか）も追加された。

設計と性能の勘所

状態管理の既定線は「新規は Riverpod 3.0（3.3.x）、監査証跡が要る規制業界・複雑並行は Bloc（9.2.x）」。Riverpod 3 は stale-while-revalidate のオフライン永続化、失敗 provider の指数バックオフ自動リトライ、書き込み中間状態を扱う Mutations API、unified Ref が要点。土台に Clean Architecture × Feature-First × go_router を据え、移行は repository を先に切り出して feature 単位で。性能の最頻出問題は不要な widget rebuild——不変なら const、build() を分割、select/Selector で局所購読、アニメ領域を RepaintBoundary で隔離、重い計算は Isolate.run() へ。

アニメーションと落とし穴

階層は implicit（micro 50–200ms）→ explicit（AnimationController＋AnimatedBuilder、200–400ms）→ Hero（300–600ms）。jank の典型は「純粋な描画変換のつもりが layout pass を誘発」——動きは Transform、フェードは Opacity に閉じてレイアウトを触らない。explicit は controller の dispose 必須。計測は必ず profile モード（debug は JIT/assert で歪む）。Impeller は全 shader を build 時に AOT precompile し compilation jank を排除する。

ひとことまとめ

3.13/3.47 は「型で締め、プレビューで速く回し、ラスタ予算で詰める」DX＋性能の底上げ。まずは no_dynamic_casts を有効化して既存コードの暗黙キャストを洗い出すのが着手点。
