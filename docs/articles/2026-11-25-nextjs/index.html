読書進捗バー＋スクロールスパイ目次 — 純CSS scroll() と IntersectionObserver の正しい組み方

進捗バーは JS ゼロのコンポジタ駆動へ、スパイは IO の“取りこぼし”を Set で潰す。App Router の RSC 境界まで一気に整理。

📅 2026年11月25日 ⏱ 約4分 🔗 出典 4 件

技術記事サイトを Next.js(App Router / MDX)で作ると、ほぼ必ず要求されるのが2点セット——ページ上端の読書進捗バーと、読み進みに合わせて現在地が光るスクロールスパイ(Scrollspy)目次。2024〜2026年のトレンドは明確に「JS を減らす」方向で、進捗バーは CSS Scroll-driven Animations でJavaScript ゼロ・コンポジタ駆動にできるようになった。ただしスパイの方はまだ純CSS化が未成熟で、現行ブラウザで確実に動かすなら IntersectionObserver(IO)併用が実務解。この“ちょうど良い”構成を、落とし穴込みで押さえる。

何が新しいか — 進捗バーは純CSS scroll()

やることは transform: scaleX(0)→scaleX(1) の @keyframes を、無名スクロールタイムライン animation-timeline: scroll() で駆動するだけ。scroll() は引数なしで「直近のブロック軸スクローラ＝通常はルート」を追跡する。アニメするのは transform だけなのでコンポジタで動き、メインスレッドを使わず軽い。最大の落とし穴は、animation ショートハンドが animation-timeline を auto にリセットすること。必ず animation-timeline はショートハンドの後に書く。

対応は Chromium 系と Firefox(near-current)まで。全ブラウザではないので @supports (animation-timeline: scroll()) で機能検出し、装飾目的なら「非対応は何もしない」プログレッシブ・エンハンスメントで十分。公式は polyfill を非推奨としている。実データ連動が要るなら、非対応時だけ scroll イベントで scaleX を更新する軽いフォールバックを足す。

仕組み — スパイは「中央線」と Set

現在地判定のキモは IO の rootMargin: '-50% 0px -50% 0px'。上下を50%削ると判定帯がビューポート中央の1本線になり、「その線を跨いでいる節＝現在地」で1つに絞れる。固定ヘッダがあれば上側だけオフセットする（例 -80px 0px -50% 0px）。

典型バグ：IO コールバックの entries には「前回から交差状態が変化した要素だけ」が来る。これを findIndex(e => e.isIntersecting) で選ぶと、上スクロール時に取りこぼす。堅牢なのは交差中の要素を Set で保持し、毎回 DOM 順で先頭を現在地に採るパターン。

App Router での組み込み

目次のマークアップ生成はサーバー側(RSC/MDX)で行い、現在地検出だけを小さな 'use client' アイランドに閉じ込めるのが定石。本文（長文）は Server Component のまま＝JS を増やさない。手順は、(1) rehype-slug 等で見出しに id を付与し ToC をサーバーで生成、(2) 進捗バーは globals.css だけ（'use client' 不要）、(3) スパイは IntersectionObserver／window を使うので Client Component 必須、SSR 時は現在地を計算せず useEffect 内でのみ observe（ハイドレーション mismatch 回避）、(4) 固定ヘッダ下に見出しが隠れないよう scroll-margin-top を当てる。スパイは純クライアント挙動なので ISR / revalidate / use cache とは無干渉。

注意点・アクセシビリティ

進捗バーの @keyframes 適用は @media (prefers-reduced-motion: no-preference) で囲い、削減時は非アニメに。ハイライトは色だけに頼らない（font-weight / 下線 / インジケーター併用）。将来の純CSSスパイ（scroll-target-group / :target-current）は支援技術に露出しないため、使うなら aria-current の併用が必須。当面は IO 併用が無難。

ひとことまとめ

進捗バー＝純CSS scroll()（順序に注意）、スパイ＝IO の中央線＋Set、マークアップはサーバー・検出だけクライアント。この3点で、JS を増やさず堅い「進捗＋目次」が組める。
