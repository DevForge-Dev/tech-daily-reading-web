9/30の急上昇は「AI×自動化の実用」から「遊び」「デスクトップ常駐」まで幅があった。共通するのは、いずれもAIエージェントを“人の操作の肩代わり”に寄せている点だ。増加率（当日増÷総スター）で見た本日の筆頭3本を、解決したい課題と提供する機能で読み解く。

feder-cr/dots（Python・⭐約1.9k）

解決したい課題：既存のbrowser-use系AIエージェントは、ログインや購入の自動化でbot検知の壁に突き当たる。提供する機能：反検知の“見えない”ブラウザを丸ごと内蔵し、ブロックされずに実際の人間の操作（ログイン・購入など）を代行する自律エージェント。Auto_Jobs_Applierで知られるfeder-crの新作で、公開約1日で約1.9k・fork約320と本日の新規リポジトリでは実測最速級。AI×ブラウザ自動化のモメンタム筆頭（MIT）。

rehan-remade/universal-modder（Python・⭐約780）

解決したい課題：PCゲームのMOD制作はツールチェーンが複雑で参入障壁が高い。提供する機能：「Claudeをゲームに向けるだけ」で所有するほぼ全てのPCゲームをMODできるClaude Code用スキル群＋fal MCP。テクスチャ生成やアセット差し替えを会話で行える。公開当日で約780・fork約53。生成AI一色の上位群に“ゲーム応用”という毛色の違いで新規性・多様性を足した純モメンタム枠（MIT）。

Louis-CFM/coucou（Swift・⭐約1.2k）

解決したい課題：AIアシスタントは基本“こちらから呼びに行く”もので、作業中にそっと気づきをくれる常駐体験が乏しい。提供する機能：macOSのノッチ（Windowsは画面上部）に住む小さな相棒。画面を見張り、Claude連携でリマインドや気づきを差し込む常駐コンパニオン。Dynamic Island風UIの可愛さと手軽さで拡散し、公開約3日で約1.2k・fork約154。Swift/macOSネイティブという異色の消費者向け枠（MIT）。

まとめ

自分が試すなら実務直結はdots——調査タスクのログイン壁を越える反検知ブラウザは、毎朝の自動調査が踏む“ログインできず詰まる”弱点を補える可能性がある。coucouは常駐UIの作法の参考に、universal-modderはエージェントに創作を丸投げする設計の遊びとして眺めておきたい。この日はDevForge適合枠（hypoarena・openai/mcp-extensions・dioramas）も動いており、根拠グラフやMCP拡張、AI生成3D LPは別途要チェックだ。
