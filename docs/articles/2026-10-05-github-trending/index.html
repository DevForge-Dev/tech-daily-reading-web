10/5のトレンドは「エージェント・スキル経済」一色(ponytail/agent-skills/claude-mem 等の新顔が上位)。その中から、方向性の異なる3本を選んだ——“エージェントに逆解析させる”rea、bash出力を圧縮してトークンを削るrtk、Claude Codeを23人の仮想チームに変えるgstack。共通するのは「エージェントの作業を、現場の実務(解析・コスト・運用規律)に落とす」視点だ。

morluto/rea（TypeScript・⭐約0.4k）

解決したい課題：ソフトの挙動解析・計測・リバースエンジニアリングは、ツールが散在していてエージェントから一貫して扱いにくい。提供する機能：アプリ挙動からネイティブバイナリのレベルまでを一つの流儀で解析・計測・ブラウザ観測・プロセスキャプチャする統一CLI＋MCPサーバ。MCP対応なので既存エージェント(Claude Code等)から呼べる。スキル経済一色の中で“エージェントに逆解析させる”希少ジャンルとして、Trendshift日次1位で話題化した。

rtk-ai/rtk（Rust・⭐要検証／本日+約323）

解決したい課題：git statusやcargo testなど開発コマンドの冗長な出力をそのままLLMに渡すと、入力トークンを恒常的に浪費する。提供する機能：bash出力をLLMへ渡す前に圧縮するCLIプロキシ。スマートフィルタ／グルーピング／トランケート／重複集約の4手法で、よくある開発コマンドの出力トークンを60〜90%削減する(※bill全体ではなくbash出力部分)。依存ゼロ・Rust製・Apache-2.0で、CLAUDE.mdや定期タスク運用に無改造で差し込める点が“コスト削減系”として評価された。

garrytan/gstack（TypeScript・⭐未確定／本日+約125）

解決したい課題：1人開発や小規模では、セキュリティ監査・QA・リリース後監視といった役割が抜けやすい。提供する機能：Claude Codeを23の専門ロール(CEO/デザイナ/EM/QAリード等)の仮想エンジニアチームに変えるスキル集。/csoがOWASP＋STRIDEで監査、/test-auditが高コスト・冗長テストを特定、/qa・/review・/ship・/canaryが実装〜PR作成〜デプロイ後監視まで自動化する。9ハーネス対応・MIT。

自分が試すなら。効果が即・定量に出るrtk(トークン削減)が入口。reaは逆解析という希少ジャンルの観察用、gstackは“運用規律のテンプレ”として参照価値が高い。
