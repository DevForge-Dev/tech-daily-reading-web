Claude Code

起動高速化＋バイナリ340MB→75MB圧縮、モデル切替フックPreModelSwitch/PostModelSwitch新設（v2.1.251）——足回りと事業の両輪が加速

新モデルではなく「速さ・軽さ・制御性」を固める一日。サンドボックス/MCPの起動が初回描画をブロックしなくなり、Linux x64バイナリは約340MB→約75MBへ圧縮。v2.1.251でモデル切替の前後に発火するPreModelSwitch/PostModelSwitchが追加され、SessionStart resumeは陳腐化と再キャッシュ推定コストを受け取れる。事業面ではAnthropicがQ2 2026に初の営業黒字（売上109億ドル・営業利益5.59億ドル）。

📅 2026年9月2日 ⏱ 約3分 🔗 出典 7 件

今日のClaude Codeは新モデル投入ではなく、日常の立ち上げ体験と運用制御性を底上げする更新が中心だった。まず体感速度：サンドボックスとMCPの起動が最初のフレーム描画をブロックしなくなり、コマンド直後から画面が出る。あわせて配布サイズも改善し、Linux x64のネイティブバイナリが約340MB→約75MBへ圧縮された。ダウンロードや自動更新の負荷が軽くなる地味だが効く変更だ。

何が新しいか

制御面の目玉はv2.1.251で追加されたモデル切替フックだ。切替の前後で発火するPreModelSwitch/PostModelSwitchにより、モデル変更をブロック・確認・注記できる。さらにSessionStartのresumeフックが、再開しようとするセッションの陳腐化状況と再キャッシュに要する推定コストを受け取れるようになった。長時間・複数セッション運用で「無駄な再開」を避ける判断材料になる。信頼性修正もまとまり、自動更新後のChrome接続断・VSCodeの権限モード不起動・壊れたPRステータスキャッシュによる起動クラッシュなどが解消された。

使い分けの判断軸

今日は運用ノウハウも整理された。要点は一言で「Skillはhow（手順）を教え、Hookはルールを強制し、Subagentは作業を隔離する」。必ず守らせたい規則はHookや権限で、文脈的な知識はSkillで、委譲の境界はSubagentで、常時のプロジェクト指針はCLAUDE.mdに短く——という対応づけだ。サブエージェントは仕様が更新され、ネスト最大3階層・同時実行はデフォルト20体だが、実務では3〜5体にまとめるのが目安（多数起動は調整オーバーヘッドとトークン増を招く）。副次タスクはクリーンな文脈で走らせ要約だけ返させるのが本番運用の型。

事業サイド・自分が試すなら

事業面ではAnthropicがQ2 2026に四半期売上109億ドル（前四半期比127%増）・営業利益5.59億ドルで初の営業黒字。Claude Codeの年換算売上は5億ドル（25/9）→25億ドル（26/2）→約80億ドル（26/5）と拡大し、売上の過半をエンタープライズが占める。日本でも楽天が新機能導入を80%短縮、みずほFGは約3万人が業務活用という事例が出ている。自分の多PJ運用なら、まずPreModelSwitchで高コストモデルへの切替時に確認を挟み、resumeの再キャッシュ推定コストを見て「本当に再開すべきセッション」だけ復帰させる運用を試したい。

注意点・ひとこと

フックは強力だが増やしすぎると発火の見通しが悪くなる。公式推奨どおりまずCLAUDE.mdを整え、譲れない部分だけHookを足すのが安全。派手さはないが、速さ・軽さ・制御性がまとめて前進した実用的な一日だった。
