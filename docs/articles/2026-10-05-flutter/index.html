Flutter 2026-10-05 — DevCon直前、3.50へ向け2026安定ラインが固まる

FlutterCon×Droidcon合流の新カンファが2日後開幕。WasmGC既定化・Impeller一本化の総仕上げと、状態管理3択(Riverpod3/Bloc/signals)の指針が見えてきた。

📅 2026年10月5日 ⏱ 約3分 🔗 出典 4 件

現行安定版は Flutter 3.47.5 / Dart 3.13.4、次の安定機能リリースは11月の 3.50。そして明後日(10/7-9)、FlutterConとDroidconが合流した新カンファ Next.App DevCon 2026 が開幕する。ロードマップ『Finishing the Job』の締め——WasmGC既定化・Impeller一本化・Material/Cupertino分離——の最終アナウンスと3.50の確定情報が主役になる見込みで、2026の安定ラインがいよいよ固まる局面だ。

3.50の目玉。Webは flutter build web --wasm の WasmGC既定化（dart:html→package:web 移行）で、desktop級の描画がブラウザに来る。Androidは Impeller一本化でlegacy Skiaバックエンドが撤去されAPI29+が前提に。土台の Great Thread Merge も効いてくる——Dart実行が専用UIスレッドからネイティブplatformスレッドへ統合され、platform channelの非同期往復なしに同期FFIでSwift/Kotlinを直接呼べる。重い計算は従来どおり Isolate.run()/compute() で別isolateへ逃がす。

状態管理は「3択を使い分け」で合意が固まった。新規は @riverpod codegenと AsyncNotifier を軸にした Riverpod 3 が既定線。Riverpod 3は書き込み/副作用を明示管理する Mutations API、失敗時の自動リトライ(指数バックオフ)、stale-while-revalidateのオフライン永続化を内蔵した。監査要件のある金融/医療や大規模チームはevent駆動でtracingの効く Bloc 9.2系、小〜中規模の細粒度リアクティビティは signals。原則は「一つ選んで一貫させる」。購読は ref.watch(provider.select(...)) で最小化し、autoDispose 既定でリークを防ぐ。

見た目と速度。Material 3 Expressive では physics(spring)ベースのモーションが標準化し、ImpellerのAOT事前コンパイル描画で表現を増やしても120fpsを維持しやすい。アニメは用途で使い分ける——同一要素の継続はHero、面の変形はContainer Transform、兄弟間移動はShared Axis、無関係な切替はFade Through、連鎖演出は flutter_animate、重いインタラクティブアートはRiveのstate machine。計測は必ず profileモードで（debugはJIT＋assertで無意味）。フレーム予算は60=16.6 / 90=11.1 / 120=8.33ms。移行で一点だけ注意：design widgetsの移行は dart fix --apply --code=migrate_design_widgets と --code を付けること（無指定は無変更の罠）。
