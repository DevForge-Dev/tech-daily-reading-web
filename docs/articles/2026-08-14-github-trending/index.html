8/14の話題リポジトリ — DeepSeek公式ハーネス・AI来歴マーク除去・完全オフライン変換

今日の3本を貫くのは「拡張性」「来歴」「オフライン実用」。全部プラグイン化する公式エージェント基盤、AIのウォーターマークを剥がすツール、ネット不要の万能ファイル変換——毛色の違う3本がTrendshift日次の上位に並んだ。

📅 2026年8月14日 ⏱ 約3分 🔗 出典 3 件

本日の急上昇3本は方向性がきれいに分かれた。エージェント基盤の拡張性、AI生成物の来歴（provenance）、そして完全オフラインの実用ツール。エージェント一色になりがちな上位ランキングの中で、ジャンルの多様性が出た日だ。以下、各リポジトリの「解決したい課題」と「提供する機能」を軸に見ていく。

deepseek-ai/deepseek-harness（TypeScript・⭐21.6k）

解決したい課題：エージェントを組むとモデル・ツール・ループ・UIが密結合になり、部品を差し替えたり拡張したりしづらい。提供する機能：DeepSeek公式のエージェント・ハーネス「dsh」は「Everything is a Plugin」を掲げ、モデル・ツール・スキル・セッション・サンドボックス・ループ・オーケストレーション・UIまで全てをプラグインとして差し替え・拡張できる（Cordis基盤）。pnpmでweb UI（dsh web）まで一式そろう。なぜ今：DeepSeek公式・Trendshift日次1位・New 2026で、公開直後から当日モメンタムを独走した。

guillaumemeyer/watermarks-remover（Python・⭐約4.3k）

解決したい課題：各社AIが埋め込む来歴マーク（不可視Unicode・統計的な文章ウォーターマーク・C2PA/EXIF/XMPメタデータ）が生成物に残る。提供する機能：PNG/JPEG/SVG/PDF/DOCX/HTML/MDから、3層（不可視Unicode＝Layer A、統計的ウォーターマークの書き換え＝Layer B、C2PA/EXIF/XMP）を除去する。Claude/Gemini（SynthID系）/OpenAI等の来歴マークに対応。なぜ今：明確な用途が受け、Trendshift日次3位・New 2026まで急上昇。エージェント一色の中で文書処理/プライバシー寄りの毛色の違いが多様性にも寄与した。

LaoFeng-mouse/flyingmouse-format（Windows・⭐約1.5k）

解決したい課題：オンライン変換は機微データを外に出すうえ、形式ごとに別ツールを使い分ける手間がある。提供する機能：Windows向けの万能変換ツール「飛鼠格式」。FFmpeg/LibreOffice/Poppler/Tesseractを内蔵し、画像/文書/表計算/PPT/PDF/音声/動画/WPSの相互変換＋OCR＋バッチ変換を完全オフラインで行う。なぜ今：AI/エージェント系が席巻する上位に、非AIのデスクトップ実用ツールがTrendshift日次4位・New 2026で食い込んだ。

ひとことまとめ：自分が試すなら、まずdeepseek-harnessの「全部プラグイン」設計を読んで自作エージェントの分割方針の参考にしたい。watermarks-removerは、自分が生成した文書にどんな来歴マークが載っているかを確認する用途で一度回してみる価値がある。
