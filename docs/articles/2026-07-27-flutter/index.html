Flutter 4.0 が視界に — Impeller 2.0・Dart 4.x・Wasm 既定化への助走（安定版は 3.44 / Dart 3.12）

今日の主役は次のメジャー。安定版は Flutter 3.44 / Dart 3.12 で、次の機能リリースは2026年8月（年4回 2/5/8/11月）。その先に控える Flutter 4.0 は Impeller 2.0 レンダリングエンジンと Dart 4.x 統合を予定し、2022年以来初のメジャー更新となる見込み。Web は Wasm を既定コンパイルターゲットにする方針で、DevTools は 3.44 で Wasm レンダラが既定になった。

📅 2026年7月27日 ⏱ 約2分 🔗 出典 3 件

なぜ今これが話題か

2026 ロードマップ「Finishing the Job」は年4回以上の安定リリースをコミットし、積み残しの完遂を掲げる。その延長線上に、2022年以来初のメジャーとなる Flutter 4.0 が視界に入ってきた。現行の安定版は Flutter 3.44 / Dart 3.12（docs は 3.44.7 反映）で、次の機能リリースは2026年8月予定。いま起きているのは「4.0 への助走」だ。

何が新しい/重要か

Flutter 4.0 は Impeller 2.0 レンダリングエンジンと Dart 4.x 統合を予定する。描画では Impeller が iOS / Android（API 29+）で既定となり、ロードマップは Android の Impeller 移行完遂を掲げる。Web は現状 flutter build web --wasm が必要だが、Wasm を既定コンパイルターゲットにする方針で、3.35+ で dry-run を実施、DevTools は 3.44 で Wasm レンダラが既定になった。言語面は Dart 3.10 で dot shorthands・analyzer plugin システム・build hooks 安定化を導入、Dart 3.11（2026年2月）は言語追加なしで editor サポートを強化。dart analyze/fix/format は AOT 化で最大 50% 高速になった。

実務での使いどころ

自分なら、今は3.44 / Dart 3.12 で安定運用しつつ、Web ターゲットは --wasm ビルドを試験導入して JS レンダラとの体感差・バンドル差を実測しておく。Dart 3.10 の dot shorthands と build hooks は既存コードの整理に効くので、analyzer plugin と合わせて先に取り込む。AOT 化した dart analyze/fix は CI の短縮に直結する。

注意点・落とし穴

4.0 の内容はロードマップベースの見込みで、時期・仕様は変わりうる。Wasm 既定化は依存パッケージの Wasm 互換性（dart:html 直叩き等の非互換）が前提になるので、移行前に依存の棚卸しが要る。Impeller は多くのシェーダー起因ジャンクを消すが他要因のジャンクは残るため、profile モードでの計測は引き続き必須。

ひとことまとめ

いまは 3.44 / Dart 3.12 が地に足の着いた選択。その裏で Impeller 2.0・Dart 4.x・Wasm 既定化が 4.0 に向けて積み上がっている。Web の Wasm 化と依存互換の確認を、今のうちから小さく始めておきたい。
