11/4のFlutter — stable 3.50の公開手続きが始動（Dart 3.14初stable・WasmGC既定・Impeller一本化）、今いちばん採り入れたい animations 3.0 と freezed sealed union

11/2にstable 3.50のrelease-tracker #195830が起票。昇格は最終段階だがArchive未到達。『今やること』と、昇格を待つ間に効く2つの技法を整理する。

📅 2026年11月4日 ⏱ 約4分 🔗 出典 5 件

背景・なぜ今これか。 11/2にstable 3.50.0 の release-tracker #195830 が起票された（候補ブランチ flutter-3.50-candidate.0・tag 3.50.0）。ただしチェックリストは全て未完（残りcherry-pickのマージ、engine hash pin、postsubmit検証、各所への告知が未着手）＝公開は最終段階だがまだArchiveには出ていない。現況のstableは依然 3.47.9 / Dart 3.13.7、beta は 3.50.0-0.3.pre / Dart 3.14.0。

何が重要か：3.50で確定とされる変更。 最大の節目は Dart 3.14 が stable 初到達（dot shorthands、dart migrate、dart2wasm標準化が一般化）。加えて Web WasmGC 既定化（build web --wasm→skwasm）、Android Impeller 一本化（legacy Skia を Android10+ で引退）、Wasm遅延ロード stable、Android 17 day-zero対応、material_ui/cupertino_ui の正式deprecation（dart fix --apply --code=migrate_design_widgets）。

実務での使いどころ・自分が試すなら。 本番は 3.47.9 を pin のまま、別ジョブで 3.50 beta を緑化しておく——具体的には build web --wasm と appbundle を今のうちに通して、WasmGC既定化とImpeller一本化の地雷を事前に踏んでおく。stable公開後はrelease notesと flutter upgrade の差分を確認してから昇格する。

昇格を待つ間に効く技法①：animations 3.0.0。 Material の4遷移（Container transform / Shared axis / Fade through / Fade）をwidget化した公式パッケージ。自前Heroや AnimationController を書かずに「意味に合った」遷移を宣言的に置ける。関係が強い（親子・ウィザード）→ SharedAxis、関係が薄い（ボトムナビの行き先）→ FadeThrough、カード/FABが画面へ膨らむ → OpenContainer、と意味で選ぶのが勘所。PageTransitionSwitcher の子には必ず一意Keyを付ける（同一視でアニメしない）。

昇格を待つ間に効く技法②：freezed 3.2 の sealed union。 状態機械を sealed class＋factoryコンストラクタで表し、Dart 3 の switch 式で網羅性をコンパイラ強制させる。ケースを足して switch を直し忘れると警告が出る＝状態の取りこぼしが消える。BLoC/Cubit/Riverpod の state をこれにすると emit と switch が噛み合う。下図は認証状態の例。

注意点・落とし穴。 ①Flutter GPU（flutter_gpu：DartとGLSLで自前レンダラを書く低レベルAPI）は experimental で API安定性の保証なし・master推奨。stableの業務アプリに今入れる技術ではなく、描画最適化の第一選択は依然 const/RepaintBoundary/raster cache/Impeller。②sealed union は record では表せない（名前付き型が要る）。局所・一時データはrecord、層をまたぐ／ログに出るドメインモデルはfreezed、と使い分ける。③生成物 *.freezed.dart/*.g.dart は手編集禁止（build_runner watch -d）。

ひとことまとめ。 3.50は「Dart 3.14＋Web/Androidの描画土台更新」という大きめの節目。pinのまま beta を緑化して備えつつ、待ち時間に animations 3.0 と freezed sealed union で遷移と状態を型に閉じ込めておくと、昇格がそのまま品質の底上げになる。
