Claude Code

v2.1.223/221 — org一括ガバナンス・Focus view・sandbox mask で"組織で安全に回す"へ

strictKnownMarketplaces/blockedMarketplaces が owner/* ワイルドカードに対応しプラグイン供給元をorg単位で一括許可/ブロック。Focus view でツール活動をターン単位に折りたたみ、Linux/WSLはsandbox資格情報のmaskモード。/teleport でクラウド作業をローカル継続。

📅 2026年8月7日 ⏱ 約3分 🔗 出典 5 件

今週の Claude Code は、個人の便利ツールから「組織で安全に運用する基盤」へと重心を移す更新が続いた。8/5 の v2.1.223、8/4 の v2.1.221（39件のCLI変更）を軸に、ガバナンス・可視性・サンドボックス強化の三方向が同時に前進している。折しも採用は"ChatGPTモーメント"と評される拡大局面で、企業導入を前提にした堅牢化が地に足の付いた形で入ってきた。

何が新しいか。まず管理設定 strictKnownMarketplaces / blockedMarketplaces が owner/* 形式のワイルドカードに対応し、特定 GitHub organization 配下のマーケットプレイスを丸ごと一括で許可またはブロックできるようになった。プラグイン供給元をorg単位でガバナンスできる。次に Focus view（Ctrl+Alt+F）が、実行中ツールのライブインジケータだけを残して詳細をターン単位のサマリーへ折りたたみ、長時間・並列運用の画面煩雑さを抑える。さらに Linux/WSL 向けに sandbox 資格情報の mask モードが加わり、サンドボックス内コマンドにはセンチネル用のコピーを読ませ、実際の値は egress 時にプロキシが差し替える（macOSはdenyにフォールバック）。加えて /teleport のヒントでクラウドセッションを claude --teleport <id> でローカルへ引き継げる。zsh の [[ ]] 正規表現や不可視Unicodeを悪用した Bash 権限バイパスなど、複数のセキュリティ修正も同梱され、月内では ultraplan が削除された。

拡張レイヤーの使い分け。ガバナンスの土台を押さえたら、拡張は Hooks・Subagents・Skills を役割で切り分けるのが定石だ。強制したいルールは決定論的に発火する Hooks（PreToolUse等）、文脈知識のオンデマンド注入は説明文一致で読み込む Skills、並列調査や委譲の隔離は Subagents。プラグインはこれらを束ねる配布フォーマットで、.claude-plugin/plugin.json と YAML 付き Skill が基本構成、--plugin-dir でローカルテストできる。

使いどころ・落とし穴。チームでプラグインを配るなら、まず信頼する org を strictKnownMarketplaces に your-org/* で登録し、供給元を面で管理するのが安全だ。長時間運用は Focus view を既定にして「今どのツールが走っているか」だけ見える状態にすると事故に気づきやすい。一方 sandbox mask はLinux/WSL限定で macOS は deny に落ちるため、mask 前提の運用を macOS に持ち込むと挙動が変わる点に注意。ultraplan 廃止のように機能が消えることもあるので、ワークフローが特定機能に依存していないか点検しておきたい。

ひとことまとめ。「org一括ガバナンス＋Focus viewの可視性＋mask/権限修正の安全性」。個人の速さより、複数人・長時間で"事故らせない"方向に週次で堅牢化が進んでいる。
