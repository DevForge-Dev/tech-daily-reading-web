cmdk で作る ⌘K コマンドパレット — App Router 統合・非同期検索・開閉アニメーション

unstyled で高速な cmdk を、クライアント島＋遅延読み込みで App Router に組み込む定石と落とし穴。

📅 2026年9月25日 ⏱ 約4分 🔗 出典 4 件

Vercel・Linear・Raycast・GitHub が備える「⌘K で開くコマンドパレット」は、いまや SaaS / ドキュメント / 管理画面の事実上の標準ナビゲーション。マウスに手を伸ばさず検索→絞り込み→Enter で「ページ移動・アクション実行・設定切替」を一気にこなせる。その決定版が cmdk（pacocoursey / Vercel）で、unstyled・composable・高速なファジー検索内蔵の React コンポーネント。shadcn/ui の <Command> / <CommandDialog> も内部はこのラッパだ。

構成は Command（ルート：子の Command.Item を自動でフィルタ＆スコア順ソート）、Radix Dialog を土台にフォーカストラップ/スクロールロック/aria を担保する Command.Dialog、制御可能な Command.Input、アニメ用に --cmdk-list-height を公開する Command.List、onSelect と検索エイリアス keywords を持つ Command.Item。挙動の要は filter（0で非表示・大きいほど上位）と shouldFilter：これを false にすると内蔵フィルタ/ソートを完全に無効化でき、サーバー検索や非同期結果を自前で流すときに必須になる。keywords に日本語や別名を入れれば「設定→せってい/config」でヒットさせられる。

App Router では初期表示に不要なのでクライアント島として隔離するのが定石。'use client' ラッパ経由で next/dynamic の ssr:false 遅延読み込みにして初期 JS を削り、⌘K トグルは自前の keydown で実装する（ライブラリは購読しない）。選択は useRouter().push、ホバー/選択移動時に router.prefetch を呼べば遷移は体感ゼロだ。

useEffect(() => {
  const onKey = (e) => {
    const mod = e.metaKey || e.ctrlKey
    if (mod && e.key.toLowerCase() === 'k') { e.preventDefault(); setOpen(o => !o) }
    if (e.key === 'Escape') setOpen(false)
  }
  window.addEventListener('keydown', onKey)
  return () => window.removeEventListener('keydown', onKey)
}, [])

開閉は @starting-style で discrete プロパティも遷移させ、--cmdk-list-height をフィルタ結果に追従させると高さが滑らかに動く。prefers-reduced-motion ではトランジションを切って即時表示に。落とし穴：cmdk は Client 専用（useId/useSyncExternalStore 依存で Server Component 不可）、React 19 / Next 15〜16 では cmdk@^1.x に固定する。⌘K のブラウザ/OS ショートカット衝突は preventDefault で回避。仮想化なしで実用は 〜2,000〜3,000 項目まで。自分が試すなら：静的なページ一覧は RSC から props で渡し、動的検索だけ Route Handler(GET) に投げるハイブリッドが軽い。ひとことまとめ：見た目は全部自前だが、キーボード駆動 UX の土台としては現状の決定版。
