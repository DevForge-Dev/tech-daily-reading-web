Claude Code

Claude Codeがセルフホスト環境を公開ベータ — クラウドセッションを自社網で実行、足回りはネスト/fork標準化

クラウドセッションをAnthropicではなく自社ネットワーク内のマシン/コンテナで実行できる「セルフホスト環境」が公開ベータに。コード・成果物・シークレットは自社に留まる（プロンプトとClaudeが読むコードは推論のため送信）。あわせてサブエージェントのネスト既定深さ3・fork既定オン、/skillsの絞り込み検索、Writeの未読上書き統一など足回りも更新した回。

📅 2026年8月17日 ⏱ 約2分 🔗 出典 3 件

今日のClaude Codeの主役は「セルフホスト環境」の公開ベータだ。Web・モバイル・デスクトップ・ターミナル・スケジュール実行から起動するクラウドセッションを、Anthropicのインフラではなく自社ネットワーク内のマシンやコンテナ上で走らせられる。claude self-hosted-runner 一発で自前マシンを実行基盤に変えられ、リポジトリのチェックアウト・ビルド成果物・シークレット・生成/変更ファイルは組織のマシンに留まる（ただしプロンプトとClaudeが読むコードは推論のためAnthropicへ送られる）。Team/Enterprise向けで既定はオフだ。

なぜ今か。Claude Codeはエンタープライズ支出の主軸になりつつあり（ARRは25年11月の10億から26年2月に25億ドル、年100万ドル超の顧客は1,000社超）、規制業種ほど「コードとシークレットを自社網から出したくない」というデータ主権の要求が強い。手元セッションを外部から継続するRemote Controlと違い、プラットフォームチームが運用する共有基盤を組織の誰もが使える点が新しい。

足回りも同時に更新。サブエージェントのネストが既定で深さ3・上限5へ拡張され（従来は1）、subagent_type:"fork" のフォークが既定オンになった（会話全文とプロンプトキャッシュを継承、対話中の非チームメイト起動は既定でバックグラウンド）。/skills には入力で絞り込む検索ボックスが付き、長い一覧からスクロールせず目的のスキルへ届く。Writeツールは新モデルが未読のファイルでも上書き可にEdit規則へ統一され、/deep-research は自発起動をやめ手動起動のみになった。

自分が試すなら、まず非機密の定期タスクをセルフホストrunnerで走らせ、成果物とシークレットが自社に留まることをログで確認したい。サブエージェントは深さ3を活かして「調査→要約→整形」を多段化し、fork既定オンでコンテキスト継承の挙動を掴む。

注意点。セルフホストでもプロンプトとClaudeが読むコードはAnthropicへ送信される点は変わらない（「一切外に出ない」ではない）。既定オフなので明示的な有効化が要る。fork既定オンでバックグラウンド実行が増えるため、走っているエージェントの把握を怠らないこと。

ひとことまとめ：実行基盤を自社に引き込む「セルフホスト」でコンプライアンス層のハードルを下げた回。足回りもネスト/forkで多段エージェントが標準化へ向かう。
