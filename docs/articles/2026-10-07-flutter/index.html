Next.App DevCon 2026 開幕 — WasmGC既定化・Impeller一本化、3.50へ“積み残し完了”

Day1基調講演でロードマップの締め。足元はstaggered/go_router/sliverの定石も。

📅 2026年10月7日 ⏱ 約4分 🔗 出典 4 件

Flutter/Androidの新カンファレンスNext.App DevCon 2026（FlutterConとDroidconが合流、10/7–9）が本日開幕。Day1基調講演では、長年のロードマップ『Finishing the Job』の締めくくりと、次期stable3.50（2026年11月）の確定スケジュールが示される見込みだ。通底テーマはAIネイティブ開発（GenUI / A2UI）。普段の小技ではなく、Flutterの“これから”が見える節目なので今日はここを主役に読む。

何が確定しそうか。締めの3本柱は(1) Web WasmGCの既定化（今はflutter build web --wasmが必要、3.50で既定へ。ベンチでロード約40%高速・ランタイムメモリ約30%減。dart:html→package:web移行が前提）、(2) Android Impellerの一本化（旧Skiaパスの撤収）、(3) Material/Cupertinoのcore分離。現行安定版は3.47.5 / Dart 3.13.4、betaは3.49系/Dart 3.14.0で、2026は「年4回stable（3.41/3.44/3.47/3.50）＋12 beta」のケイデンスを公約。Dart言語側はPrimary Constructors（宣言とフィールド定義の同時化）とAugmentationsが次の目玉で、macrosは無期限ポーズ継続——コード生成は当面build_runner＋source_genのままだ。AIトラックの中核は公式GenUI SDK（pub.devでalpha）で、LLMがFlutterのwidgetカタログを使ってUIを生成・動的追従する仕組みである。

今日の実装トピックも粒ぞろい。アニメーションはstaggered（時間差）——controllerは1つだけ用意し、各TweenをCurvedAnimation(parent: controller, curve: Interval(開始%, 終了%))で区切る。区間は重ねてよく（0.0–0.6でslide、0.3–1.0でfade等）、controllerが0→1を一度走るだけで各アニメが自分の区間だけ動く（dispose()必須）。ナビはgo_router 16系でURL駆動に一元化し、@TypedGoRoute＋build_runnerで型安全ルートに、タブごとに独立スタックを持たせるならStatefulShellRoute.indexedStack。長リストはListView.builderで遅延生成し、高さ一定ならitemExtentでレイアウト計算を省略、複合スクロールはCustomScrollView＋sliverで。計測は必ずprofileモードのDevTools Frame chartで、UI(Dart)が赤ならbuild()、Raster(GPU)が赤ならpaint()/saveLayerを疑う。

自分が試すなら。まずWebターゲットのプロジェクトで--wasmビルドのサイズ/速度を測り、dart:html依存の棚卸しを前倒ししておく（3.50の既定化で詰まらないため）。注意点：3.50はまだ11月予定でbetaは3.49系、macros前提の設計はしないこと。

まとめ：DevCon Day1は「WasmGC既定・Impeller一本化・core分離」で積み残しの完了を示す回。足元はWasm移行の下調べと、staggered/go_router/sliverの定石を押さえておけば十分に追いつける。
