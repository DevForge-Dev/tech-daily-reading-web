出力を短く、既定を賢く — Conciseスタイルとv2.1.236のANTHROPIC_DEFAULT_MODEL、そしてサブエージェント/Skillの使い分け

v2.1.236→237が連日リリース。237は前置きを省いて結果先出しする組み込み出力スタイル『Concise』とLLMゲートウェイのキャッシュ不具合修正、236は新規セッションの既定モデルを固定するANTHROPIC_DEFAULT_MODELとセッション間notify_when_idle。VS Code拡張のFocus viewとOpus 5(1Mコンテキスト・価格据え置き)も追加。運用面はサブエージェント(独自コンテキスト・最終要約のみ)とSkillの線引きが軸で、裏づけとして30人チーム+35%、ラン率25億ドルの数字が並ぶ回。

📅 2026年8月21日 ⏱ 約3分 🔗 出典 5 件

今日は特定の一機能というより、『出力を短く・既定を賢く』の両輪が主題だ。Claude Codeはv2.1.236→237を連日で刻み、応答の冗長さとモデル選択という日々の摩擦を削りにきた。

何が新しいか。v2.1.237は組み込み出力スタイル「Concise（簡潔）」を追加。/configの「Output style」から選ぶと、前置きやナレーションを省いて結果から先に返す。作業自体の丁寧さは保ったまま読み時間とトークンだけを削るのがミソで、詳細が要るなら追加で尋ねればよい。あわせてLLMゲートウェイ/カスタムbase URL経由でプロンプトキャッシュが効かない不具合も修正された。v2.1.236は環境変数ANTHROPIC_DEFAULT_MODELで新規セッションの既定モデルを指定でき、/model選択が優先され再起動後も保持される（都度上書きのANTHROPIC_MODELとの違い）。さらにセッション間SendMessageにnotify_when_idle（別セッションが次にアイドルになったら一度だけ通知）が加わった。エディタ側ではVS Code拡張にFocus view（ツール実行ログを畳んで会話の見通しを確保）、そしてOpus 5が既定Opusに——1Mトークンコンテキスト対応で価格はOpus 4.8据え置きだ。

仕組みと勘所。運用面の中心はサブエージェントだ。独自のコンテキスト・ツール・モデルを持つ別インスタンスで、親には最終要約だけが返る。だから深い検索・ログ解析・依存監査のような『中間結果を後で見ない副次タスク』を切り出せば、メイン会話を汚さずコンテキストを節約できる。逆に手順を目で追って逐次操作したいならSkillを使う、という線引きが明快だ。加えてHooksでライフサイクルイベントに決定的（deterministic）な制御を差し込み、memory / hooks / skills / subagents / plugins / MCPを別レイヤーとして設計するのが上級者の型になってきた。

自分が試すなら：定常作業とCIログはConciseを既定にし、チームのANTHROPIC_DEFAULT_MODELを揃えて『どのモデルで走ったか』の揺れを消す。重い調査は迷わずサブエージェントへ回す。裏づけも厚い——30人開発チームは共有スキル22本・Hooks11本を整備して四半期で+35%の生産性、効果は4か月持続。市場でもラン率売上25億ドル超、ローンチ3か月で10倍、法人サブスクは年初から4倍と、まさに『ChatGPTモーメント』の様相だ。注意点：Conciseは端的すぎると感じたら都度詳細を要求する前提で、ANTHROPIC_DEFAULT_MODELも/model選択に上書きされる。まとめ：小さなUX/設定改善（Concise・既定モデル・Focus view）と、サブエージェント/Skillの使い分けが噛み合って、日常運用の摩擦がまた一段下がった。
