Flutter 3.47 / Dart 3.13 の実務移行 — primary constructors・Impeller デスクトップ既定

2026-08-12 リリース。primary constructors が stable、Impeller が macOS/Windows/Linux でも既定、Widget Previews stable の3点が効く。

📅 2026年9月7日 ⏱ 約2分 🔗 出典 2 件

今日の主役は Flutter 3.47 / Dart 3.13（2026-08-12 リリース、現行安定版 3.47.1 / 3.13.1）の実務移行。年4回（2/5/8/11月）サイクルの一環で、実務インパクトが大きいのは primary constructors の stable 化・Impeller のデスクトップ既定・material/cupertino の standalone パッケージ化＋Widget Previews stable の3点だ。

何が新しいか

Dart 3.13 の primary constructors は、クラスヘッダで constructor と instance 変数を 1行で宣言でき boilerplate を大幅に削減する。レンダラは Impeller が macOS/Windows/Linux でも既定に（iOS=Metal／Android=Vulkan は従来どおり）。Impeller は全 shader を build 時に AOT precompile するため shader compilation jank を排除し、複雑アニメでも 120fps を狙える。Web は experimental で WasmGC 移行を継続（dart:html → package:web）。

// 従来
class Point {
  final int x; final int y;
  Point(this.x, this.y);
}
// primary constructors（Dart 3.13）
class Point(final int x, final int y) {}

実務での使いどころと注意

新規は language version を ^3.13.0 に上げ、モデル/DTO の定型を primary constructors で圧縮する。デスクトップ配布は Impeller 既定でカクつきが減る。ただし Web の Wasm はまだ experimental で、dart:html 依存は package:web へ移行が必要。experimental な multi-window API も本番投入は慎重に。次の機能リリースは 2026 年 11 月。

ひとこと：まず primary constructors でモデル層を書き換え、生成される差分の小ささを体感するのが移行の入口として手頃。
