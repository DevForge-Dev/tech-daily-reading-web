今日のモメンタム上位3本は、ジャンルこそバラバラ（Androidランナー／チャットUI／グラフィックス）だが、重いインフラを立てず手元で軽く動くという一点で通じている。AIエージェント一色の局面で、こうした「低レイヤー・ローカル完結」の多様性枠が急伸しているのは、2026らしい揺り戻しだ。

RoutineMiku/apkstart（JavaScript・⭐3.5k）

解決したい課題：Android アプリを Windows で使うには従来エミュレータの重い UI を開く必要があった。提供する機能：.apk を関連付けておけばダブルクリックで解析→インストール→デスクトップ図标生成まで模拟器UIを一切開かず完結し、各アプリが独立ウィンドウ＋開始メニュー検索で動く（自前QEMUランタイム）。壳層は第三者依存ゼロ（ZIP/PNG/ICO/AXML解析も手書き）で空闲自動回収＝極致轻量。本日 Trendshift 日次 +184 で当日トップ級（公開約16日で3,500★）、AI一色のトレンドで希少な非AI・システム題材が刺さった。MIT。

deepseek-ai/chat-demo（TypeScript・⭐1.7k）

解決したい課題：LLM API を試すのにアプリ用バックエンドを立てるのは重い。提供する機能：DeepSeek 公式org製のバックエンド不要・ブラウザ→API直結の静的チャットUI。配布zipを解凍して index.html をダブルクリックすればビルド不要でローカル起動し、初回に API キーを入れるだけ。公式リファレンス実装として、公開約3日で1,723★（日平均約648★/日＝本日最速級）、Trendshift 日次 +169 の当日モメンタム筆頭。MIT。

berkantay/gpucanvas（TypeScript・⭐419）

解決したい課題：数千のライブ DOM ノードを無限キャンバスに載せると描画が重い。提供する機能：描画を WebGPU の1インスタンスパスに肩代わりさせ、5,000枚のライブReact画面でもパン/ズームがDOMに触れないのにクリック/入力/stateは实元素へ届く。ダブルクリックでコンポーネント階層にドリル、移動/リサイズ、シェーダ、そしてAIエージェントが要素を読んで指差せる。公開約2日で419★（率約49%/日換算）。WebGPU/グラフィックスの多様性枠。MIT。

ひとこと

自分が試すなら、まず chat-demo（ビルド不要でDeepSeek APIの手触りをすぐ確認できる）と、UI実験用に gpucanvas（大量ノードのキャンバス表現の下敷き）。apkstart は Windows 環境限定だが「アプリを独立窓でネイティブ風に」という発想自体が参考になる。3本とも MIT で、読んで学ぶ素材として素直だ。
