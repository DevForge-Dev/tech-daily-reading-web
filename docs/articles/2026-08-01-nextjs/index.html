無限マーキーを純CSSで継ぎ目レスに — App RouterではServer Componentのまま、gapを移動量の式に入れるのが肝

中身を2セット複製しtranslateX(calc(-100% - gap))で1コピー分だけ流すと継ぎ目が消える。純CSSなので'use client'不要でhydrationゼロ、複製にaria-hidden、prefers-reduced-motionでは静止表示へ。

📅 2026年8月1日 ⏱ 約2分 🔗 出典 3 件

ロゴウォールや『Trusted by』帯のように途切れなく流れるバナーはマーケLPの定番だが、素朴に組むとループの継ぎ目でカクつく・画面幅を変えると隙間が出る・アクセシビリティが壊れる。旧 <marquee> は非推奨（reduced-motion 無視・可読性の問題）で、いまはHTML＋純CSSで作るのが定石だ。

何が新しい/重要か：核心のトリックは中身をまるごと2セット並べ、トラックを1コピー分だけ流すこと。1コピー分流れた瞬間に複製が元とピクセル単位で同じ位置に来るので、0 へ戻す瞬間が目に見えない＝継ぎ目レス。移動量は必ず割合/変数で送る（項目数で幅が変わっても同期するため）。最頻出バグは gap を式に入れ忘れることで、translateX(-100%) だと隙間1個分ずれて見える。端は mask-image: linear-gradient(...) でフェードし、:hover / :focus-within で animation-play-state: paused。

@keyframes scroll {
  to { transform: translateX(calc(-100% - var(--gap))); }
}

App Routerでの使いどころ：純CSSなので'use client' 不要、Server Componentのまま置けてhydrationゼロ・INP/CLS有利。データはRSCで取得し、配列を2回mapして複製側コンテナに aria-hidden='true' を付ける（SRの二重読み防止）。ロゴ画像は width/height を明示してCLSを回避。注意点：マーキー内にリンクや本文などフォーカス可能/重要要素は置かない（タブ順・可読性が壊れる。装飾に限定）。速すぎると酔うので duration は長めに。prefers-reduced-motion では単に一時停止するだけでなく、複製を隠し flex-wrap で全ロゴが静止表示されるレイアウトへ戻すのが丁寧だ。加点として animation-timeline: scroll() でスクロール駆動ティッカーもJSゼロで作れる（未対応は時間駆動へフォールバック）。まとめ：2セット複製＋gap込みの移動量＋a11y、この型さえ押さえれば安く堅い。
