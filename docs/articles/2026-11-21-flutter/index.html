Flutter 3.50.1 が stable 出荷 — あわせて物理シミュレーションアニメ（animateWith + SpringSimulation）でバネに運動を委ねる

数日追ってきた 3.50.1 hotfix がついに stable 出荷（11/20・Dart 3.14.0 据え置き）。中身は回帰修正の寄せ集めで移行リスクは低め。ただし release-tracker #196743 は未更新のねじれあり。今日の技法は物理シミュレーション——AnimationController.animateWith(SpringSimulation) で duration を捨て、離した瞬間の速度を初速にバネで中心へ戻す。

リリースから。数日追ってきた 3.50.1 hotfix がついに stable 出荷された（11/20・Dart 3.14.0 据え置き）。flutterreleases.com の stable 表に 3.50.1 / Dart 3.14.0 / 2026-11-20 行が出現し、11/11 の 3.50.0 から約9日での hotfix。中身は回帰修正の寄せ集め（flutter_tools・Linux 描画・Android split-APK の versionCode offset など計11エントリ）で機能追加はなく、移行リスクは低めだ。ただし release-tracker #196743 は 11/21 時点でも OPEN・チェックリスト全項目未チェックというねじれがあり、「配布物は出ているが tracker は未更新」の状態——判断は flutterreleases / SDK Archive 側を一次として優先する。pin 基準は 3.50.0→3.50.1 へ更新可（flutter upgrade→flutter analyze→CI 緑を確認）。beta は 3.51.0-0.2.pre（Dart 3.15.0）へ前進した。

今日の技法：duration を捨て、運動をバネ物理に委ねる

これまでの Tween/Curve ベースは duration を固定して 0→1 を補間する。対して物理シミュレーションは「初速・質量・バネ定数から運動を解く」——自然な慣性・弾みを duration 無しで表現する。公式 cookbook「Animate a widget using a physics simulation」は、ドラッグして離したカードを離した瞬間の速度を初速にバネで中心へ戻す例だ。import は package:flutter/physics.dart。

肝は AnimationController.animateWith(Simulation)。公式いわく「シミュレーションを使うので controller の duration 引数はもう要らない」——AnimationController(vsync: this) だけで生成し、値の進行はシミュレーション側が決める。バネは SpringDescription(mass, stiffness, damping) の3値で性格が決まり、SpringSimulation(spring, 開始値, 終了値, 初速) に渡す。

const spring = SpringDescription(mass: 1, stiffness: 1, damping: 1);
final simulation = SpringSimulation(spring, 0, 1, -unitVelocity);
controller.animateWith(simulation); // duration なしの controller でOK

実務での使いどころ・注意点・併読

mass/stiffness/damping を手で決める代わりに SpringDescription.withDurationAndBounce()（尺と弾み具合から生成）が公式 tip。より宣言的に書きたいなら community の flutter_physics（PhysicsController 等）という別アプローチもある。ルーティング文脈では go_router 18.1.1（flutter.dev・Flutter Favorite）が、ボトムナビで各タブの状態を保つ定番として StatefulShellRoute.indexedStack（各ブランチが独立 Navigator を持ち、タブ切替で dispose されない／切替は navigationShell.goBranch(index)）を提供する——18.0.0 で material_ui/cupertino_ui へ移行し最低 Flutter 3.44 になった破壊的変更に注意。高度スクロールは CustomScrollView に sliver を並べ、SliverAppBar の pinned/floating/snap/expandedHeight で折りたたみヘッダ、SliverList.builder で可視分だけ遅延生成、が土台だ。

ひとこと

3.50.1 は「回帰修正だけ」の安全な一段。アニメは、tap で決め打ちしたいなら Tween、ドラッグ&フリングの“手触り”が要るなら物理シミュレーション——animateWith で duration を手放す、と使い分けるのが指針になる。
