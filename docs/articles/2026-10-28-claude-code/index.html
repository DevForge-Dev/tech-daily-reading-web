Claude Code

10/28のClaude Code — v2.1.311がまとめて効かせる「無人で安全に長く走る」地固め

self-hosted-runnerのアイドル保持やultrathinkのxhigh実行に加え、200K超での圧縮継続・CLAUDE.mdフリーズ解消・SubagentStop多重実行の修正。派手さより信頼性の週。

📅 2026年10月28日 ⏱ 約3分 🔗 出典 5 件

新しい版が途切れがちだった週に、v2.1.311（10/26）がまとめて効く更新を出した。昨日(10/27)の枠では「新規未確認」としていたが、実際にはこの版が出ていたので今日補足する。目玉は信頼性の底上げと、長時間・無人運用を支える細部だ。

何が新しいか

機能面では、self-hosted-runner にアイドルセッションを保持する --hold-idle-file / --max-hold-min、VS Code 返信内コードブロックの構文ハイライト、ターミナルの ultrathink を API 経由で Opus 5.5 / Sonnet 5.5 / Haiku 5.5 / Fable 5.1 の xhigh effort で実行、Bedrock/Vertex/Foundry 等のモデル設定を downloads.claude.ai の署名ファイルから読み込み（CLAUDE_CODE_MODEL_CATALOG=off で無効化）。設定の DISABLE_COMPACT は「無効化専用」になり再有効化はできなくなった。

そして効くのが信頼性修正だ。リクエストが200Kトークンを超えても「Usage credits required for 1M context」で止まらず、圧縮（compaction）して継続するように。CLAUDE.md に非常に長い箇条書きがあると起動時や読み書き後に固まる問題を解消。実行中サブエージェントごとに毎分約2回起きていた SubagentStop フックの多重実行を、終了時1回だけに修正した。

設計の勘所：知識と実行制約を分ける

同じ週、運用ベストプラクティス（SmartScope）と Skills/Subagents の使い分け（chudi.dev）の解説が出た。核心は「知識」と「実行制約」の分離。プロジェクト知識は CLAUDE.md や Skills に置くが、これらは読まれる指示であって強制力はない。禁止を本当に守らせたいなら、イベント入力・判定・終了コードの仕様に従う Hooks で担保する。Skills は本体会話のコンテキストに積まれ、Subagents は別ウィンドウで動いて要約だけ返す——大量読込は Subagent、見ながら進める反復は Skill、常に守るルールは Hook、という住み分けだ。

自分が試すなら

まず DISABLE_COMPACT を外して 200K 超の自動圧縮継続を体験し、CI の self-hosted-runner で --max-hold-min を使ってアイドル保持による立ち上がり短縮を測る。CLAUDE.md が長大なら、長い箇条書きを Skills へ切り出す良い機会でもある（フリーズ修正と合わせて体感が変わる）。

注意点

プラグインの公式化で入った「Mods」（JS/TS で実行経路に割り込む拡張）は、ツール呼び出し前に介入できる分新たな攻撃面でもある。本番コードと同じ目でレビューを。これは「proxy/middleware は認可境界ではない」（ヘッダ偽装の CVE-2025-29927）という Next.js 側の教訓とも通じる。

ひとことまとめ

派手な新機能より、「人が張り付かなくても安全に長く走る」方向の地固め。圧縮継続とフック修正は、まさに毎日無人で回すこの種のパイプラインに直接効く。
