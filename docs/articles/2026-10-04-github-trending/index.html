10/4の話題リポジトリ — 画像から歩ける3D世界・スマホからエージェント操作・常駐するAI同僚

エージェント基盤一色のトレンドの中で、本日は創作3D・端末運用・常駐同僚という毛色の違う3本が急上昇した。

📅 2026年10月4日 ⏱ 約3分 🔗 出典 3 件

GitHubのトレンドは相変わらず記憶／RAG／ハーネスといったエージェント基盤一色だ。そんな中で本日急上昇した3本は、いずれもその王道から一歩ずれた——画像を丸ごと世界に変える創作系、エージェントを外から操る運用系、チャンネルを横断して常駐する同僚系。多様性のある顔ぶれが揃った。

neilsonnn/image-blaster（JavaScript・⭐約4.8k）

解決したい課題：1枚の画像から3D環境・メッシュ・ガウシアンスプラット・効果音までを作ろうとすると、World LabsやHunyuanなど複数のツールを個別に組み合わせる手間がかかる。提供する機能：それらを束ねたClaude用スキルセットで、5分弱で「画像→探索できる世界」を生成する。環境はMarble、オブジェクトはHunyuan 3Dが担当し、面数・PBR材質・ポリゴン種別まで調整可能。.glb/.obj/.spz/.mp3 で書き出し、Unity/Unreal/Godot・Blender/Mayaへ渡せる(MIT)。なぜ今：エージェント基盤一色の中で希少な創作応用がTrendshift日次上位に。

pingdotgg/t3code（TypeScript・⭐約15.6k）

解決したい課題：手元のマシンで長時間回すAIコーディングエージェントを、外出先や別端末から操作・監視したい。提供する機能：Claude Code/Codex/Cursor/Grok Build/OpenCodeに対応した“エージェント操作面”を、モバイル/web/デスクトップで提供。リモート運用前提でself-host可、winget/Homebrew/AURや npx t3@latest で導入できる(MIT)。なぜ今：本日+約492(率約3.2%/日)でTheo(t3)発、fork前提の“truly open”姿勢が支持を集めた。

CopilotKit/OpenDots（TypeScript・⭐約3.2k）

解決したい課題：AIエージェントを単発のチャットでなく「チャンネルを横断して常駐する同僚」として業務に組み込みたい。提供する機能：テキスト/通話/Slackをまたいで常駐するAI同僚(Dots)を建てるOSSテンプレート。各Dotに隔離コンピュータ(ブラウザ/FS/シェル)を与え、役割・ツール権限・human-in-the-loop承認・文書WS(Spaces)まで設定できる。CopilotKit/AG-UI/TanStack AI上で完全self-host可(MIT)。なぜ今：Trendshift新顔として登場、常駐エージェント運用の設計を丸ごと公開した点が新しい。

自分が試すなら。LP/映像の素材生成の下地としてimage-blaster、エージェントを長時間回す運用の“操作面”としてt3codeから触りたい。OpenDotsは常駐エージェントの権限・承認設計のリファレンスとして読む価値がある。
