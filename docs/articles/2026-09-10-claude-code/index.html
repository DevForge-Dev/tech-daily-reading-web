Claude Code v2.1.266 — ゲートウェイ回帰バグの緊急修正と、v2.1.263 の広範改善＋Fable 5.1 既定化

9/8 の v2.1.266 が最新。直前 v2.1.265 で混入した CLAUDE_CODE_USE_GATEWAY の回帰を潰す修正が中心で、あわせて 9/6 v2.1.263 の広範改善と Fable 5.1 の既定化を棚卸しする。

📅 2026年9月10日 ⏱ 約2分 🔗 出典 3 件

9月8日公開の v2.1.266 が現時点の最新で、内容は直前 v2.1.265 で混入した回帰の緊急修正が中心だ。派手な新機能ではないが、LLM ゲートウェイ／プロキシ経由で Claude Code を使う企業構成を直撃していたため、影響範囲は広い。あわせて 9/6 の広範改善 v2.1.263 と、既定モデルの Fable 5.1 化まで棚卸しする。

何が新しい/重要か

問題は未文書の環境変数 CLAUDE_CODE_USE_GATEWAY にあった。v2.1.265 ではこの変数が単独で Cloud ゲートウェイへのサインインを強制するようになり、API キーや apiKeyHelper、独自認証ヘッダと併用する構成が『Not signed in to the Cloud gateway』で全リクエスト失敗。v2.1.266 でこの変数は単独では再び無視される元の挙動に戻り、ゲートウェイ／プロキシ利用者は設定変更なしで復旧する。

9/6 v2.1.263 の広範改善

9/6 の v2.1.263 は多数の改善をまとめた回。ポリシー／スキル診断の追加、コマンド・タスクのインライン出力上限の拡大、VS Code ワークフロー・モデル選択・Remote Control・起動信頼性の改善を含む。性能面では描画済みブロックを更新のたびにレイアウト再チェックしないストリーミング最適化、安全面では rm -rf の位置パラメータやダブルクオート内 sh -c を捕捉する危険 rm 安全プロンプトの強化が入った。

既定モデル Fable 5.1

9 月の大型更新で Fable 5.1 が新しい既定 Fable モデルになり、コンテキスト拡大と価格改善を伴う。時間・モデルの制御が拡張され、サンドボックスと権限まわりの安全策も強化。v2.1.257 で Fable 5.1 既定化＋カスタム時刻フォーマット、v2.1.260 で未コミット変更の左右差分パネル表示が加わっている。

実務での使いどころ・注意点

ゲートウェイ／プロキシ構成のチームは即アップデートが正解。危険 rm 強化は自動化・CI での事故防止に効くので、権限設計とあわせて有効化したい。教訓としては未文書の環境変数に依存しないこと。コミット前レビューは左右差分パネルに寄せると、エージェントの変更を機械的に確認しやすい。

ひとことまとめ

「新機能」より「壊れた運用を戻す」修正が主役の週。ゲートウェイ復旧・128K 級の出力・危険 rm 強化・差分パネルと、毎日回す作業の安定性に直結する更新が積み上がっている。
