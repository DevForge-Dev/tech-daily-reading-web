Flutter 3.44 の3つの転換 — Impeller が Android 既定・Skia 撤去・Material が独立パッケージへ

モダンAndroid（API 29+）の既定レンダラがImpellerになりSkiaがコアから撤去、Material/Cupertinoがコアから独立パッケージへ分離、Agentic Hot Reload/GenUIなどAIツーリングも強化。安定版はFlutter 3.44.6 / Dart 3.12.2。

📅 2026年7月31日 ⏱ 約2分 🔗 出典 4 件

今日の主役は Flutter 3.44 がもたらす3つの転換だ。長く議論されてきたレンダラ刷新とパッケージ構成の見直しが、ついに既定として動いた。

何が新しいか：(1) Impeller がモダン Android（API 29+）でも既定レンダラになり、Skia がコアから撤去された。歴史的課題だったシェーダーコンパイルジャンクが解消され、ネイティブ級の 120fps が射程に入る。(2) Material/Cupertino がコアから独立パッケージへ分離——M3更新が四半期SDKリリースを待たず pub.dev から届き、アプリサイズも縮めやすい。(3) Agentic Hot Reload・GenUI・Hybrid Composition++ など AI ツーリングを強化。安定版最新は Flutter 3.44.6 / Dart 3.12.2（2026-07-09）で、次の機能リリースは8月。Dart 3.12 は private named parameters・primary constructors（experimental）・dot shorthands で定型コードを削減する。

状態管理の現在地：新規は Riverpod 3.0（現行 3.3.x）が既定線。Mutations が Login/Post Comment 等のアクションを Idle/Pending/Success/Error として自動で UI に公開し、ネットワーク失敗時は自動リトライ、ref.mounted が非同期処理後の provider 生存を検証して disposed 後の副作用を防ぐ。テストは平均30–40%行数が少ない。監査/大規模・full event traceability が要るなら Bloc 9.0（現行 9.2.x）。アニメは Rive 0.13.20 の state machine events で描画ロジックを widget から分離できる。

試すなら：ミッドレンジ Android 実機で Impeller 有無を profile モードで計測し、差が出たら --no-enable-impeller で切り分ける。const ウィジェットと RepaintBoundary の戦略配置で再ビルド/再描画を絞る。注意点：Impeller 使用時は Rive で描画差が出ることがあり実機検証が必須。ひとことまとめ：3.44 は「Finishing the Job」——Android の Impeller 完遂と Web の WASM 既定化へ向けた土台固めだ。
