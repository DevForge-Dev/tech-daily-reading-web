シャイニー/シマーテキスト — AIの「考え中…」をJSゼロのCSSだけで

処理中テキストを光の帯が横切る表現。半透明下地＋background-clip:text＋横スクロールで、Server Componentにそのまま置ける。

📅 2026年11月8日 ⏱ 約4分 🔗 出典 4 件

LLM/AI プロダクトの普及で、「Thinking…」「Generating…」といった処理中テキストの上を淡い光の帯がゆっくり横切る表現（shiny / shimmer text）が定番になった。箱をちらつかせるスケルトンシマーと役割が違い、こちらは可読なテキストそのものを“生きている”状態に見せる。止まっていないことを非侵襲的に伝えられるのが強みだ。

何が嬉しいか

第一に純粋 CSS だけで実装でき追加 JS がゼロ——App Router の Server Component や loading.tsx のフォールバックにそのまま置ける。第二に background-clip: text が Baseline（widely available）になり、プレフィックス前提から脱却しつつある。ReactBits・Vercel AI Elements・MVPBlocks が軒並み採用し事実上の共通言語になった（ただし AI Elements は shadcn/ui へ統合され 2026/11 末で非推奨予定なので依存しすぎない）。

仕組み

核は「半透明のテキスト色＋帯状グラデーションを背景にして background-clip: text でグリフ内だけに描く＋背景を横スクロール」の3点。文字色を半透明グレーにし、両端が透明・中央が明るい帯グラデを背景に敷き、グリフ形にクリップする。背景は半透明文字の“下”に残るので、帯が来た位置だけ明るく透けて光が走って見える。background-size: 200% 100% で引き伸ばし、@keyframes で background-position を動かすと帯が流れる。

ReactBits 流儀：可読性を落とさない

ポイントは -webkit-text-fill-color: transparent を使わないこと。透明塗りにすると帯が無い位置で文字が消える。代わりにテキスト色のアルファで下地を透かせば、常に読めたまま帯だけが明るく走る。

.shimmer-text{
  display:inline-block;
  color:color-mix(in oklab, currentColor 45%, transparent);
  background-image:linear-gradient(110deg,transparent 40%,
    color-mix(in oklab,currentColor 90%,white) 50%,transparent 60%);
  background-size:200% 100%; background-position:100% 0;
  background-clip:text; -webkit-background-clip:text;
}
@media (prefers-reduced-motion:no-preference){
  .shimmer-text{animation:text-shimmer 2.4s linear infinite}
}
@keyframes text-shimmer{to{background-position:-100% 0}}

App Router での置き方・落とし穴

シマー自体は CSS のみなので 'use client' 不要。loading.tsx に role=status / aria-live=polite を付けた <p class="shimmer-text"> を置けば JS ゼロのストリーミング用プレースホルダになる。「処理中だけ出す」制御が要るときだけ親を Client にして useFormStatus の pending で出し分ける。落とし穴は、display:inline だと帯が行で分断されること（inline-block 必須）、Safari 向けに -webkit-background-clip を併記すること、そして無限ループは WCAG 2.2.2 の対象——prefers-reduced-motion を尊重し既定を静止に。

ひとことまとめ

JS を1行も増やさず「処理中」を上品に伝えられる。鍵は透明塗りではなくアルファで下地を残す ReactBits 流儀と、reduce 時に静止する安全側の書き方。
