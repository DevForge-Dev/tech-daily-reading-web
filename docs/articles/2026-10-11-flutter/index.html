Flutter 3.47 — Impeller が全デスクトップ既定に、マルチウィンドウ前進と本番アニメの具体値

デスクトップの shader jank が構造的に解消。Web は HTML renderer を撤去。3.50（11月）の WasmGC／Android Impeller 一本化へ向けた地ならしの版。

📅 2026年10月11日 ⏱ 約4分 🔗 出典 3 件

背景。現行安定はFlutter 3.47.5 / Dart 3.13.4、betaは3.49系。次期stableの3.50（11月）でWebWasmGC既定化・AndroidImpeller一本化・Material/Cupertinoのcore分離が出揃うことがDevCon 2026で確定済みで、3.47はその地ならしにあたる。

何が新しいか。最大の変化はImpeller が Windows / Linux でも既定レンダラになったこと（macOSは既にMetal）。WindowsはOpenGLES＋SDF、両OSでグリフのガンマ補正が入り、デスクトップのshader jank が構造的に解消する。WebエンジンはHTML rendererを完全撤去してCanvasKit/Skwasmに一本化。マルチウィンドウ（windowing）APIも前進し、Win32/Linuxでpopup window、regular/dialogのsized-to-contentに対応。ただし破壊的変更に注意——preferredSize→size、preferredConstraints→constraints、decoratedフラグ削除。API追加ではAnimatedCrossFade.clipBehavior、ImageIcon.useOriginalColors、Target-Followerより推奨のOverlayPortal.overlayChildLayoutBuilderあたりが実務で効く。プラットフォーム要件はmacOS最低12、AndroidテンプレがAGP 9+＋内蔵Kotlinに。

本番アニメの具体値。レシピとして覚えておくと速い。staggeredリスト出現＝1本のAnimationController＋Interval＋CurvedAnimation(easeOutCubic)で、各アイテムは前の約60ms後に開始しフェードイン＋16px上シフト、総尺の目安は220ms＋60ms×件数。スプリングtap＝押下は80ms/easeOutで0.94倍、離すとSpringSimulation＋SpringDescription(mass:1, stiffness:220, damping:18)。shimmer＝ShaderMask＋LinearGradientを約1400msループ。120Hzの解放＝iOSはInfo.plistにCADisableMinimumFrameDurationOnPhone=YES（ProMotion、予算8.3ms/フレーム）。禁則は、listener内setState・controller未dispose・大ブラーBoxShadow。

実務の土台。状態管理は新規既定がRiverpod 3.3系、監査・大規模はBloc 9.2系。データ層はRepositoryパターンでUIがデータ源を直接触らずUserRepositoryを唯一の窓口にし、データ源をコンストラクタ注入で差し替え可能にしておくと、後からオフライン/キャッシュをUI無改修で足せてテストもfake差し替えで楽になる。

パフォーマンス。アプリサイズはflutter build --analyze-size→DevToolsのApp Size toolで内訳を見て、配信はAABで端末別に30–50%減。画像はcacheWidth/cacheHeightで表示解像度にデコード（4Kを384×216表示で約1/100）。単発CPU処理はIsolate.run()で本線を止めない。const＋RepaintBoundary、saveLayer回避も定番。

自分が試すなら。デスクトップ配布があるプロジェクトは3.47へ上げてImpeller既定の恩恵を即受ける。windowingを使っているならsize/constraintsへのリネームを先に潰してから上げるのが安全。
