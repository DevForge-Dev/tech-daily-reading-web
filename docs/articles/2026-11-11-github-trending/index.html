11/11の話題リポジトリ — GPU内部を覗くhtop・Xの見逃し推文を回収・セルフホスト統合

AI一色の飽和局面で急上昇したのは、フロンティアAIではなく"自分の手元の環境を見える化・取り戻す・束ねる"オーナーシップ系3本。

📅 2026年11月11日 ⏱ 約3分 🔗 出典 3 件

本日の急上昇枠は、大規模AIそのものではなく「自分の手元の環境を見る・取り戻す・まとめる」道具に票が集まった。3本とも作成から数日〜1週間の新星で、増加"率"が高い。各リポジトリを「解決したい課題」「提供する機能」で押さえる。

shanselman/gputaskman（Python・⭐1.7k）

解決したい課題：「GPUメモリが15GB使用中——何に？ モデル重み？ KVキャッシュ？ ブラウザ？」が普通の nvidia-smi では分からない。提供する機能：GPU版の htop。プロセス別 VRAM/エンジン稼働に加え、ロード済みモデルや LLM の KV キャッシュ内訳まで可視化するターミナルUI（Win+NVIDIA/AMD・Linux/WSL・Apple Silicon、スコープはローカルGPU）。Scott Hanselman 作・MIT。なぜ今：公開約8日で1,654★・pushアクティブ。ローカル推論に踏み込むなら観測の手当てに直結する。

yetone/rewind-for-x（JavaScript・⭐353）

解決したい課題：X(Twitter)のタイムラインで一度スクロールして流れた"見たはず"の推文が二度と探せない。提供する機能：画面に半分以上露出した推文だけを作者/本文/画像/引用/RT元/リンク付きでローカル記録し、あとから一覧・キーワード検索・メディア種別フィルタで見返せる Chrome 拡張（Alt+Shift+R で即起動、広告やプロフィールは非記録）。なぜ今：公開約2日で353★の当日最高率級。avante.nvim で知られる yetone 作・MIT。

HolyArrs/HolyArrs（Go・⭐560）

解決したい課題：Plex/Jellyfin と各種 *Arr（Sonarr/Radarr系）を個別に立てて繋ぐセルフホスト運用の手間。提供する機能：番組・映画・音楽の収集〜再生を単一の自己ホストアプリに統合したオールインワン・メディアスタック（Docker/homelab前提）。なぜ今：公開約2日で560★、9言語READMEで国際拡散、open issues 76 と初期から活発。Go・AGPL-3.0＝自己ホスト/個人利用は問題ないが製品組み込みは要注意。

まとめ：3本を貫くのは"フロンティアAIの外側で、自分の資源（GPU・タイムライン・メディア）を自分の手に取り戻す"志向。自分が一つ試すなら、ローカル推論の可視化に直結する gputaskman から。
