Flutter 2026-10-03 — build hooks で同梱、transformer で連打制御、Rebuild Stats で可視化

11月 3.50 の WasmGC／Impeller 一本化を前に。native assets 同梱、bloc_concurrency の4トランスフォーマー、Hero 共有要素、DevTools Rebuild Stats。

📅 2026年10月3日 ⏱ 約4分 🔗 出典 7 件

年4回サイクル（3.41/3.44/3.47/3.50）の締めが近づき、11月の 3.50 stable には大きな既定変更が控える。現行安定版は Flutter 3.47.5 / Dart 3.13.4、beta は 3.49.0-0.1.pre / Dart 3.14.0。今日の主役は、ビルド基盤・アニメーション・状態管理・計測の各所で「定型作業を仕組みで消す」動きだ。

何が新しいか（リリース）

beta で前進したのが build hooks × native assets。hook/build.dart がビルド時にネイティブライブラリをコンパイル／取得して同梱し、hook/link.dart の tree-shaking が未使用ネイティブシンボルを除去する。dart run／flutter build がフックを自動実行するので、dart:ffi 連携や C/Rust ライブラリ同梱にありがちな「手動コピー・プラットフォーム分岐」が消える。言語面では Dart 3.14 の dot shorthands（MainAxisAlignment.start → .start）が定着、一方 macros は無期限ポーズのままでコード生成は従来どおり build_runner＋source_gen が主軸。そして11月 3.50 の目玉は Web の WasmGC 既定化（--wasm、dart:html→package:web）と Android の Impeller 一本化（legacy Skia 撤去・API29+）だ。

主役の仕組み：bloc_concurrency の event transformer

状態管理で今日いちばん実務に効くのが bloc_concurrency（0.3.0）の event transformer。on<Event>(handler, transformer: ...) に渡すだけで、同一イベントが連続したときの処理方針を宣言的に切り替えられる。未指定は concurrent 相当だが、API 連携では明示が安全だ。

検索サジェストは古い結果の上書きを防ぐ restartable()、送信ボタン連打は droppable()、順序保証が要るページングは sequential()——と、UI の要求がそのまま指定に対応する。土台には hydrated_bloc で状態の自動永続化、bloc_test の blocTest(build/act/expect) で event→state 列を厳密検証、BlocSelector で最小購読、BlocObserver で横断ロギング、が揃う。イベント駆動・監査可能・大規模チームの一貫性は依然 Bloc が優位で、新規の手触り重視は Riverpod 3.3、細粒度は signals、という住み分けだ。

アニメーションと計測

画面間の主役は Hero／共有要素トランジション。遷移元/先に同じ Hero(tag: 'id', child: ...) を置くだけで、Navigator の push/pop 時にフレームワークが対の widget をルート間で飛ばす（既定の飛行経路は MaterialRectArcTween）。飛行中だけ別 widget に差し替える flightShuttleBuilder、円→矩形を中心基準で補間する radial hero（MaterialRectCenterArcTween＋ClipOval×ClipRect）が実務の勘所。Android の predictive back ジェスチャに合わせた shared element transition も framework へ入りつつある。計測面では DevTools Performance の Rebuild Stats（Track Widget Builds）で各 widget のフレーム毎 build 回数がリアルタイム集計でき、多い行をクリックで該当コードへジャンプできる。

落とし穴と自分が試すなら

デザインシステム standalone 化（material_ui / cupertino_ui 1.0）の移行は dart fix --apply --code=migrate_design_widgets で、--code 無しは無変更の罠。計測は必ず profile モードで行い、重い計算は Isolate.run()／compute() で背景 isolate へ逃がす。自分ならまず Rebuild Stats を一周して過剰 rebuild の犯人を const 化・BlocSelector・child: 退避で削り、API 連携の bloc には明示 transformer を入れる。11月 3.50 の WasmGC／Impeller 一本化に備え、dart:html 依存と legacy Skia 前提のコードは今のうちに棚卸ししておきたい。

ひとこと：「仕組みで定型を消す」回。ネイティブ同梱は build hooks、連打・順序制御は transformer、過剰 rebuild は Rebuild Stats——手作業と勘を道具に置き換える。
