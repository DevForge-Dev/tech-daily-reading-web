3.50 stable 待ちの間に掘るStaggeredアニメ — 1本のcontrollerをIntervalで分割する

stable 3.50は11/7も未公開(#195830 open)。待ちの間に、1本のAnimationControllerをIntervalで時差駆動する技法を図解＋Riverpod3.0/DevToolsも。

📅 2026年11月7日 ⏱ 約4分 🔗 出典 4 件

まず現況：stable は 3.47.9 / Dart 3.13.7、beta は 3.50.0-0.4.pre / Dart 3.14.0（11/4）で、11/7 時点でも 3.50 stable は未公開。release-tracker #195830 は open のままでコメントなし、Dart Hash 欄もプレースホルダのままと、昇格の最終ゲートで足踏みが続く。3.50 の確定内容は Web WasmGC 既定・Android Impeller 一本化・Android 17 day-zero・material_ui/cupertino_ui の正式 deprecation。本番は 3.47.9 を pin しつつ、別ジョブで 0.4.pre を緑化（build web --wasm と appbundle）しておくのが安全。今日は“待ちの間”に手を動かせる技法として Staggered（時差）アニメーションを掘る。

1本のコントローラを Interval で分割する

staggered は「順次、または一部重なる」複数アニメを1つの AnimationController で駆動する考え方。controller の値は実時間（例 2000ms）に関係なく常に 0.0→1.0 を進み、プロパティごとに作った Tween がタイムライン上の自分の Interval でだけ動く。公式例では opacity=0.0–0.100 / width=0.125–0.250 / height・padding=0.250–0.375 / borderRadius=0.375–0.500 / color=0.500–0.750 と割り当て、最後の 25% は何も動かさない。範囲を重ねれば同時進行、空ければ「何も動かない隙間」になり、順次 vs 重畳を Interval の範囲だけで表現できる。

型と駆動

各プロパティは Tween<T>(begin:, end:).animate(CurvedAnimation(parent: controller, curve: Interval(0.125, 0.25, curve: Curves.ease)))。double 以外も同じで、EdgeInsetsTween・BorderRadiusTween・ColorTween が使える。State に SingleTickerProviderStateMixin を付け、AnimationController(duration: Duration(milliseconds: 2000), vsync: this) を作り dispose で破棄。駆動は await controller.forward().orCancel →（必要なら）reverse().orCancel、再入防止に if (controller.isAnimating) return;。表示は AnimatedBuilder 内で各 value を読む（opacity 単体なら FadeTransition で child の再描画を避けると軽い）。カーブのデバッグは main() で timeDilation = 10;。

合わせて押さえたい2つ

Riverpod 3.0 ＋ codegen：3.0 で Ref が統一され（旧 UserRef 等は廃止）、codegen の provider は autoDispose 既定。残したいものだけ @Riverpod(keepAlive: true)。runtime(3.3.2) と generator(4.x) はロックステップで上げる（3.x runtime に 2.x generator だとコンパイル不可）。DevTools Performance view：計測は必ず profile ビルドで（debug は未最適化 JIT で実機を反映しない）。frames chart は UI/raster の2本バーで 16ms 超過フレームを赤表示（シェーダコンパイルは濃い赤）。Enhance tracing の Track Builds/Layouts/Paints や Render Clip/Opacity を個別 off にして raster time が下がれば、そこが jank 元と特定できる。

自分が試すなら

まず公式の staggered サンプルを写経し、Interval の範囲を重ねたり空けたりして“隙間”の効果を体感する。次に timeDilation=10 でカーブを目視確認。アプリ全体の滑らかさは profile ビルド＋frames chart で赤フレームを拾い、不要な saveLayer・重なり opacity・clip/影を疑う、の順が定石だ。
