Claude Code v2.1.287 — プラグインが挙動に介入する「Claude Mods」、傍らで見張る『You Should Know』

機能を足すプラグインから、エージェントの振る舞いそのものを変える“Mods”へ。10/1リリースの目玉と、Barclaysの全社展開まで。

📅 2026年10月1日 ⏱ 約3分 🔗 出典 3 件

10月1日に公開された v2.1.287 は、Claude Code を「チャット」から「プログラム可能なプラットフォーム」へ押し進める節目になった。目玉は、プラグインが本体のより深い挙動に介入できる新しい拡張層「Claude Mods」だ。これまでのプラグインが skill / hook / コマンドを配って機能を足すものだったのに対し、Mods はエージェントの振る舞いそのものを調整できる点が新しい。

何が新しいか

公式が内蔵 Mod として用意した「You Should Know」は代表例で、/plugin enable cc-plugin-you-should-know@builtin で有効化すると、副次（サイド）エージェントがセッションを見守り、潜在的な問題や見落としに気づいた時点で横から指摘してくれる。あわせて /agents 一覧にセッション名・タスク名で絞る n:<text> フィルタ、MCP サーバーからの URL 方式 elicitation（2025-11-25 プロトコル）対応、Windows で Bash/PowerShell の一方を拒否するともう一方も無効化される起動時警告が入った。修正も厚く、危険な rm の安全策喪失、クラウド/Remote Control のファイル配信タイムアウト（30→35秒）、8000px 超画像の自動縮小、添付16件超の欠落などが解消されている。

仕組み（You Should Know の動き）

本体エージェントが作業する傍らで、別コンテキストの副次エージェントが進行を観測し、見落としや潜在リスクに気づいたときだけ割り込む——という監視ループになる。常時助言で邪魔をするのではなく「気づいた時点で横から」なのが肝だ。

自分が試すなら

まず /plugin enable cc-plugin-you-should-know@builtin で監視 Mod を入れ、長時間・無人のスケジュール実行やマイグレーション作業に当てて「見落とし指摘」の精度を確かめたい。チュートリアル群（Hooks/Subagents/Skills 完全ガイド、Boris 直伝ベストプラクティス）とも接続し、訂正のたびに CLAUDE.md を 200 行以下で更新、並列ワークツリー 3〜5 個で文脈汚染を避ける運用に、Mod の自動指摘を重ねるのが筋が良さそうだ。

注意点

Mods は本体挙動に深く介入できるぶん、何を監視し何に割り込むのかを把握しないと、かえってノイズや予期しない挙動変更になりうる。チーム導入時は運用規約と対応づけて有効化範囲を絞るのが安全。Windows の Bash/PowerShell 無効化警告のように、環境依存の落とし穴も増えている。

ひとこと

「プラグイン＝機能追加」から「Mods＝振る舞いの調整」へ。Barclays が開発者の50%へ展開（2027年までに大半）という当日ニュースとも符合する、運用規模を見据えたアップデートだ。
