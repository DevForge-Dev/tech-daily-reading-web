Claude Code

v2.1.246で/permissionsに「Auto mode」タブ・広すぎるBash許可に起動警告 — /designと"Concise"、そして市場54%へ

派手な新モデルではなく「権限と出力の見通し」を締める更新。/permissionsにAuto modeタブが付き自動許可ルールをGUIで編集、ワイルドカード先行のBash許可には起動時警告。/designはCLI/デスクトップでアートボードから実装まで、Conciseは結論を先頭に。裏では年換算売上80億ドル・AIコーディング市場の約54%という定着が進む。

📅 2026年8月27日 ⏱ 約3分 🔗 出典 5 件

今日のClaude Codeは、モデルの世代交代ではなく権限設計と出力体験の細部を締める一日だった。最新版 v2.1.246（8月25日）で /permissions に「Auto mode」タブが加わり、どのツール実行を自動で通すかの分類ルールを画面上で確認・編集できる。あわせて、サブコマンドの前にワイルドカードを置いたBash許可ルールには起動時に警告が出るようになり、Bash(* install) のような意図せず広すぎる許可を握らせる事故を未然に防ぐ。ターン終了時の所要時間表示には完了時刻も併記され、長時間セッションの振り返りがしやすい。

何が新しいか

UI面では2つの新スキル/スタイルが目を引く。/design（8月17日にリサーチプレビュー）はブリーフやスクリーンショット、既存デザインを渡すと編集可能なアートボードを公開し、1枚選んで微調整→そのまま実装まで一気通貫でつなぐ。artifacts基盤の上で動き、ターミナルから離れずUIの叩き台づくりと実装を往復できる。出力スタイル「Concise」（v2.1.237・8月20日）は作業自体は丁寧にこなしつつ、返答は結果を先頭に置き前置きや逐次実況を省く。選択は /output-style から行い、.claude/settings.local.json にプロジェクト単位で保存されるので他PJに波及しない。

エコシステムと事業の温度感

技術記事側では、決定論的に走るHooks（PreToolUseでの書込遮断・PostToolUseでのprettier・Stopでのテスト）、独自コンテキストで並列委譲するSubagents、必要時だけ本文を読むSkillsという3層の使い分けを整理したガイドが2026年版として出そろった。指針は明快で「強制はHooks/権限、文脈知識はSkills、委譲はSubagents、常時指針はCLAUDE.mdへ短く」。事業面では、Claude Codeが2026年5月時点で年換算売上80億ドル規模・AIコーディング市場の約54%を占め、年100万ドル超の大口顧客は倍増して1000社超、法人サブスクは年初比4倍とされる。

自分が試すなら・注意点

まず /permissions のAuto modeタブで現状の自動許可を棚卸しし、Bash(*...) のような先行ワイルドカードを具体的なサブコマンド許可へ絞り直したい。UIの叩き台は /design でアートボードから起こし、結論から素早く確認したい定型作業は Concise に切り替える。注意点は更新頻度の速さで、GUIで一度整えても新タブ・新ルールが増えるため、破壊的変更の有無を確認しつつこまめに追従すること。企業導入は「ツール導入」ではなく変更管理として、1チーム起点で CLAUDE.md を磨いてから横展開するのが定石だ。

ひとこと

モデルが一段落し、権限・出力・デザイン連携という「毎日安全に使い倒すための足回り」を固める局面。地味だが、道具としての完成度と安心感が着実に上がっている。
