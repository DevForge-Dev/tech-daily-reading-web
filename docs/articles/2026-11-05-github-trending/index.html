govijr/terminal-mac（Swift・⭐約1.5k）

解決したい課題。 ターミナル中心の作業中に、ウィンドウやメニューといった GUI 操作へ切り替えるのは文脈が途切れて億劫で、CUI だけの環境ではそもそも触れない。提供する機能。 macOS 全体（ウィンドウ・メニュー・アプリ操作）をテキスト端末の中に再現し、GUI 的な操作を文字で行える単体 Swift アプリ。なぜ今急上昇か。 created 2026-11-03＝公開約1日で実測約1,478★/forks90（日平均約1,000★/日級）と、当日計測組で最高率級。AI一色の中で希少な「見た目のインパクト×システムハック」の非AI新星として拡散した。Swift・MIT。

AssassinCreator/steam-stash-value-report-card（Python・⭐約747）

解決したい課題。 自分の Steam ライブラリにどれだけの「資産価値」が眠っているか、どれが売れ筋でどれが積みゲーかが一目で分からない。提供する機能。 ライブラリの資産価値をターミナルで算出し、ゲーム別・マーケット別に「売れたもの/眠っているもの」を一覧化、共有用のカード画像に印字する。Windows 単体ビルドでアカウント連携不要。なぜ今急上昇か。 created 2026-11-02＝公開約2〜3日で実測約747★/forks57（日平均約300★/日）。「自分の積みゲーの価値を可視化して晒す」遊び心が拡散理由。Python・MIT。

elvarofficial/teardown（JavaScript・⭐約1.9k）

解決したい課題。 身近な機械や装置の仕組みは、実際に分解しないと中身が見えず、安全・費用の面から気軽に学べない。提供する機能。 任意の「機械・装置」を3Dシミュレーターに起こして分解し、中身をインタラクティブに見られる Claude Code スキル。身近なモノを「ばらして」学べる。なぜ今急上昇か。 created 2026-10-30＝公開約5日で実測約1,898★/forks287（日平均約380★/日）。AIスキルではあるが「モノを分解して仕組みを見る」という創作/教育寄りの尖った新規性で当日モメンタム上位に。JavaScript・MIT。

まとめ：自分が試すなら。 手元ですぐ回せるのは teardown——Claude Code スキルなので、既存のスキル運用にそのまま載せて「身近な装置の3D分解」を試せる。3本に共通するのは、AIの汎用的な便利さではなく具体的な好奇心・遊び心・面倒を突いた点。トレンドがAIで埋まるほど、こうした「人の手触り」のあるツールが相対的に目立って伸びる構図が今日も続いた。
