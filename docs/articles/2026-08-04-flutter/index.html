3.45 リリースウィンドウ入り — 今日の通奏低音は「フレーム予算を守る」：layout を誘発しない Transform/Opacity・RepaintBoundary・CustomPainter 最適化・rebuild 削減

現行安定版は 3.44.7 / Dart 3.12、次の機能リリースは2026年8月（3.45系は未リリース）。移行前の足場固めと、jank を断つ設計（合成変換・RepaintBoundary・CustomPainter最適化）＋状態構造による rebuild 削減が今日の芯。

📅 2026年8月4日 ⏱ 約4分 🔗 出典 4 件

Flutter は年4回（2/5/8/11月）の機能リリースで、いまは 3.45 のリリースウィンドウに入っている。現行安定版は Flutter 3.44.7 / Dart 3.12 で、3.45 系はまだ未リリース。機能リリースの合間は 3.44 系で安定運用を固める好機だ。移行前チェックは、① flutter upgrade で 3.44 系の最新パッチへ追随、② Impeller を実機（特にミッドレンジ Android）で検証し差が出たら --no-enable-impeller で切り分け、③ dart fix / dart format・flutter analyze で警告解消、④ Material/Cupertino のパッケージ分離に備えた依存整理、の4点。

今日の芯はパフォーマンスだ。複雑アニメでフレームが落ちるとき、多くは「純グラフィック変換のつもりで layout パスを誤って誘発している」ことが原因。width/height/padding をアニメさせると毎フレーム再レイアウトが走る。合成可能な Transform（scale/translate/rotate）・Opacity に寄せて layout を回さず、アニメ区間を RepaintBoundary で囲んで再描画を周囲から切り離すのが鉄則だ。

CustomPainter の最適化も同じ budget 思想だ。① Paint オブジェクトを毎フレーム作らずキャッシュ（paint() 内で Paint() を new しない）、② shouldRepaint を正しく実装して不要な再描画を止める、③ RepaintBoundary で描画を隔離する。計測は DevTools を profile モードで行い、UI/raster スレッドが budget に収まるか見る。土台の Impeller（iOS=Metal / Android=Vulkan、API 29+ 既定）は pre-compiled shader で複雑シーンの raster 時間を約50%短縮し、shader compilation jank を排除する。

rebuild 削減は状態の構造で決まる。2026 の比較記事の結論は、性能はライブラリ選択より「状態をどう構造化し、派生値を memoize し、重い処理を隔離するか」だ。冗長な再計算は derived/computed provider（Riverpod）や selector（Bloc）で回避し、ref.watch(provider.select((s)=>s.field)) で必要フィールドだけ購読して granular rebuild にする。棲み分けは新規の既定が Riverpod 3.0（compile-time safety・最小ボイラープレート）、監査証跡が要る規制業界は Bloc 9.0。現行版は Riverpod 3.3.x / bloc 9.2.x。

アニメの黄金律は「まず implicit」。UI モーションの約80%は AnimatedOpacity/AnimatedContainer/AnimatedSize で足り、複雑な choreography・physics だけ explicit（AnimationController＋Tween、dispose 必須）。重い演出は Rive/Lottie にオフロード。時間設計は micro 50–200ms／component 200–400ms／Hero・page 300–600ms。まとめ：3.45 待ちのいまは 3.44 系で足場を固めつつ、layout を回さない・隔離する・購読を絞る、の3手で budget を守るのが最短だ。
