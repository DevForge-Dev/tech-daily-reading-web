Next.js 16 の next/image 変更点 — priority 非推奨・qualities 既定[75]・キャッシュ4時間で、移行が“静かに”壊れる所と直し方

next/image は LCP/CLS を最も左右する定番だが、Next.js 16 で既定値とAPIが複数変わり、15以前からの移行で静かに壊れる。priority が非推奨→preload、画質は images.qualities が既定[75]に制限、最適化画像の最小キャッシュが60秒→4時間、images.domains は remotePatterns へ、私設IP最適化は既定ブロック……。LCP悪化・画質劣化・400エラーを避ける要点を、next.config の明示設定とコードで押さえる。
